48.1 Bi-tension

Our construction of good expanders, would use the idea of composing graphs together. To this end, in our analysis, we will need the notion of bi-tension. Let \(\DEdges (\Graph )\) be the set of directed edges of \(\Graph \); that is, every edge \(xy \in E(\Graph )\) appears twice as \(\dirEdge {x}{y}\) and \(\dirEdge {y}{x}\) in \(\DEdges \).

  • Definition 48.1.1. For a graph \(\Graph \), let \(\BiDialX {\Graph }\) denote the bi-tension of \(\Graph \); that is, the smallest constant, such that for any two function \(f,g :V(\Graph ) \rightarrow \Re \), we have that

    \(\seteqnumber{0}{48.}{0}\)

    \begin{align} \ExExt {x,y \in V}{\cardin {f(x)- g(y)}^2} \leq \BiDialX {\Graph } \ExExt { \dirEdge {x}{y} \in \DEdges \; }{\cardin {f(x)- g(y)}^2}. \eqlab {b:i:tension} \end{align}

The proof of the following lemma is similar to the proof of Lemma 47.2.4. The proof is provided for the sake of completeness, but there is little new in it.

  • Lemma 48.1.2. Let \(\Graph =(V,E)\) be a connected \(d\)-regular graph with \(n\) vertices. Then \(\ds \BiDialX {\Graph } = \frac {1}{1-\EVal }\,\), where \(\EVal = \EVal (\Graph )\), where \(\EVal (\Graph ) = \max \pth {\TEV {2}, -\TEV {n} }\), where \(\TEV {i}\) is the \(i\)th largest eigenvalue of the random walk matrix associated with \(\Graph \).

  • Proof: We can assume that \(\Ex {f(x)}=0\). As such, we have that

    \(\seteqnumber{0}{48.}{1}\)

    \begin{align} \eqlab {reduction:2} &\hspace {-1cm} \ExExt {x,y \in V}{\cardin {f(x)- g(y)}^2} =\ExExt {x,y \in V}{\pth []{f(x)}^2} -2 \ExExt {x,y \in V}{ f(x) g(y)} + \ExExt {y \in V}{\pth []{g(y)}^2} =\ExExt {x,y \in V}{\pth []{f(x)}^2} + \ExExt {y \in V}{\pth []{g(y)}^2}. \end{align}

    Let \(\TMtrx \) be the matrix associated with the random walk on \(\Graph \) (each entry is either zero or \(1/d\)), we have

    \(\seteqnumber{0}{48.}{2}\)

    \begin{align*} \rho = \ExExt {\dirEdge {x}{y} \in \DEdges \;}{ \cardin {f(x)-g(y)}^2 } & = \frac {1}{nd} \sum _{\dirEdge {x}{y} \in \DEdges \;}\pth { f(x) -g(y) }^2 = \frac {1}{n} \sum _{x,y \in V} \TMtrx _{xy} \pth {f(x) - g(y)}^2\\ &= \frac {1}{n}\sum _{x\in V} \pth {\pth {f(x)}^2 +\pth { g(x)}^2} - \frac {2}{n} \sum _{x,y \in V} \TMtrx _{xy} f(x)g(y). \end{align*} Let \(\Basis (\TMtrx )= \permut {v_1,\ldots , v_n}\) be the orthonormal eigenvector basis defined by \(\TMtrx \) (see Definition 47.2.3), with eigenvalues \(\TEV {1} \geq \TEV {2} \geq \cdots \geq \TEV {n}\), respectively. Write \(f=\sum _{i=1}^n \alpha _i v_i\) and \(g=\sum _{i=1}^n \beta _i v_i\). Since \(\Ex {f(x)} = 0\), we have that \(\alpha _1 = 0\). Now, \(\TMtrx _{xy}= \TMtrx _{yx}\), and we have

    \(\seteqnumber{0}{48.}{2}\)

    \begin{align*} \sum _{x,y \in V} \TMtrx _{xy} f(x) g(y) &= \sum _{x,y \in V} \TMtrx _{yx} \pth {\sum _{i} \alpha _iv_i(x)} \pth {\sum _{j} \beta _jv_j(y)} = \sum _{i,j} \alpha _i \beta _j \sum _{y\in V} v_j(y) \sum _{x \in V} \TMtrx _{yx} v_i(x) \\ & =\sum _{i,j} \alpha _i \beta _j \sum _{y\in V} v_j(y) \pth {\TEV {i} v_i \pth {y} \MakeBig } =\sum _{i,j} \alpha _i \beta _j \TEV {i} \DotProd {v_j}{v_i} =\sum _{i=2}^n \alpha _i \beta _i \TEV {i} \sum _{y\in V}\pth {v_i(y)}^2 \\&\leq \EVal \sum _{i=2}^n \frac {\alpha _i^2 + \beta _i^2}{2}\sum _{y\in V}\pth {v_i(y)}^2 \leq \frac {\EVal }{2} \sum _{i=1}^n \sum _{y\in V}\pth { \pth {\alpha _iv_i(y)}^2 + \pth {\beta _iv_i(y)}^2 }\\ &=\frac {\EVal }{2} \sum _{y\in V} \pth { \pth {f(y)}^2 + \pth {g(y)}^2 } \end{align*} As such,

    \(\seteqnumber{0}{48.}{2}\)

    \begin{align*} \ExExt {\dirEdge {x}{y} \in \DEdges \;}{ \cardin {f(x)-g(y)}^2 } &= \frac {1}{nd}\sum _{\dirEdge {x}{y} \in \DEdges \;} \cardin {f(x)-g(y)}^2 = \frac {1}{n}\sum _{y\in V} \pth {\pth {f(y)}^2 +\pth { g(y)}^2} - \frac {1}{n} \sum _{x,y \in V} \frac {2 f(x)g(y)}{d}\\ &= \frac {1}{n}\sum _{y\in V} \pth {\pth {f(y)}^2 +\pth { g(y)}^2} - \frac {2}{n} \sum _{x,y \in V} \TMtrx _{xy} f(x)g(y)\\ & \geq \pth { \frac {1}{n}- \frac {2}{n} \cdot \frac {\EVal }{2} } \sum _{y\in V} \pth {\pth {f(y)}^2 +\pth { g(y)}^2} = \pth {1-\EVal } \pth { \ExExt {y \in V}{\pth []{f(y)}^2} + \ExExt {y \in V}{\pth []{g(y)}^2} }\\ &=\pth {1-\EVal } \ExExt {x,y \in V}{\cardin {f(x)- g(y)}^2}, \end{align*} by Eq. (48.2). This implies that \(\BiDialX {\Graph } \leq {1}/\pth []{1-\EVal \,}\). Again, by trying either \(f=g= v_2\) or \(f = v_n\) and \(g= -v_n\), we get that the inequality above holds with equality, which implies \(\displaystyle \BiDialX {\Graph } \geq {1} / \pth []{1-\EVal \,}\). Together, the claim now follows.

48.2 Explicit construction

For a set \(U \subseteq V\) of vertices, its characteristic vector, denoted by \(x = \ChartX {U}\), is the \(n\) dimensional vector, where \(x_i = 1\) if and only if \(i \in U\).

The following is an easy consequence of Lemma 47.1.1.

  • Lemma 48.2.1. For a \(d\)-regular graph \(\Graph \) the vector \(\OneVec {n} = \pth {1, 1, \ldots , 1}\) is the only eigenvector with eigenvalue \(d\) (of the adjacency matrix \(\Mtrx \pth {\Graph }\), if and only if \(\Graph \) is connected. Furthermore, we have \(\cardin {\lambda _i} \leq d\), for all \(i\).

Our main interest would be in the second largest eigenvalue of \(\Mtrx \). Formally, let

\[ \lambda _2(\Graph ) = \max _{x \bot \OneVec {n}, x \ne 0} \cardin {\frac {\DotProd {x \Mtrx }{x}}{\DotProd {x}{x}}}. \]

We state the following result but do not prove it since we do not need it for our nafarious purposes (however, we did prove the left side of the inequality).

  • Theorem 48.2.2. Let \(\Graph \) be a \(\delta \)-expander with adjacency matrix \(\Mtrx \) and let \(\lambda _2 = \lambda _2(\Graph )\) be the second-largest eigenvalue of \(\Mtrx \). Then

    \[ \frac {1}{2} \pth {1- \frac {\lambda _2}{d}} \leq \delta \leq \sqrt {2\pth {1 - \frac {\lambda _2}{d}}}. \]

What the above theorem says, is that the expansion of a [𝑛, 𝑑, 𝛿]-expander is a function of how far is its second eigenvalue (i.e., \(\lambda _2\)) from its first eigenvalue (i.e., \(d\)). This is usually referred to as the spectral gap.

We will start by explicitly constructing an expander that has “many” edges, and then we will show to reduce its degree till it become a constant degree expander.

48.2.1 Explicit construction of a small expander
48.2.1.1 A quicky reminder of fields

A field is a set \(\Field \) together with two operations, called addition and multiplication, and denoted by \(+\) and \(\cdot \), respectively, such that the following axioms hold:

  • (i) Closure: \(\forall x,y \in \Field \), we have \(x+y \in \Field \) and \(x\cdot y \in \Field \).

  • (ii) Associativity: \(\forall x,y,z \in \Field \), we have \(x+(y+z) = (x+y)+z\) and \((x \cdot y ) \cdot z =x \cdot (y\cdot z)\).

  • (iii) Commutativity: \(\forall x,y \in \Field \), we have \(x+y = y+x\) and \(x\cdot y = y\cdot x\).

  • (iv) Identity: There exists two distinct special elements \(0,1 \in \Field \). We have that \(\forall x \in \Field \) it holds \(x+0 = a\) and \(x\cdot 1 = x\).

  • (v) Inverse: There exists two distinct special elements \(0,1 \in \Field \), and we have that \(\forall x \in \Field \) there exists an element \(-x \in \Field \), such that \(x+ (-x)=0\).

    Similarly, \(\forall x \in \Field \), \(x \ne 0\), there exists an element \(y= x^{-1} = 1/x \in \Field \) such that \(x \cdot y = 1\).

  • (vi) Distributivity: \(\forall x,y,z \in \Field \) we have \(x\cdot (y+z) = x\cdot y + x\cdot z\).

Let \(q = 2^t\), and \(r>0\) be an integer. Consider the finite field \(\Field _{q}\). It is the field of polynomials of degree at most \(t-1\), where the coefficients are over \(\mathbb {Z}_2\) (i.e., all calculations are done modulus 2). Formally, consider the polynomial

\[ p(x) = x^t + x +1. \]

It it irreducible over \(\Field _2 =\brc {0,1}\) (i.e., \(p(0) = p(1) \ne 0\)). We can now do polynomial arithmetic over polynomials (with coefficients from \(\Field _2\)), where we do the calculations modulus \(p(x)\). Note, that any irreducible polynomial of degree \(n\) yields the same field up to isomorphism. Intuitively, we are introducing the \(n\) distinct roots of \(p(x)\) into \(\Field \) by creating an extension field of \(\Field \) with those roots.

An element of \(\Field _q=\Field _{2^t}\) can be interpreted as a binary string \(b = b_0b_1\ldots ,b_{t-1}\) of length \(t\), where the corresponding polynomial is

\[ \mathrm {poly}(b) =\sum _{i=0}^{t-1} b_i x^i. \]

The nice property of \(\Field _q\) is that addition can be interpreted as a xor operation. That is, for any \(x,y \in \Field _q\), we have that \(x+y+y = x\) and \(x-y -y = x\). The key properties of \(\Field _q\) we need is that multiplications and addition can be computed in it in polynomial time in \(t\), and it is a field (i.e., each non-zero element has a unique inverse).

48.2.1.1.1 Computing multiplication in \(\Field _q\). Consider two elements \(\alpha , \beta \in \Field _q\). Multiply the two polynomials \(\mathrm {poly}(\alpha )\) by \(\mathrm {poly}(\beta )\), let \(\mathrm {poly}(\gamma )\) be the resulting polynomial (of degree at most \(2t-2\)), and compute the remainder \(\mathrm {poly}(\beta )\) when dividing it by the irreducible polynomial \(p(x)\). For this remainder polynomial, normalize the coefficients by computing their modules base \(2\). The resulting polynomial is the product of \(\alpha \) and \(\beta \).

For more details on this field, see any standard text on abstract algebra.

48.2.1.2 The construction

Let \(q = 2^t\), and \(r>0\) be an integer. Consider the linear space \(\LSpace = \Field _q^{\,r}\). Here, a member \(\alpha = (\alpha _0,\ldots , \alpha _r) \in \LSpace \) can be thought of as being a string (of length \(r+1\)) over \(\Field _q\), or alternatively, as a binary string of length \(n=t(r+1)\).

For \(\alpha = (\alpha _0,\ldots , \alpha _r) \in \LSpace \), and \(x,y \in \Field _q\), define the operator

\[ \rho (\alpha ,x,y) = \alpha + y \cdot \pth { 1, x, x^2, \ldots , x^r} = \pth {\alpha _0 + y, \alpha _1 + y x, \alpha _2 + y x^2, \ldots , \alpha _r+ y x^r} \in \LSpace . \]

Since addition over \(\Field _q\) is equivalent to a xor operation we have that

\(\seteqnumber{0}{48.}{2}\)

\begin{align*} \rho \pth {\MakeBig \rho (\alpha ,x,y), x, y} &= \pth {\alpha _0 + y + y, \alpha _1 + y x + yx, \alpha _2 + y x^2+yx^2, \ldots , \alpha _r+ y x^r+yx^r}\\ &= \pth {\alpha _0, \alpha _1, \alpha _2, \ldots , \alpha _r} = \alpha . \end{align*} Furthermore, if \((x,y) \ne (x',y')\) then \(\rho (\alpha ,x,y) \ne \rho (\alpha ,x',y')\).

We now define a graph \(\LD {q}{r}=\pth {\LSpace , E}\), where

\[ E= \brc { \alpha \beta \sep { \begin {array}{l} \alpha \in \LSpace , x, y \in \Field _q\\ \beta = \rho (\alpha ,x,y) \end {array}}} \]

Note, that this graph is well defined, as \(\rho (\beta ,x,y) =\alpha \). The degree of a vertex of \(\LD {q}{r}\) is \(\cardin {\Field _q}^2 = q^2\), and \(\LD {q}{r}\) has \(N = \cardin {\LSpace } = q^{r+1} = 2^{t(r+1)}=2^n\) vertices.

  • Theorem 48.2.3. For any \(t > 0, r>0\) and \(q = 2^t\), where \(r<q\), we have that \(\LD {q}{r}\) is a graph with \(q^{r+1}\) vertices. Furthermore, \(\lambda _1\pth {\LD {q}{r}} = q^2\), and \(\lambda _i\pth {\LD {q}{r}} \leq rq\), for \(i=2,\ldots , n\).

    In particular, if \(r \leq q/2\), then \(\LD {q}{r}\) is a [𝑞𝑟+1 , 𝑞2 , 14 ]-expander.

  • Proof: Let \(\Mtrx \) be the \(N \times N\) adjacency matrix of \(\LD {q}{r}\). Let \(L:\Field _q \rightarrow \brc {0,1}\) be a linear map which is onto. It is easy to verify that \(\cardin {L^{-1}(0)} = \cardin {L^{-1}(1)}\)48.1

    We are interested in the eigenvalues of the matrix \(\Mtrx \). To this end, we consider vectors in \(\Re ^N\). The \(i\)th row an \(i\)th column of \(\Mtrx \) is associated with a unique element \(b_i \in \LSpace \). As such, for a vector \(v \in \Re ^N\), we denote by \(\Entry {v}{b_i}\) the \(i\)th coordinate of \(v\). In particular, for \(\alpha =\pth {\alpha _0, \ldots , \alpha _r} \in \LSpace \), let \(v_\alpha \in \Re ^N\) denote the vector, where its \(\beta =\pth {\beta _0, \ldots , \beta _r} \in \LSpace \) coordinate is

    \[ \Entry {v_{\alpha }}{\beta } = \pth {-1}^{L\pth []{\sum _{i=0}^r \alpha _i\, \beta _i}}. \]

    Let \(V = \brc {v_\alpha \sep { \alpha \in \LSpace }}\). For \(\alpha \ne \alpha ' \in V\), observe that

    \[ \DotProd {v_{\alpha }}{v_{\alpha '}} = \sum _{\beta \in \LSpace } \pth {-1}^{L\pth []{\sum _{i=0}^r \alpha _i\, \beta _i}} \cdot \pth {-1}^{L\pth []{\sum _{i=0}^r \alpha _i'\, \beta _i}} = \sum _{\beta \in \LSpace } \pth {-1}^{L\pth []{\sum _{i=0}^r \pth {\alpha _i+\alpha _i'}\, \beta _i}} = \sum _{\beta \in \LSpace } \Entry {v_{\alpha +\alpha '}}{\beta }. \]

    So, consider \(\psi =\alpha +\alpha ' \ne 0\). Assume, for the simplicity of exposition that all the coordinates of \(\psi \) are non-zero. We have, by the linearity of \(L\) that

    \[ \DotProd {v_{\alpha }}{v_{\alpha '}} = \sum _{\beta \in \LSpace } \pth {-1}^{L\pth []{\sum _{i=0}^r \alpha _i\, \beta _i}} = \sum _{\beta _0 \in \Field _q, \ldots , \beta _{r-1} \in \Field _q} \;\; \pth {-1}^{L\pth []{ \psi _0\, \beta _0 + \cdots + \psi _{r-1}\,\beta _{r-1}}} \sum _{\beta _r \in \Field _q} \pth {-1}^{L\pth []{ \psi _r\, \beta _r}}. \]

    However, since \(\psi _r \ne 0\), the quantity \(\brc {\psi _r \beta _r\sep { \beta _r \in \Field _q}} = \Field _q\). Thus, the summation \(\sum _{\beta _r \in \Field _q} \pth {-1}^{L\pth []{ \psi _r\, \beta _r}}\) gets \(\cardin {L^{-1}(0)}\) terms that are \(1\), and \(\cardin {L^{-1}(0)}\) terms that are \(-1\). As such, this summation is zero, implying that \(\DotProd {v_{\alpha }}{v_{\alpha '}} = 0\). Namely, the vectors of \(V\) are orthogonal.

    Observe, that for \(\alpha ,\beta ,\psi \in \LSpace \), we have \(\Entry {v_\alpha }{\beta + \psi } =\Entry {v_\alpha }{\beta } \Entry {v_\alpha }{\psi }\). For \(\alpha \in \LSpace \), consider the vector \(\Mtrx v_\alpha \). We have, for \(\beta \in \LSpace \), that

    \(\seteqnumber{0}{48.}{2}\)

    \begin{align*} \Entry {\pth {\Mtrx v_\alpha }}{\beta } = \sum _{\psi \in \LSpace } \Mtrx _{\beta \psi } \cdot \Entry {v_\alpha }{\psi } &=\sum _{\substack {x,y\; \in \; \Field _q\\ \psi =\rho (\beta ,x,y)}} \Entry {v_\alpha }{\psi } =\sum _{x,y\; \in \; \Field _q} \Entry {v_\alpha }{\beta + y(1,x,\ldots , x^r)}\\ &=\pth {\sum _{x,y\; \in \; \Field _q} \Entry {v_\alpha }{y(1,x,\ldots , x^r)}} \cdot \Entry {v_\alpha }{\beta }. \end{align*} Thus, setting \(\lambda (\alpha ) = \sum _{x,y\; \in \; \Field _q} \Entry {v_\alpha }{y(1,x,\ldots , x^r)} \in \Re \), we have that \(\Mtrx v_\alpha = \lambda (\alpha ) \cdot v_\alpha \). Namely, \(v_\alpha \) is an eigenvector, with eigenvalue \(\lambda (\alpha )\).

    Let \(p_\alpha (x) =\sum _{i=0}^r \alpha _i x^i\), and let

    \(\seteqnumber{0}{48.}{2}\)

    \begin{align*} \lambda (\alpha )&= \sum _{x,y\; \in \; \Field _q} \Entry {v_\alpha }{y(1,x,\ldots , x^r)} \in \Re = \sum _{x,y \in \Field _q} \pth {-1}^{L(y p_\alpha (x))}\\ &= \sum _{\substack {x,y \in \Field _q\\p_\alpha (x)=0}} \pth {-1}^{L(y\; p_\alpha (x))} + \sum _{\substack {x,y \in \Field _q\\p_\alpha (x)\ne 0}} \pth {-1}^{L(y\; p_\alpha (x))} . \end{align*} If \(p_\alpha (x) = 0\) then \((-1)^{L(y\;p_\alpha (x))} = 1\), for all \(y\). As such, each such \(x\) contributes \(q\) to \(\lambda (\alpha )\).

    If \(p_\alpha (x) \ne 0\) then \(y\;p_\alpha (x)\) takes all the values of \(\Field _q\), and as such, \(L(y\;p_\alpha (x))\) is \(0\) for half of these values, and \(1\) for the other half. Implying that these kind terms contribute \(0\) to \(\lambda (\alpha )\). But \(p_\alpha (x)\) is a polynomial of degree \(r\), and as such there could be at most \(r\) values of \(x\) for which the first term is taken. As such, if \(\alpha \ne 0\) then \(\lambda (\alpha ) \leq rq\). If \(\alpha = 0\) then \(\lambda (\alpha )=q^2\), which implies the theorem.

48.1 Indeed, if \(Z = L^{-1}(0)\), and \(L(x) = 1\), then \(L(y)=1\), for all \(y \in U = \brc {x+z \sep {z \in Z}}\). Now, its clear that \(\cardin {Z} = \cardin {U}\).

This construction provides an expander with constant degree only if the number of vertices is a constant. Indeed, if we want an expander with constant degree, we have to take \(q\) to be as small as possible. We get the relation \(n = q^{r+1}\leq q^{q}\), since \(r \leq r\), which implies that \(q = \Omega ( \log n /\log \log n)\). Now, the expander of Theorem 48.2.3 is \(q^2\)-regular, which means that it is not going to provide us with a constant degree expander.

However, we are going to use it as our building block in a construction that would start with this expander and would inflate it up to the desired size.

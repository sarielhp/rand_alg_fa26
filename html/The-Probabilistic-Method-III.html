51.1 The Lovász Local Lemma

  • Lemma 51.1.1.

    • (i) \(\ds \Prob {A \sep {B \cap C}} = \frac {\Prob {A \cap B \sep {C}}}{\Prob {B \sep C}}\)

    • (ii) Let \(\eta _{1},\ldots ,\eta _{n}\) be \(n\) events which are not necessarily independent. Then,

      \(\seteqnumber{0}{51.}{0}\)

      \begin{align*} \ds \Prob {\Bigl . \cap _{i=1}^{n}\eta _{i}}=\Prob {\Bigl . \eta _{1}} * \Prob {\Bigl . \eta _{2}\sep {\eta _{1}}} \Prob {\Bigl . \eta _{3}\sep {\eta _{1}\cap \eta _{2}}}*\ldots *\Prob {\Bigl . \eta _{n}\sep {\eta _{1}\cap \ldots \cap \eta _{n-1}}}. \end{align*}

  • Proof: (i) We have that

    \(\seteqnumber{0}{51.}{0}\)

    \begin{align*} {\frac {\Prob {A \cap B \sep {C}}} {\Prob {B \sep {C}}}} = { \frac {\Prob {A \cap B \cap C}}{\Prob {C}}} \! \left / \; {\frac {\Prob {B \cap C}}{\Prob {C}}} \right . = \frac {\Prob {A \cap B \cap C}} {\Prob {B \cap C}} = \Prob {A \sep {B \cap C}}. \end{align*}

    As for (ii), we already saw it and used it in the minimum cut algorithm lecture.

  • Definition 51.1.2. An event \(\Event \) is mutually independent of a set of events \(\EuScript {C}\), if for any subset \(\EuScript {U} \subseteq \EuScript {C}\), we have that \(\Prob {\Event \cap \pth {\bigcap _{\Event ' \in U} \Event '}} =\Prob {\Event } \Prob {\bigcap _{\Event ' \in U} \Event '}\).

    Let \(\Event _1, \ldots , \Event _n\) be events. A dependency graph for these events is a directed graph \(\Graph =(\Vertices ,\Edges )\), where \(\brc {1,\ldots , n}\), such that \(\Event _i\) is mutually independent of all the events in \(\brc { \Event _j \sep { (i,j) \notin \Edges }}\).

Intuitively, an edge \((i,j)\) in a dependency graph indicates that \(\Event _i\) and \(\Event _j\) have (maybe) some dependency between them. We are interested in settings where this dependency is limited enough, that we can claim something about the probability of all these events happening simultaneously.

  • Lemma 51.1.3 (Lovász Local Lemma). Let \(\Graph (\Vertices ,\Edges )\) be a dependency graph for events \(\Event _1,\) \(\ldots , \Event _n\). Suppose that there exist \(x_i \in [0,1]\), for \(1 \leq i \leq n\) such that \(\ds \Prob {\Event _i} \leq x_i \prod _{(i,j) \in E} \pth {1-x_j}\). Then \(\ds \Prob {\cap _{i=1}^{n} \overline {\Event _i}} \geq \prod _{i=1}^{n} \pth {1-x_i}\).

We need the following technical lemma.

  • Lemma 51.1.4. Let \(\Graph (\Vertices ,\Edges )\) be a dependency graph for events \(\Event _1,\) \(\ldots , \Event _n\). Suppose that there exist \(x_i \in [0,1]\), for \(1 \leq i \leq n\) such that \(\ds \Prob {\Event _i} \leq x_i \prod _{(i,j) \in E} \pth {1-x_j}\). Now, let \(S\) be a subset of the vertices from \(\brc {1, \ldots , n}\), and let \(i\) be an index not in \(S\). We have that

    \(\seteqnumber{0}{51.}{0}\)

    \begin{align} \Prob {\Event _i \sep { \cap _{j \in S} \overline {\Event _j}}} \leq x_i. \eqlab {ind} \end{align}

  • Proof: The proof is by induction on \(k = \cardin {S}\).

    For \(k = 0\), we have by assumption that \(\Prob {\Event _i \sep { \cap _{j \in S} \overline {\Event _j}}} = \Prob {\Event _i } \leq x_i \prod _{(i,j) \in E} \pth {1-x_j} \leq x_i\).

    Thus, let \(N = \brc { j \in S \sep { (i,j) \in E}}\), and let \(R = S \setminus N\). If \(N = \emptyset \), then we have that \(\Event _i\) is mutually independent of the events of \(\EuScript {C}(R) = \brc {\Event _j \sep { j \in R}}\). Thus, \(\Prob {\Event _i \sep { \cap _{j \in S} \overline {\Event _j}}} = \Prob {\Event _i \sep { \cap _{j \in R} \overline {\Event _j}}} = \Prob {\Event _i} \leq x_i\), by arguing as above.

    By Lemma 51.1.1 (i), we have that

    \(\seteqnumber{0}{51.}{1}\)

    \begin{align*} \Prob {\Event _i \sep {\bigcap _{j \in S} \overline {\Event _j}}} = \frac {\Prob {\Event _i \cap \pth { \cap _{j \in N} \overline {\Event _j} } \sep { \cap _{m \in R} \overline {\Event _m}}}} {\Prob {\cap _{j \in N}\overline {\Event _j} \sep { \cap _{m \in R} \overline {\Event _m}} }}. \end{align*} We bound the numerator by

    \(\seteqnumber{0}{51.}{1}\)

    \begin{align*} \Prob {\Event _i \cap \pth { \cap _{j \in N} \overline {\Event _j} } \sep { \cap _{m \in R} \overline {\Event _m}}} \leq \Prob {\Event _i \sep { \cap _{m \in R} \overline {\Event _m}}} = \Prob {\Event _i} \leq x_i \prod _{(i,j) \in E} \pth {1-x_j}, \end{align*} since \(\Event _i\) is mutually independent of \(\EuScript {C}(R)\). As for the denominator, let \(N=\brc {j_1, \ldots , j_r}\). We have, by Lemma 51.1.1 (ii), that

    \(\seteqnumber{0}{51.}{1}\)

    \begin{eqnarray*} \Prob { \overline {\Event _{j_1}} \cap \ldots \cap \overline {\Event _{j_r}} \sep { \cap _{m \in R} \overline {\Event _m}}} \hspace {-4cm}&&\hspace {3.0cm}= \Prob {\overline {\Event _{j_1}} \sep { \cap _{m \in R} \overline {\Event _m}}} \Prob {\overline {\Event _{j_2}} \sep { \overline {\Event _{j_1}} \;\cap \; \pth { \cap _{m \in R} \overline {\Event _m}}}} \\ &&\cdots \Prob {\overline {\Event _{j_r}} \sep { \overline {\Event _{j_1}} \cap \ldots \cap \overline {\Event _{j_{r-1}}} \;\cap \; \pth { \cap _{m \in R} \overline {\Event _m}}}} \\ &=& \pth {1 - \Prob {{\Event _{j_1}} \sep { \cap _{m \in R} \overline {\Event _m}}}} \; \pth { 1 - \Prob {{\Event _{j_2}} \sep { \overline {\Event _{j_1}} \cap \pth { \cap _{m \in R} \overline {\Event _m}}}}} \\ &&\cdots \pth { 1 - \Prob {{\Event _{j_r}} \sep { \overline {\Event _{j_1}} \cap \ldots \cap \overline {\Event _{j_{r-1}}} \;\cap \; \pth { \cap _{m \in R} \overline {\Event _m}}}} \;} \\ &\geq & \pth {1 -x_{j_1}} \cdots \pth {1 - x_{j_r}} \geq \prod _{(i,j) \in E} \pth {1 -x_j}, \end{eqnarray*}

    by Eq. (51.1) and induction, as every probability term in the above expression has less than \(\cardin {S}\) items involved. It thus follows, that \(\Prob {\Event _i \sep {\bigcap _{j \in S} \overline {\Event _j}}} \leq x_i\).

Proof of Lovász local lemma (Lemma 51.1.3): Using Lemma 51.1.4, we have that

\(\seteqnumber{0}{51.}{1}\)

\begin{align*} \Prob {\cap _{i=1}^{n} \overline {\Event _i}} = \pth {1 - \Prob {\Event _1}} \pth {1 - \Prob {\Event _2 \sep {\overline {\Event _1}}}} \cdots \pth {1 - \Prob {\Event _n \sep { \cap _{i=1}^{n-1} \overline {\Event _{i}}}}} \geq \prod _{i=1}^{n} \pth {1-x_i}. \end{align*}     

  • Corollary 51.1.5. Let \(\Event _1, \ldots , \Event _n\) be events, with \(\Prob {\Event _i} \leq p\) for all \(i\). If each event is mutually independent of all other events except for at most \(d\), and if \(\;e p(d+1)\leq 1\), then \(\Prob {\cap _{i=1}^{n} \overline {\Event _{i}}} > 0\).

  • Proof: If \(d = 0\) the result is trivial, as the events are independent. Otherwise, there is a dependency graph, with every vertex having degree at most \(d\). Apply Lemma 51.1.3 with \(x_i = \frac {1}{d+1}\). Observe that

    \(\seteqnumber{0}{51.}{1}\)

    \begin{align*} x_i (1-x_i)^{d} =\frac {1}{d+1}\pth {1- \frac {1}{d+1}}^d > \frac {1}{d+1} \cdot \frac {1}{e} \geq p, \end{align*} by assumption and the since \(\pth []{1- \frac {1}{d+1}}^d > 1/e\), see Lemma 51.1.6 below.

The following is standard by now, and we include it only for the sake of completeness.

  • Lemma 51.1.6. For any \(n \geq 1\), we have \(\ds \pth []{1- \frac {1}{n+1}}^n > \frac {1}{e}\).

  • Proof: This is equivalent to \(\pth {\frac {n}{n+1}}^n > \frac {1}{e}\). Namely, we need to prove \(e > \pth {\frac {n+1}{n}}^n\). But this obvious, since \(\pth {\frac {n+1}{n}}^n = \pth {1 + \frac {1}{n}}^n < \exp \pth {n(1/n)} = e\).

51.2 Application to \(k\)-SAT

We are given a instance \(I\) of \(k\)-SAT, where every clause contains \(k\) literals, there are \(m\) clauses, and every one of the \(n\) variables, appears in at most \(2^{k/50}\) clauses.

Consider a random assignment, and let \(\Event _i\) be the event that the \(i\)th clause was not satisfied. We know that \(p = \Prob {\Event _i} = 2^{-k}\), and furthermore, \(\Event _i\) depends on at most \(d = k 2^{k/50}\) other events. Since \(e p(d+1) = e \pth {k\cdot 2^{k/50} + 1}2^{-k}<1\), for \(k\geq 4\), we conclude that by Corollary 51.1.5, that

\(\seteqnumber{0}{51.}{1}\)

\begin{align*} \Prob { \Bigl . I \text { have a satisfying assignment}}=\Prob { \Bigl . \cup _{i} \Event _i} > 0. \end{align*}

51.2.1 An efficient algorithm

The above just proves that a satisfying assignment exists. We next show a polynomial algorithm (in \(m\)) for the computation of such an assignment (the algorithm will not be polynomial in \(k\)).

Let \(\Graph \) be the dependency graph for \(I\), where the vertices are the clauses of \(I\), and two clauses are connected if they share a variable. In the first stage of the algorithm, we assign values to the variables one by one, in an arbitrary order. In the beginning of this process all variables are unspecified, at each step, we randomly assign a variable either \(0\) or \(1\) with equal probability.

  • Definition 51.2.1. A clause \(\Event _i\) is dangerous if both the following conditions hold:

    • (i) \(k/2\) literals of \(\Event _i\) have been fixed.

    • (ii) \(\Event _i\) is still unsatisfied.

After assigning each value, we discover all the dangerous clauses, and we defer (“freeze”) all the unassigned variables participating in such a clause. We continue in this fashion till all the unspecified variables are frozen. This completes the first stage of the algorithm.

At the second stage of the algorithm, we will compute a satisfying assignment to the variables using brute force. This would be done by taking the surviving formula \(I'\) and breaking it into fragments, so that each fragment does not share any variable with any other fragment (naively, it might be that all of \(I'\) is one fragment). We can find a satisfying assignment to each fragment separately, and if each such fragment is “small” the resulting algorithm would be “fast”.

We need to show that \(I'\) has a satisfying assignment and that the fragments are indeed small.

51.2.1.1 Analysis

A clause had survived if it is not satisfied by the variables fixed in the first stage. Note, that a clause that survived must have a dangerous clause as a neighbor in the dependency graph \(\Graph \). Not that \(I'\), the instance remaining from \(I\) after the first stage, has at least \(k/2\) unspecified variables in each clause. Furthermore, every clause of \(I'\) has at most \(d=k2^{k/50}\) neighbors in \(\Graph '\), where \(\Graph '\) is the dependency graph for \(I'\). It follows, that again, we can apply Lovász local lemma to conclude that \(I'\) has a satisfying assignment.

  • Definition 51.2.2. Two connected graphs \(\Graph _1=(V_1, E_1)\) and \(\Graph _2=(V_2, E_2)\), where \(V_1, V_2 \subseteq \brc {1,\ldots , n}\) are unique if \(V_1 \ne V_2\).

  • Lemma 51.2.3. Let \(\Graph \) be a graph with degree at most \(d\) and with \(n\) vertices. Then, the number of unique subgraphs of \(\Graph \) having \(r\) vertices is at most \(nd^{2r}\).

  • Proof: Consider a unique subgraph \(\widehat {G}\) of \(\Graph \), which by definition is connected. Let \(H\) be a connected subtree of \(\Graph \) spanning \(\widehat {G}\). Duplicate every edge of \(H\), and let \(H'\) denote the resulting graph. Clearly, \(H'\) is Eulerian, and as such posses a Eulerian path \(\pi \) of length at most \(2(r-1)\), which can be specified, by picking a starting vertex \(v\), and writing down for the \(i\)-th vertex of \(\pi \) which of the \(d\) possible neighbors, is the next vertex in \(\pi \). Thus, there are st most \(nd^{2(r-1)}\) ways of specifying \(\pi \), and thus, there are at most \(nd^{2(r-1)}\) unique subgraphs in \(\Graph \) of size \(r\).

  • Lemma 51.2.4. With probability \(1- o(1)\), all connected components of \(\Graph '\) have size at most \(O( \log {m})\), where \(\Graph '\) denote the dependency graph for \(I'\).

  • Proof: Let \(\Graph _4\) be a graph formed from \(\Graph \) by connecting any pair of vertices of \(\Graph \) of distance exactly \(4\) from each other. The degree of a vertex of \(\Graph _4\) is at most \(O(d^4)\).

    Let \(U\) be a set of \(r\) vertices of \(\Graph \), such that every pair is in distance at least \(4\) from each other in \(\Graph \). We are interested in bounding the probability that all the clauses of \(U\) survive the first stage.

    The probability of a clause to be dangerous is at most \(2^{-k/2}\), as we assign (random) values to half of the variables of this clause. Now, a clause survive only if it is dangerous or one of its neighbors is dangerous. Thus, the probability that a clause survive is bounded by \(2^{-k/2}(d+1)\).

    Furthermore, the survival of two clauses \(\Event _i\) and \(\Event _j\) in \(U\) is an independent event, as no neighbor of \(\Event _i\) shares a variable with a neighbor of \(\Event _j\) (because of the distance \(4\) requirement). We conclude, that the probability that all the vertices of \(U\) to appear in \(\Graph '\) is bounded by

    \(\seteqnumber{0}{51.}{1}\)

    \begin{align*} \pth {2^{-k/2}(d+1)}^{r}. \end{align*}

    In fact, we are interested in sets \(U\) that induce a connected subgraphs of \(\Graph _4\). The number of unique such sets of size \(r\) is bounded by the number of unique subgraphs of \(\Graph _4\) of size \(r\), which is bounded by \(m d^{8r}\), by Lemma 51.2.3. Thus, the probability of any connected subgraph of \(\Graph _4\) of size \(r = \log _2 {m}\) to survive in \(\Graph '\) is smaller than

    \(\seteqnumber{0}{51.}{1}\)

    \begin{align*} m d^{8r} \pth {2^{-k/2}(d+1)}^{r}=m \pth {k2^{k/50}}^{8r } \pth {2^{-k/2}(k2^{k/50}+1)}^{r}\leq m 2^{kr/5} \cdot 2^{-kr/4}=m 2^{-kr/20}=o(1), \end{align*} since \(k \geq 50\). (Here, a subgraph survive of \(\Graph _4\) survive, if all its vertices appear in \(\Graph '\).) Note, however, that if a connected component of \(\Graph '\) has more than \(L\) vertices, than there must be a connected component having \(L/d^3\) vertices in \(\Graph _4\) that had survived in \(\Graph '\). We conclude, that with probability \(o(1)\), no connected component of \(\Graph '\) has more than \(O(d^3 \log {m}) = O(\log {m})\) vertices (note, that we consider \(k\) to be a constant, and thus, also \(d\)).

Thus, after the first stage, we are left with fragments of \((k/2)\)-SAT, where every fragment has size at most \(O(\log {m})\), and thus having at most \(O(\log {m})\) variables. Thus, we can by brute force find the satisfying assignment to each such fragment in time polynomial in \(m\). We conclude:

  • Theorem 51.2.5. The above algorithm finds a satisfying truth assignment for any instance of \(k\)-SAT containing \(m\) clauses, which each variable is contained in at most \(2^{k/50}\) clauses, in expected time polynomial in \(m\).

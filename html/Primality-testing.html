Introduction – how to read this write-up

In this note, we present a simple randomized algorithms for primality testing. The challenge is that it requires a non-trivial amount of number theory, which is not the purpose of this course. Nevertheless, this note is more or less self contained, and all necessary background is provided (assuming some basic mathematical familiarity with groups, fields and modulo arithmetic). It is however not really necessary to understand all the number theory material needed, and the reader can take it as given. In particular, I recommend to read the number theory background part without reading all of the proofs (at least on first reading). Naturally, a complete and total understanding of this material one needs to read everything carefully.

The description of the primality testing algorithm in this write-up is not minimal – there are shorter descriptions out there. However, it is modular – assuming the number theory machinery used is correct, the algorithm description is relatively straightforward.

54.1 Number theory background

54.1.1 Modulo arithmetic
54.1.1.1 Prime and coprime

For integer numbers \(x\) and \(y\), let \(x \divides y\) denotes that \(x\) divides \(y\). The greatest common divisor (gcd) of two numbers \(x\) and \(y\), denoted by \(\gcd (x,y)\), is the largest integer that divides both \(x\) and \(y\). The least common multiple (lcm) of \(x\) and \(y\), denoted by \(\lcm (x,y) = xy / \gcd (x,y)\), is the smallest integer \(\alpha \), such that \(x \divides \alpha \) and \(y \divides \alpha \). An integer number \(p > 0\) is prime if it is divisible only by \(1\) and itself (we will consider \(1\) not to be prime).

Some standard definitions:

\(\seteqnumber{0}{54.}{0}\)

\begin{align*} x,y \text { are \emphOnly {coprime}} \qquad &\iff \qquad \gcd (x,y)=1,\\ \text {\emphOnly {quotient} of } x/y \qquad &\iff \qquad x \bdiv y = \floor {x/y},\\ \text {\emphOnly {remainder} of }x /y \qquad &\iff \qquad x \bmod y = x - y \floor {x/y}. \end{align*} The remainder \(x \bmod y\) is sometimes referred to as residue.

54.1.1.2 Computing \(\gcd \)

Computing the \(\gcd \) of two numbers is a classical algorithm (see Figure 54.1) – proving that it indeed returns the right result follows by an easy induction. It is easy to verify that if the input is made out of \(\log n\) bits, then this algorithm takes \(O\pth { \poly ( \log n )}\) time (i.e., it is polynomial in the input size). Indeed, doing basic operations on numbers (i.e., multiplication, division, addition, subtraction, etc) with total of \(\ell \) bits takes \(O\pth { \ell ^2 }\) time (naively – faster algorithms are known).

  • Exercise 54.1.1. Show that \(\gcd (F_n, F_{n-1}) =1\), where \(F_i\) is the \(i\)th Fibonacci number. Argue that for two consecutive Fibonacci numbers, EuclidGCD(\(F_n,F_{n-1}\)) takes \(O(n)\) time, if every operation takes \(O(1)\) time.

  • Lemma 54.1.2. For all \(\alpha , \beta > 0\) integers, there are integer numbers \(x\) and \(y\), such that \(\gcd (\alpha ,\beta ) = \alpha x + \beta y\), which can be computed in polynomial time; that is, \(O\pth { \biggl . \poly \pth { \Bigl . \log \alpha + \log \beta }}\).

  • Proof: If \(\alpha = \beta \) then the claim trivially holds. Otherwise, assume that \(\alpha > \beta \) (otherwise, swap them), and observe that \(\gcd (\alpha , \beta ) = \gcd (\alpha \bmod \beta , \beta )\). In particular, by induction, there are integers \(x', y'\), such that \(\gcd (\alpha \bmod \beta , \beta ) = x'(\alpha \bmod \beta ) + y' \beta \). However, \(\tau = \alpha \bmod \beta = \alpha - \beta \floor { \alpha / \beta }\). As such, we have

    \(\seteqnumber{0}{54.}{0}\)

    \begin{align*} \gcd (\alpha , \beta )&=\gcd (\alpha \bmod \beta , \beta )=x'\pth []{ \Bigl . \alpha - \beta \floor { \alpha / \beta } } + y'\beta \\ &=x'\alpha + \pth []{y' - \beta \floor { \alpha / \beta } } \beta , \end{align*} as claimed. The running time follows immediately by modifying EuclidGCD to compute these numbers.

We use \(\alpha \equiv \beta \pmod {n}\) or \(\alpha \equiv _n \beta \) to denote that \(\alpha \) and \(\beta \) are congruent modulo \(n\); that is \(\alpha \bmod n = \beta \bmod n\). Or put differently, we have \(n \divides \pth []{\alpha - \beta }\). The set \(\ZZ _n = \brc {0, \ldots , n-1 \Bigl . }\) form a group under addition modulo \(n\) (see Definition 54.1.9p(page for theorem 54.1.9) for a formal definition of a group). The more interesting creature is \(\ZZ _n^* = \brc {x \sep { x \in \brc {1,\ldots , n}, x > 0, \text { and } \gcd (x, n) =1}}\), which is a group modulo \(n\) under multiplication.

  • Remark 54.1.3. Observe that \(\ZZ _1^* = \brc {1}\), while for \(n >1\), \(\ZZ _n^*\) does not contain \(n\).

  • Lemma 54.1.4. For any element \(\alpha \in \ZZ _n^*\), there exists a unique inverse element \(\beta = \alpha ^{-1} \in \ZZ _n^*\) such that \(\alpha * \beta \equiv _n 1\). Furthermore, the inverse can be computed in polynomial time54.1.

54.1 Again, as is everywhere in this chapter, the polynomial time is in the number of bits needed to specify the input.

  • Proof: Since \(\alpha \in \ZZ _n^*\), we have that \(\gcd (\alpha , n) =1\). As such,
    by Lemma 54.1.2, there exists \(x\) and \(y\) integers, such that \(x \alpha + y n =1\). That is \(x \alpha \equiv 1 \pmod {n}\), and clearly \(\beta := x \bmod n\) is the desired inverse, and it can be computed in polynomial time by Lemma 54.1.2.

    As for uniqueness, assume that there are two inverses \(\beta ,\beta '\) to \(\alpha < n\), such that \(\beta < \beta ' < n\). But then \(\beta \alpha \equiv _n \beta ' \alpha \equiv _n 1\), which implies that \(n \divides (\beta ' -\beta ) \alpha \), which implies that \(n \divides \beta ' - \beta \), which is impossible as \(0 < \beta ' - \beta < n\).

It is now straightforward, but somewhat tedious, to verify the following (the interested reader that had not encountered this stuff before can spend some time proving this).

  • Lemma 54.1.5. The set \(\ZZ _n\) under the \(+\) operation modulo \(n\) is a group, as is \(\ZZ _n^*\) under multiplication modulo \(n\). More importantly, for a prime number \(p\), \(\ZZ _p\) forms a field with the \(+,*\) operations modulo \(p\) (see Definition 54.1.17p(page for theorem 54.1.17) ).

54.1.1.3 The Chinese remainder theorem

  • Theorem 54.1.6 (Chinese remainder theorem). Let \(n_1, \ldots , n_k\) be coprime numbers, and let \(n = n_1 n_2 \cdots n_k\). For any residues \(r_1 \in \ZZ _{n_1}, \ldots , r_k \in \ZZ _{n_k}\), there is a unique \(r \in \ZZ _n\), which can be computed in polynomial time, such that \(r \equiv r_i \pmod {n_i}\), for \(i=1, \ldots , k\).

  • Proof: By the coprime property of the \(n_i\)s it follows that \(\gcd (n_i, n/n_i) = 1\). As such, \(n/n_i \in \ZZ _{n_i}^*\), and it has a unique inverse \(m_i\) modulo \(n_i\); that is \((n/n_i) m_i \equiv 1 \pmod {n_i}\). So set \(r = \sum _i r_i m_i n/n_i\). Observe that for \(i \neq j\), we have that \(n_j \divides \pth []{n/n_i}\), and as such \(r_i m_i n/n_i \pmod {n_j} \equiv 0 \pmod {n_j}\). As such, we have

    \(\seteqnumber{0}{54.}{0}\)

    \begin{align*} r \bmod {n_j}&=\pth []{\sum _i \pth { r_i m_i \frac {n}{n_i} \bmod {n_j}}} \bmod {n_j}\\ &=\pth []{r_j m_j \frac {n}{n_j} \bmod {n_j}} \bmod {n_j}=r_j * 1 \bmod {n_j}=r_j. \end{align*} As for uniqueness, if there is another such number \(r'\), such that \(r < r' < n\), then \(r' - r \pmod {n_i} = 0\) implying that \(n_i \divides r' -r\), for all \(i\). Since all the \(n_i\)s are coprime, this implies that \(n \divides r' -r\), which is of course impossible.

  • Lemma 54.1.7 (Fast exponentiation). Given numbers \(b,c, n\), one can compute \(b^c \bmod n\) in polynomial time.

  • Proof: The key property we need is that

    \(\seteqnumber{0}{54.}{0}\)

    \begin{align*} x y \bmod n = \pth []{\Bigl . (x\bmod n) \, (y \bmod n)} \bmod n. \end{align*} Now, if \(c\) is even, then we can compute

    \(\seteqnumber{0}{54.}{0}\)

    \begin{align*} b^c \bmod n=\pth []{b^{c/2}}^2 \bmod n=\pth []{b^{c/2} \bmod n }^2 \bmod n. \end{align*} Similarly, if \(c\) is odd, we have

    \(\seteqnumber{0}{54.}{0}\)

    \begin{align*} b^c \bmod n&=\pth []{b \bmod n} \pth []{b^{(c-1)/2}}^2 \bmod n\\ &=\pth []{b \bmod n} \pth []{b^{(c-1)/2} \bmod n }^2 \bmod n. \end{align*} Namely, computing \(b^c \bmod n\) can be reduced to recursively computing \(b^{\floor {c/2}} \bmod n\), and a constant number of operations (on numbers that are smaller than \(n\)). Clearly, the depth of the recursion is \(O( \log c)\).

54.1.1.4 Euler totient function


The Euler totient function \(\phi (n) = \cardin {\ZZ _n^*}\) is the number of positive integer numbers that at most \(n\) and are coprime with \(n\). If \(n\) is prime then \(\phi (n)=n-1\).

  • Lemma 54.1.8. Let \(n=p_1^{k_1} \cdots p_t^{k_t}\), where the \(p_i\)s are prime numbers and the \(k_i\)s are positive integers (this is the prime factorization of \(n\)). Then \(\ds \phi (n) = \prod _{i=1}^t p_{i}^{k_i -1} (p_{i} -1).\)and this quantity can be computed in polynomial time if the factorization is given.

  • Proof: Observe that \(\phi (1) = 1\) (see Remark 54.1.3), and for a prime number \(p\), we have that \(\phi (p) = p-1\). Now, for \(k > 1\), and \(p\) prime we have that \(\phi (p^k) = p^{k-1} (p-1)\), as a number \(x \leq p^k\) is coprime with \(p^k\), if and only if \(x \bmod p \neq 0\), and \((p-1)/p\) fraction of the numbers in this range have this property.

    Now, if \(n\) and \(m\) are relative primes, then \(\gcd (x,nm) =1\) \(\iff \) \(\gcd (x,n) =1\) and \(\gcd (x,m)=1\). In particular, there are \(\phi (n)\phi (m)\) pairs \((\alpha , \beta )\in \ZZ _n^* \times \ZZ _m^*\), such that \(\gcd (\alpha , n )=1\) and \(\gcd (\beta , m )=1\). By the Chinese remainder theorem (Theorem 54.1.6), each such pair represents a unique number in the range \(1,\ldots , nm\), as desired.

    Now, the claim follows by easy induction on the prime factorization of the given number.

54.1.2 Structure of the modulo group \(\ZZ _n\)
54.1.2.1 Some basic group theory

  • Definition 54.1.9. A group is a set, \(\Group \), together with an operation \(\gOp \) that combines any two elements \(a\) and \(b\) to form another element, denoted \(a \gOp b\) or \(ab\). To qualify as a group, the set and operation, \((\Graph , \gOp )\), must satisfy the following:

    • (A) (CLOSURE) For all \(a, b \in \Group \), the result of the operation, \(a \gOp b \in \Group \).

    • (B) (ASSOCIATIVITY) For all \(a, b, c \in \Group \), we have \((a \gOp b) \gOp c = a \gOp (b \gOp c)\).

    • (C) (IDENTITY ELEMENT) There exists an element \(\gIdent \in \Group \), called the identity element, such that for every element \(a \in \Group \), the equation \(\gIdent \gOp a = a \gOp \gIdent = a\) holds.

    • (D) (INVERSE ELEMENT) For each \(a \in \Group \), there exists an element \(b \in \Group \) such that \(a \gOp b = b \gOp a = \gIdent \).

    A group is abelian (aka, commutative group) if for all \(a,b \in \Group \), we have that \(a \gOp b = b \gOp a\).

In the following we restrict our attention to abelian groups since it makes the discussion somewhat simpler. In particular, some of the claims below holds even without the restriction to abelian groups.

The identity element is unique. Indeed, if both \(f, g \in \Group \) are identity elements, then \(f = f \gOp g = g\). Similarly, for every element \(x \in \Group \) there exists a unique inverse \(y = x^{-1}\). Indeed, if there was another inverse \(z\), then \(y = y \gOp \gIdent = y \gOp (x\gOp z) = (y\gOp x)\gOp z = \gIdent \gOp z = z\).

54.1.2.2 Subgroups

For a group \(\Group \), a subset \(\GroupA \subseteq \Group \) that is also a group (under the same operation) is a subgroup.

For \(x, y \in \Group \), let us define \(x \sim y\) if \(x/y \in \GroupA \). Here \(x/y = x y^{-1}\) and \(y^{-1}\) is the inverse of \(y\) in \(\Group \). Observe that \(\pth {y/x}\pth []{x/y} = \pth []{yx^{-1}} \pth []{xy^{-1}} = \gIdent .\)That is \(y/x\) is the inverse of \(x/y\), and it is in \(\GroupA \). But that implies that \(x \sim y \implies y \sim x\). Now, if \(x \sim y\) and \(y \sim z\), then \(x/y, y/z \in \GroupA \). But then \(x/y \gOp y/z \in \GroupA \), and furthermore \(x/y \gOp y/z = x y^{-1} y z^{-1} = x z^{-1} = x/z\). that is \(x \sim z\). Together, this implies that \(\sim \) is an equivalence relationship.

Furthermore, observe that if \(x/y = x/z\) then \(y^{-1} = x^{-1} (x/y) = x^{-1} (x/z) = z^{-1},\)that is \(y=z\). In particular, the equivalence class of \(x \in \Group \), is \([x] = \brc {z \in \Group \sep {x \sim z}}\). Observe that if \(x \in \GroupA \) then \(\gIdent / x = \gIdent x^{-1} = x^{-1} \in \GroupA \), and thus \(\gIdent \sim x\). That is \(\GroupA = [x]\). The following is now easy.

  • Lemma 54.1.10. Let \(\Group \) be an abelian group, and let \(\GroupA \subseteq \Group \) be a subgroup. Consider the set \(\Group / \GroupA = \brc { [x] \sep { x \in \Group }}\). We claim that \(\cardin {\bigl . [x]} = \cardin {\bigl . [y]}\) for any \(x,y \in \Group \). Furthermore \(\Group / \GroupA \) is a group (that is, the quotient group), with \([x] \gOp [y] = [x \gOp y]\).

  • Proof: Pick an element \(\alpha \in [x]\), and \(\beta \in [y]\), and consider the mapping \(f(x) = x \alpha ^{-1} \beta \). We claim that \(f\) is one to one and onto from \([x]\) to \([y]\). For any \(\gamma \in [x]\), we have that \(\gamma \alpha ^{-1} =\gamma /\alpha \in \GroupA \) As such, \(f(\gamma ) = \gamma \alpha ^{-1} \beta \in [\beta ] = [y]\). Now, for any \(\gamma , \gamma ' \in [x]\) such that \(\gamma \neq \gamma '\), we have that if \(f(\gamma ) =\gamma \alpha ^{-1} \beta = \gamma '\alpha ^{-1} \beta = f(\gamma ')\), then by multiplying by \(\beta ^{-1} \alpha \), we have that \(\gamma = \gamma '\). That is, \(f\) is one to one, implying that \(\cardin {\bigl . [x]} = \cardin {\bigl . [y]}\).

    The second claim follows by careful but tediously checking that the conditions in the definition of a group holds.

  • Lemma 54.1.11. For a finite abelian group \(\Group \) and a subgroup \(\GroupA \subseteq \Group \), we have that \(\cardin {\GroupA }\) divides \(\cardin {\Group }\).

  • Proof: By Lemma 54.1.10, we have that \(\cardin {\Group } = \cardin {\GroupA } \cdot \cardin {\Group / \GroupA }\), as \(\GroupA = [\gIdent ]\).

54.1.2.3 Cyclic groups

  • Lemma 54.1.12. For a finite group \(\Group \), and any element \(g\in \Group \), the set \(\permut {g} = \brc { g^i \sep { i\geq 0}}\) is a group.

  • Proof: Since \(\Group \) is finite, there are integers \(i > j\geq 1\), such that \(i \neq j\) and \(g^i = g^j\), but then \(g^j\gOp g^{i-j} =g^i = g^j\). That is \(g^{i-j} = \gIdent \) and, by definition, we have \(g^{i-j} \in \permut {g}\). It is now straightforward to verify that the other properties of a group hold for \(\permut {g}\).

In particular, for an element \(g \in \Group \), we define its order as \(\ordX {g} = \cardin {\bigl . \permut {g}}\), which clearly is the minimum positive integer \(m\), such that \(g^m = \gIdent \). Indeed, for \(j > m\), observe that \(g^j = g^{j \bmod m} \in X = \brc { \gIdent , g, g^2, \ldots , g^{m-1}}\), which implies that \(\permut {g} = X\).

A group \(\Group \) is cyclic, if there is an element \(g \in \Group \), such that \(\permut {g} = \Group \). In such a case \(g\) is a generator of \(\Group \).

  • Lemma 54.1.13. For any finite abelian group \(\Group \), and any \(g \in \Group \), we have that \(\ordX {g}\) divides \(\cardin {\Group }\), and \(g^{\cardin {\Group }} = \gIdent \).

  • Proof: By Lemma 54.1.12, the set \(\permut {g}\) is a subgroup of \(\Group \). By Lemma 54.1.11, we have that \(\ordX {g} = \cardin {\bigl . \permut {g}} \divides \cardin {\Group }\). As such, \(g^{\cardin {\Group }}=\pth []{g^{\ordX []{g}}}^{\cardin {\Group } / \ordX []{ g}}=\pth []{\Bigl .\, \gIdent \,}^{\cardin {\Group } / \ordX []{ g}}=\gIdent .\)

54.1.2.4 Modulo group

  • Lemma 54.1.14. For any integer \(n\), consider the additive group \(\ZZ _n\). Then, for any \(x \in \ZZ _n\), we have that \(x \cdot \ordX {x} = \lcm (x,n)\). In particular, \(\ds \ordX {x} = \frac {\lcm (n,x)}{x} = \frac {n}{\gcd (n,x)}\). If \(n\) is prime, and \(x \neq 0\) then \(\ordX {x} = \cardin {\ZZ _n} = n\), and \(\ZZ _n\) is a cyclic group.

  • Proof: We are working modulo \(n\) here under additions, and the identity element is \(0\). As such, \(x \cdot \ordX {x} \equiv _n 0\), which implies that \(n \divides x \ordX {x}\). By definition, \(\ordX {x}\) is the minimal number that has this property, implying that \(\ds \ordX {x} = \frac {\lcm (n,x)}{x}\). Now, \(\lcm (n,x) = nx / \gcd (n,x)\). The second claim is now easy.

  • Theorem 54.1.15. (Euler’s theorem) For all \(n\) and \(x \in \ZZ _n^*\), we have \(x^{\phi (n)} \equiv 1 \pmod {n}.\)

    (Fermat’s theorem) If \(p\) is a prime then \(\forall x \in \ZZ _p^* \quad x^{p-1} \equiv 1 \pmod {p}.\)

  • Proof: The group \(\ZZ _n^*\) is abelian and has \(\phi (n)\) elements, with \(1\) being the identity element (duh!). As such, by Lemma 54.1.13, we have that \(x^{\phi (n)} = x^{\cardin {\ZZ _n^*}} \equiv 1 \pmod {n}\), as claimed.

    The second claim follows by setting \(n=p\), and recalling that \(\phi (p) = p-1\), if \(p\) is a prime.

One might be tempted to think that Lemma 54.1.14 implies that if \(p\) is a prime then \(\ZZ _p^*\) is a cyclic group, but this does not follow, as the cardinality of \(\ZZ _p^*\) is \(\phi (p) = p-1\), which is not a prime number (for \(p >2\)). To prove that \(\ZZ _p^*\) is cyclic, let us go back shortly to the totient function.

  • Lemma 54.1.16. For any \(n > 0\), we have \(\sum _{d \divides n} \phi (d) =n\).

  • Proof: For any \(g > 0\), let \(V_g = \brc { x \sep { x \in \brc {1, \ldots , n} \text { and } \gcd (x, n) = g}}\). Now, \(x \in V_g\) \(\iff \) \(\gcd (x,n) = g\) \(\iff \) \(\gcd (x/g, n/g) = 1\) \(\iff \) \(x/g \in \ZZ _{n/g}^*\). Since \(V_1, V_2, \ldots , V_n\) form a partition of \(\brc {1,\ldots , n}\), it follows that \(\ds \Biggl . n=\sum _g \cardin {V_g}=\sum _{g \divides n} \cardin {\ZZ _{n/g}^*}=\sum _{g \divides n} \phi (n/g)=\sum _{d \divides n} \phi (d).\)

54.1.2.5 Fields

  • Definition 54.1.17. A field is an algebraic structure \(\permut {\Field , +, *, 0, 1}\) consisting of two abelian groups:

    • (A) \(\Field \) under \(+\), with \(0\) being the identity element.

    • (B) \(\Field \setminus \brc {0}\) under \(*\), with \(1\) as the identity element (here \(0 \neq 1\)).

    Also, the following property (distributivity of multiplication over addition) holds:

    \(\seteqnumber{0}{54.}{0}\)

    \begin{align*} \forall a,b,c \in \Field \qquad a * (b + c) = (a*b) + (a*c). \end{align*}

We need the following: A polynomial \(p\) of degree \(k\) over a field \(\Field \) has at most \(k\) roots. indeed, if \(p\) has the root \(\alpha \) then it can be written as \(p(x) = (x-\alpha ) q(x)\), where \(q(x)\) is a polynomial of one degree lower. To see this, we divide \(p(x)\) by the polynomial \((x-\alpha )\), and observe that \(p(x) = (x-\alpha ) q(x) + \beta \), but clearly \(\beta = 0\) since \(p(\alpha ) = 0\). As such, if \(p\) had \(t\) roots \(\alpha _1,\ldots , \alpha _t\), then \(p(x) = q(x) \prod _{i=1}^t \pth []{x-\alpha _i}\), which implies that \(p\) would have degree at least \(t\).

54.1.2.6 \(\ZZ _p^*\) is cyclic for prime numbers

For a prime number \(p\), the group \(\ZZ _p^*\) has size \(\phi (p) = p-1\), which is not a prime number for \(p>2\). As such, Lemma 54.1.13 does not imply that there must be an element in \(\ZZ _p^*\) that has order \(p-1\) (and thus \(\ZZ _p^*\) is cyclic). Instead, our argument is going to be more involved and less direct.

  • Lemma 54.1.18. For \(k < n\), let \(R_k = \brc { x \in \ZZ _p^* \sep { \ordX {x} = k}}\)be the set of all numbers in \(\ZZ _p^*\) that are of order \(k\). We have that \(\cardin {R_k} \leq \phi \pth {k}\).

  • Proof: Clearly, all the elements of \(R_k\) are roots of the polynomial \(x^k - 1 = 0 \pmod {n}\). By the above, this polynomial has at most \(k\) roots. Now, if \(R_k\) is not empty, then it contains an element \(x \in R_k\) of order \(k\), which implies that for all \(i < j \leq k\), we have that \(x^i \nequiv x^j \pmod {n}\), as the order of \(x\) is the size of \(\permut {x}\), and the minimum \(k\) such that \(x^k \equiv 1 \pmod {n}\). In particular, we have that \(R_k \subseteq \permut {x}\), as for \(y = x^j\), we have that \(y^k \equiv _n x^{jk} \equiv _n 1^j \equiv _n 1\).

    Observe that for \(y = x^i\), if \(g= \gcd (k,i)> 1\), then \(y^{k/g} \equiv _n x^{i(k/g)} \equiv _n x^{\lcm (i,k)} \equiv _n 1\); that is, \(\ordX {y} \leq k/g < k\), and \(y \notin R_k\). As such, \(R_k\) contains only elements of \(x^i\) such that \(\gcd (i,k)=1\). That is \(R_k \subseteq \ZZ _k^*\). The claim now readily follows as \(\cardin {\ZZ _k^*} = \phi (k)\).

  • Lemma 54.1.19. For any prime \(p\), the group \(\ZZ _p^*\) is cyclic.

  • Proof: For \(p=2\) the claim trivially holds, so assume \(p >2\). If the set \(R_{p-1}\), from Lemma 54.1.18, is not empty, then there is \(g \in R_{p-1}\), it has order \(p-1\), and it is a generator of \(\ZZ _p^*\), as \(\cardin {\ZZ _p^*} = p-1\), implying that \(\ZZ _p^* = \permut {g}\) and this group is cyclic.

    Now, by Lemma 54.1.13, we have that for any \(y \in \ZZ _p^*\), we have that \(\ordX {y} \divides p-1 =\cardin {\ZZ _p^*}\). This implies that \(R_k\) is empty if \(k\) does not divides \(p-1\). On the other hand, \(R_1, \ldots , R_{p-1}\) form a partition of \(\ZZ _p^*\). As such, we have that

    \(\seteqnumber{0}{54.}{0}\)

    \begin{align*} p-1 = \cardin {\ZZ _p^*}=\sum _{k \divides p-1} \cardin {R_k}\leq \sum _{k \divides p-1} \phi (k)=p-1, \end{align*} by Lemma 54.1.18 and Lemma 54.1.16p(page for theorem 54.1.16) , implying that the inequality in the above display is equality, and for all \(k \divides p-1\), we have that \(\cardin {R_k} = \phi (k)\). In particular, \(\cardin {R_{p-1}} = \phi (p-1) > 0\), and by the above the claim follows.

54.1.2.7 \(\ZZ _n^*\) is cyclic for powers of a prime

  • Lemma 54.1.20. Consider any odd prime \(p\), and any integer \(c \geq 1\), then the group \(\ZZ _n^*\) is cyclic, where \(n=p^c\).

  • Proof: Let \(g\) be a generator of \(\ZZ _p^*\). Observe that \(g^{p-1} \equiv 1 \mod p\). The number \(g <p\), and as such \(p\) does not divide \(g\), and also \(p\) does not divide \(g^{p-2}\), and also \(p\) does not divide \(p-1\). As such, \(p^2\) does not divide \(\Delta = (p-1)g^{p-2}p\); that is, \(\Delta \nequiv 0 \pmod {p^2}\). As such, we have that

    \(\seteqnumber{0}{54.}{0}\)

    \begin{align*} (g+p)^{p-1} \equiv g^{p-1} + \binom {p-1}{1} g^{p-2} p \equiv g^{p-1} + \Delta \nequiv g^{p-1} \pmod {p^2}\\ \implies \quad (g+p)^{p-1} \nequiv 1 \pmod {p^2}\quad \text {or}\quad g^{p-1} \nequiv 1 \pmod {p^2}. \end{align*} Renaming \(g+p\) to be \(g\), if necessary, we have that \(g^{p-1} \nequiv 1 \pmod {p^2}\), but by Theorem 54.1.15p(page for theorem 54.1.15) , \(g^{p-1} \equiv 1 \pmod {p}\). As such, \(g^{p-1} = 1 +\beta p\), where \(p\) does not divide \(\beta \). Now, we have

    \(\seteqnumber{0}{54.}{0}\)

    \begin{align*} g^{p(p-1)} = (1+\beta p)^p = 1 + \binom {p}{1} \beta p + \beta p^3 \text {<whatever>}=1 + \gamma _1 p^2, \end{align*} where \(\gamma _1\) is an integer (the \(p^3\) is not a typo – the binomial coefficient contributes at least one factor of \(p\) – here we are using that \(p >2\)). In particular, as \(p\) does not divides \(\beta \), it follows that \(p\) does not divides \(\gamma _1\) either. Let us apply this argumentation again to

    \(\seteqnumber{0}{54.}{0}\)

    \begin{align*} g^{p^2(p-1)}=\pth []{1+\gamma _1 p^2}^p = 1 +\gamma _1 p^3 + p^4 \text {<whatever>}=1 + \gamma _2 p^3, \end{align*} where again \(p\) does not divides \(\gamma _2\). Repeating this argument, for \(i=1,\ldots , c-2\), we have

    \(\seteqnumber{0}{54.}{0}\)

    \begin{align*} \alpha _i&=g^{p^i(p-1)}=\pth []{g^{p^{i-1}(p-1)}}^p=\pth []{1+\gamma _{i-1} p^{i}}^p\\ &=1 + \gamma _{i-1} p^{i+1} + p^{i+2} \text {<whatever>}=1 + \gamma _i p^{i+1}, \end{align*} where \(p\) does not divides \(\gamma _i\). In particular, this implies that \(\ds \alpha _{c-2} =1 + \gamma _{c-2} p^{c-1}\)and \(p\) does not divides \(\gamma _{c-2}\). This in turn implies that \(\alpha _{c-2} \nequiv 1 \pmod {p^{c}}\).

    Now, the order of \(g\) in \(\ZZ _n\), denoted by \(k\), must divide \(\cardin {\ZZ _n^*}\)
    by Lemma 54.1.13p(page for theorem 54.1.13) . Now \(\cardin {\ZZ _n^*} = \phi (n) = p^{c-1}(p-1)\), see Lemma 54.1.8p(page for theorem 54.1.8) . So, \(k \divides p^{c-1}(p-1)\). Also, \(\alpha _{c-2} \nequiv 1 \pmod {p^{c}}\). implies that \(k\) does not divides \(p^{c-2}(p-1)\). It follows that \(p^{c-1} \divides k\). So, let us write \(k = p^{c-1} k'\), where \(k' \leq (p-1)\). This, by definition, implies that \(g^{k} \equiv 1 \pmod {p^c}\). Now, \(g^p \equiv g \pmod {p}\), because \(g\) is a generator of \(\ZZ _p^*\). As such, we have that

    \(\seteqnumber{0}{54.}{0}\)

    \begin{align*} g^{k}&\equiv _pg^{p^\delta k'} \equiv _p\pth []{g^p}^{p^{\delta -1} k'} \equiv _p\pth []{g}^{p^{\delta -1} k'} \\ &\equiv _p \ldots \equiv _p\pth []{g}^{k'} \equiv _p \pth []{g^k \bmod {p^c}} \bmod {p} \equiv _p 1. \end{align*} Namely, \(g^{k'} \equiv 1 \pmod {p}\), which implies, as \(g\) as a generator of \(\ZZ _p^*\), that either \(k'=1\) or \(k'=p-1\). The case \(k'=1\) is impossible, as this implies that \(g =1\), and it can not be the generator of \(\ZZ _p^*\). We conclude that \(k = p^{c-1}(p-1)\); that is, \(\ZZ _n^*\) is cyclic.

54.1.3 Quadratic residues
54.1.3.1 Quadratic residue

  • Definition 54.1.21. An integer \(\alpha \) is a quadratic residue modulo a positive integer \(n\), if \(\gcd (\alpha , n)=1\) and for some integer \(\beta \), we have \(\alpha \equiv \beta ^2 \pmod {n}\).

  • Theorem 54.1.22 (Euler’s criterion). Let \(p\) be an odd prime, and \(\alpha \in \ZZ _p^*\). We have that

    • (A) \(\alpha ^{(p-1)/2} \equiv _p \pm 1\).

    • (B) If \(\alpha \) is a quadratic residue, then \(\alpha ^{(p-1)/2} \equiv _p 1\).

    • (C) If \(\alpha \) is not a quadratic residue, then \(\alpha ^{(p-1)/2} \equiv _p -1\).

  • Proof: (A) Let \(\gamma = \alpha ^{(p-1)/2}\), and observe that \(\gamma ^2 \equiv _p \alpha ^{p-1} \equiv 1\), by Fermat’s theorem (Theorem 54.1.15p(page for theorem 54.1.15) ), which implies that \(\gamma \) is either \(+1\) or \(-1\), as the polynomial \(x^2 -1\) has at most two roots over a field.

    (B) Let \(\alpha \equiv _p \beta ^2\), and again by Fermat’s theorem, we have \(\alpha ^{(p-1)/2} \equiv _p \beta ^{p-1} \equiv _p 1\).

    (C) Let \(X\) be the set of elements in \(\ZZ _p^*\) that are not quadratic residues, and consider \(\alpha \in X\). Since \(\ZZ _p^*\) is a group, for any \(x \in \ZZ _p^*\) there is a unique \(y \in \ZZ _p^*\) such that \(xy \equiv _p \alpha \). As such, we partition \(\ZZ _p^*\) into pairs \(C = \brc { \brc {x, y} \sep { x, y \in \ZZ _p^* \text { and } xy \equiv _p \alpha }}\). We have that

    \(\seteqnumber{0}{54.}{0}\)

    \begin{align*} \ds \tau \;\equiv _p\;\prod _{\beta \in \ZZ _p^*} \beta \;\equiv _p\;\prod _{\brc {x,y} \in C} x y\;\equiv _p\;\prod _{\brc {x,y} \in C} \alpha \;\equiv _p\;\alpha ^{(p-1)/2}. \end{align*} Let consider a similar set of pair, but this time for \(1\):

    \[ D = \brc { \brc {x, y} \sep { x, y \in \ZZ _p^*, x \neq y \text { and } xy \equiv _p 1}}. \]

    Clearly, \(D\) does not contain \(-1\) and \(1\), but all other elements in \(\ZZ _p^*\) are in \(D\). As such,

    \(\seteqnumber{0}{54.}{0}\)

    \begin{align*} \ds \tau \;\equiv _p\;\prod _{\beta \in \ZZ _p^*} \beta \;\equiv _p\;(-1) 1 \prod _{\brc {x,y} \in D} x y\;\equiv _p\;\prod _{\brc {x,y} \in D} 1\;\equiv _p\;-1. \end{align*}

54.1.3.2 Legendre symbol

For an odd prime \(p\), and an integer \(a\) with \(\gcd (a,n)=1\), the Legendre symbol \(\lSym {a}{p}\) is one if \(a\) is a quadratic residue modulo \(p\), and \(-1\) otherwise (if \(p \divides a\), we define \(\lSym {a}{p} = 0\)). Euler’s criterion (Theorem 54.1.22) implies the following equivalent definition.

  • Definition 54.1.23. The Legendre symbol, for a prime number \(p\), and \(a\in \ZZ _p^*\), is

    \(\seteqnumber{0}{54.}{0}\)

    \begin{align*} \lSym {a}{p} = a^{(p-1)/2} \pmod p. \end{align*}

The following is easy to verify.

  • Lemma 54.1.24. Let \(p\) be an odd prime, and let \(a,b\) be integer numbers. We have:

    • (i) \(\lSym {-1}{p} = (-1)^{(p-1)/2}\).

    • (ii) \(\lSym {a}{p} \lSym {b}{p} = \lSym {ab}{p}\).

    • (iii) If \(a \equiv _p b\) then \(\lSym {a}{p} = \lSym {b}{p}\).

  • Lemma 54.1.25 (Gauss’ lemma). Let \(p\) be an odd prime and let \(a\) be an integer that is not divisible by \(p\). Let

    \(\seteqnumber{0}{54.}{0}\)

    \begin{align*} X &= \brc { \alpha _ j = ja \pmod {p}\sep {j=1,\ldots , (p-1)/2}},\\ \text {and}\quad L &= { \brc { x \in X \sep { x > p/2}} } \subseteq X. \end{align*} Then \(\lSym {a}{p} = (-1)^n\), where \(n = \cardin {L}\).

  • Proof: Observe that for any distinct \(i,j\), such that \(1\leq i\leq j\leq (p-1)/2\), we have that \(ja \equiv ia \pmod {p}\) implies that \((j-i) a \equiv 0 \pmod {p}\), which is impossible as \(j-i < p\) and \(\gcd (a,p) = 1\). As such, all the elements of \(X\) are distinct, and \(\cardin {X} = (p-1)/2\). We have a somewhat stronger property: If \(ja \equiv p - ia \pmod {p}\) implies \((j+i)a \equiv 0 \pmod {p}\), which is impossible. That is, \(S =X \setminus L\), and \(\overline {L} = \brc { p -\ell \sep {\ell \in L}}\) are disjoint, and \(S \cup \overline {L} = \brc {1,\ldots , (p-1)/2\biggl .}\). As such,

    \(\seteqnumber{0}{54.}{0}\)

    \begin{align*} \pth {\frac {p-1}{2}}!&\equiv \prod _{x \in S} x \cdot \prod _{y \in L} (p-y)\;\equiv \;(-1)^n \prod _{x \in S} x \cdot \prod _{y \in L} y\\ &\equiv \;(-1)^n \prod _{j=1}^{(p-1)/2} j a\;\equiv \;(-1)^n a^{(p-1)/2} \pth []{\frac {p-1}{2}}! \pmod {p}. \end{align*} Dividing both sides by \((-1)^n((p-1)/2)!\), we have that \(\lSym {a}{p} \equiv a^{(p-1)/2} \equiv (-1)^n \pmod {p}\), as claimed.

  • Lemma 54.1.26. If \(p\) is an odd prime, and \(a>2\) and \(\gcd (a, p)=1\) then \(\lSym {a}{p} = \ds (-1)^\Delta \), where \(\ds \Delta = \sum _{j=1}^{(p-1)/2} \floor {j a / p}\). Furthermore, we have \(\lSym {2}{p} = (-1)^{(p^2 - 1)/8}\).

  • Proof: Using the notation of Lemma 54.1.25, we have

    \(\seteqnumber{0}{54.}{0}\)

    \begin{align*} \sum _{j=1}^{(p-1)/2} j a &=\sum _{j=1}^{(p-1)/2} \pth {\biggl .\floor {\ts j a / p}p + (ja \bmod p)}=\Delta p + \sum _{x \in S} x + \sum _{y \in L} y\\ &=(\Delta +n) p + \sum _{x \in S} x - \sum _{y \in \overline {L}} y\\ &=(\Delta +n) p + \sum _{j=1}^{(p-1)/2} j - 2\sum _{y \in \overline {L}} y. \end{align*} Rearranging, and observing that \(\sum _{j=1}^{(p-1)/2} j= \frac {p-1}{2}\cdot \frac {1}{2}\pth []{\bigl . \frac {p-1}{2} +1} = \frac {p^2-1}{8}.\)We have that

    \(\seteqnumber{0}{54.}{0}\)

    \begin{align} &(a-1) \frac {p^2-1}{8} = (\Delta +n) p - 2\sum _{y \in \overline {L}} y\nonumber \\ &\implies \qquad (a-1) \frac {p^2-1}{8} \equiv (\Delta +n) p \pmod {2}.\eqlab {a:m:one} \end{align} Observe that \(p \equiv 1 \pmod {2}\), and for any \(x\) we have that \(x \equiv -x \pmod {2}\). As such, and if \(a\) is odd, then the above implies that \(n \equiv \Delta \pmod {2}\). Now the claim readily follows from Lemma 54.1.25.

    As for \(\lSym {2}{p}\), setting \(a=2\), observe that \(\floor {j a / p} = 0\), for \(j=0,\ldots (p-1)/2\), and as such \(\Delta =0\). Now, Eq. (54.1) implies that \(\frac {p^2-1}{8} \equiv n \pmod {2},\)and the claim follows from Lemma 54.1.25.

  • Theorem 54.1.27 (Law of quadratic reciprocity). If \(p\) and \(q\) are distinct odd primes, then

    \(\seteqnumber{0}{54.}{1}\)

    \begin{align*} \ds \lSym {p}{q} = (-1)^{\frac {p-1}{2} \frac {q-1}{2}} \lSym {q}{p}. \end{align*}

  • Proof: Let \(S = \brc { (x,y) \sep { 1\leq x \leq (p-1)/2 \text { and } 1 \leq y \leq (q-1)/2}}.\)As \(\lcm (p,q) = pq\), it follows that there are no \((x,y) \in S\), such that \(qx = py\), as all such numbers are strict smaller than \(pq\). Now, let

    \(\seteqnumber{0}{54.}{1}\)

    \begin{align*} S_1= \brc {(x,y) \in S \sep { qx >py}}\quad \text {and}\quad S_2= \brc {(x,y) \in S \sep { qx <py}}. \end{align*} Now, \((x,y) \in S_1\) \(\iff \) \(1 \leq x \leq (p-1)\), and \(1 \leq y \leq \floor {qx /p}\). As such, we have \(\cardin {S_1} = \sum _{x=1}^{(p-1)/2} \floor {qx / p}\), and similarly \(\cardin {S_2} = \sum _{y=1}^{(q-1)/2} \floor {py / q}\). We have

    \(\seteqnumber{0}{54.}{1}\)

    \begin{align*} \tau &= \frac {p-1}{2} \cdot \frac {q-1}{2} = \cardin {S} = \cardin {S_1} + \cardin {S_2}\\ &=\underbrace {\sum _{x=1}^{(p-1)/2} \floor {qx / p}}_{\tau _1} + \underbrace {\sum _{y=1}^{(q-1)/2} \floor {py / q}}_{\tau _2}. \end{align*} The claim now readily follows by Lemma 54.1.26, as \((-1)^\tau = (-1)^{\tau _1} (-1)^{\tau _2}\) \(= \lSym {p}{q} \lSym {q}{p}\).

54.1.3.3 Jacobi symbol

  • Definition 54.1.28. For any integer \(a\), and an odd number \(n\) with prime factorization \(n=p_1^{k_1} \cdots p_t^{k_t}\), its Jacobi symbol is

    \(\seteqnumber{0}{54.}{1}\)

    \begin{align*} \jSym {a}{n} = \prod _{i=1}^t \lSym {a}{p_i}^{k_i}. \end{align*}

  • Claim 54.1.29. For odd integers \(n_1, \ldots , n_k\), we have that \(\sum _{i=1}^k (n_i -1)/2 \equiv \pth []{\prod _{i=1}^k n_i -1} /2 \pmod {2}\).

  • Proof: We prove for two odd integers \(x\) and \(y\), and apply this repeatedly to get the claim. Indeed, we have \(\ds \frac {x-1}{2} + \frac {y-1}{2} \equiv \frac {xy - 1}{2} \pmod {2} \iff 0 \equiv \frac {xy -x + 1 -y + 1 - 1}{2} \pmod {2} \iff 0 \equiv \frac {xy -x -y + 1}{2} \pmod {2} \iff 0 \equiv \frac {(x-1)(y-1)}{2} \pmod {2},\)which is obviously true.

  • Lemma 54.1.30 (Law of quadratic reciprocity). For \(n\) and \(m\) positive odd integers, we have that \(\ds \jSym {n}{m} = (-1)^{\frac {n-1}{2} \frac {m-1}{2}} \jSym {m}{n}.\)

  • Proof: Let \(n = \prod _{i=1}^\nu p_i\) and Let \(m = \prod _{j=1}^\mu q_j\) be the prime factorization of the two numbers (allowing repeated factors). If they share a common factor \(p\), then both \(\jSym {n}{m}\) and \(\jSym {m}{n}\) contain a zero term when expanded, as \(\lSym {n}{p} = \lSym {m}{p} = 0\). Otherwise, we have

    \(\seteqnumber{0}{54.}{1}\)

    \begin{align*} \jSym {n}{m}&=\prod _{i=1}^\nu \prod _{j=1}^\mu \jSym {p_i}{ q_j}=\prod _{i=1}^\nu \prod _{j=1}^\mu \lSym {p_i}{ q_j}\\ &=\prod _{i=1}^\nu \prod _{j=1}^\mu { (-1)^{(q_j-1)/2 \cdot (p_i -1 )/2}} \lSym {q_j}{p_i}\\&=\underbrace {{\prod _{i=1}^\nu \prod _{j=1}^\mu { (-1)^{(q_j-1)/2 \cdot (p_i -1 )/2}}}}_{s} \cdot \pth []{ \prod _{i=1}^\nu \prod _{j=1}^\mu \lSym {q_j}{p_i}}\\ &=s \jSym {m}{n}. \end{align*} by Theorem 54.1.27. As for the value of \(s\), observe that

    \(\seteqnumber{0}{54.}{1}\)

    \begin{align*} s&=\prod _{i=1}^\nu \pth []{ \prod _{j=1}^\mu { (-1)^{(q_j-1)/2}}}^{ (p_i -1 )/2}=\prod _{i=1}^\nu \pth { (-1)^{(m-1)/2}}^{ (p_i -1 )/2}\\ &=\pth {\prod _{i=1}^\nu (-1)^{ (p_i -1 )/2}}^ {(m-1)/2} =(-1)^{(n-1)/2 \cdot (m-1)/2}, \end{align*} by repeated usage of Claim 54.1.29.

  • Lemma 54.1.31. For odd integers \(n\) and \(m\), we have that

    \[ \frac {n^2 -1 }{8} + \frac {m^2 -1 }{8} \equiv \frac {n^2m^2 -1 }{8} \pmod {2}. \]

  • Proof: For an odd integer \(n\), we have that either (i) \(2\divides n-1\) and \(4 \divides n+1\), or (ii) \(4\divides n-1\) and \(2 \divides n+1\). As such, \(8 \divides n^2 - 1 = (n-1)(n+1)\). In particular, \(64 \divides \pth []{n^2 - 1 } \pth []{m^2 -1}\). We thus have that

    \(\seteqnumber{0}{54.}{1}\)

    \begin{align*} &\frac {\pth []{n^2 -1}\pth []{m^2 - 1}}{8} \equiv 0 \pmod {2} \\ &\iff \frac {n^2 m^2 - n^2 - m^2 +1}{8} \equiv 0 \pmod {2}\\&\iff \frac {n^2 m^2 -1}{8} \equiv \frac {n^2 -m^2 -2}{8} \pmod {2}\\&\iff \frac {n^2 -1 }{8} + \frac {m^2 -1 }{8} \equiv \frac {n^2m^2 -1 }{8} \pmod {2}. \end{align*}

  • Lemma 54.1.32. Let \(m, n\) be odd integers, and \(a,b\) be any integers. We have the following:

    • (A) \(\jSym {a b}{n} = \jSym {a}{n} \jSym {b}{n}\).

    • (B) \(\jSym {a}{nm} = \jSym {a}{n} \jSym {a}{m}\).

    • (C) If \(a \equiv b \pmod {n}\) then \(\jSym {a }{n} = \jSym {b}{n}\).

    • (D) If \(\gcd (a,n) > 1\) then \(\jSym {a}{n} = 0\).

    • (E) \(\jSym {1}{n} =1\).

    • (F) \(\jSym {2}{n} =(-1)^{(n^2 - 1)/8}\).

    • (G) \(\jSym {n}{m} = (-1)^{\frac {n-1}{2} \frac {m-1}{2}} \jSym {m}{n}\).

  • Proof: (A) Follows immediately, as \(\lSym {a b}{p_i} = \lSym {a}{p_i} \lSym {b}{p_i}\),
    see Lemma 54.1.24p(page for theorem 54.1.24) .

    (B) Immediate from definition.

    (C) Follows readily from Lemma 54.1.24p(page for theorem 54.1.24) (iii).

    (D) Indeed, if \(p \divides \gcd ( a, n)\) and \(p >1\), then \(\lSym {a}{p}^k = \lSym {0}{p}^k = 0\) appears as a term in \(\jSym {a}{n}\).

    (E) Obvious by definition.

    (F) By Lemma 54.1.26p(page for theorem 54.1.26) , for a prime \(p\), we have \(\lSym {2}{p} = (-1)^{(p^2 - 1)/8}\). As such, writing \(n = \prod _{i=1}^t p_i\) as a product of primes (allowing repeated primes), we have

    \(\seteqnumber{0}{54.}{1}\)

    \begin{align*} \jSym {2}{n}=\prod _{i=1}^t \lSym {2}{p_i}=\prod _{i=1}^t {(-1)^{(p_i^2 - 1)/8}}=(-1)^\Delta , \end{align*} where \(\Delta = \sum _{i =1}^t (p_i^2 - 1)/8\). As such, we need to compute the \(\Delta \pmod {2}\), which by Lemma 54.1.31, is

    \(\seteqnumber{0}{54.}{1}\)

    \begin{align*} \Delta \equiv \sum _{i =1}^t \frac {p_i^2 - 1}{8}\equiv \frac {\prod _{i =1}^t p_i^2 - 1}{8}\equiv \frac {n^2 - 1}{8}\pmod {2}, \end{align*} and as such \(\jSym {2}{n} = (-1)^\Delta = (-1)^{(n^2 -1 ) /8}\).

    (G) This is Lemma 54.1.30.

54.1.3.4 Jacobi(\(a,n\)): Computing the Jacobi symbol

Given \(a\) and \(n\) (\(n\) is an odd number), we are interested in computing (in polynomial time) the Jacobi symbol \(\jSym {a}{n}\). The algorithm Jacobi(\(a,n\)) works as follows:

  • (A) If \(a=0\) then return 0   // Since \(\jSym {0}{n} = 0\).

  • (B) If \(a > n\) then return Jacobi(\(a \pmod n ,n\))   // Lemma 54.1.32 (C)

  • (C) If \(\gcd (a,n) > 1\) then return \(0\)   // Lemma 54.1.32 (D)

  • (D) If \(a =2\) then

    • (I) Compute \(\Delta = n^2 -1 \pmod {16}\),

    • (II) Return \((-1)^{\Delta /8 \pmod {2}}\)   // As \((n^2 -1)/8 \equiv \Delta /8 \pmod {2}\), and by Lemma 54.1.32 (F)

  • (E) If \(2 \divides a\) then return Jacobi(\(2,n\)) * Jacobi(\(a/2,n\))  // Lemma 54.1.32 (A)

    // Must be that \(a\) and \(b\) are both odd, \(a < n\), and they are coprime

  • (F) \(a' := a \pmod {4}\),   \(n' := n \pmod {4}\),   \(\beta = (a' -1)(n'-1)/4\).

    return \((-1)^\beta \) Jacobi(\(n,a\))   // By Lemma 54.1.32 (G)

Ignoring the recursive calls, all the operations takes polynomial time. Clearly, computing Jacobi(\(2,n\)) takes polynomial time. Otherwise, observe that Jacobi reduces its input size by say, one bit, at least every two recursive calls, and except the \(a=2\) case, it always perform only a single call. Thus, it follows that its running time is polynomial. We thus get the following.

  • Lemma 54.1.33. Given integers \(a\) and \(n\), where \(n\) is odd, then \(\jSym {a}{n}\) can be computed in polynomial time.

54.1.3.5 Subgroups induced by the Jacobi symbol

For an \(n\), consider the set

\(\seteqnumber{0}{54.}{1}\)

\begin{align} J_n =\brc {a \in \ZZ _n^* \sep { \jSym {a}{n} \equiv a^{(n-1)/2} \bmod {n}}}.\eqlab {J:n} \end{align}

  • Claim 54.1.34. The set \(J_n\) is a subgroup of \(\ZZ _n^*\).

  • Proof: For \(a, b \in J_n\), we have that

    \[ \jSym {a b}{n}\equiv \jSym {a}{n} \jSym {b}{n}\equiv a^{(n-1)/2} b^{(n-1)/2}\equiv (ab)^{(n-1)/2} \bmod {n}, \]

    implying that \(ab \in J_n\). Now, \(\jSym {1}{n} = 1\), so \(1 \in J_n\). Now, for \(a \in J_n\), let \(a^{-1}\) the inverse of \(a\) (which is a number in \(\ZZ _n^*\)). Observe that \(a (a^{-1}) = k n + 1\), for some \(k\), and as such, we have

    \(\seteqnumber{0}{54.}{2}\)

    \begin{align*} 1&=\jSym {1}{n}=\jSym {kn + 1}{n}=\jSym {a {} a^{-1}}{n}\\ &=\jSym {kn + 1}{n}=\jSym {a }{n} \jSym { a^{-1}}{n}. \end{align*} And modulo \(n\), we have

    \(\seteqnumber{0}{54.}{2}\)

    \begin{align*} 1\equiv \jSym {a }{n} \jSym { a^{-1}}{n} \equiv a^{(n-1)/2} \jSym { a^{-1}}{n} \bmod {n}. \end{align*} Which implies that \(\pth []{a^{-1}}^{(n-1)/2} \equiv \jSym { a^{-1}}{n} \bmod {n}\). That is \(a^{-1} \in J_n\).

    Namely, \(J_n\) contains the identity, it is closed under inverse and multiplication, and it is now easy to verify that fulfill the other requirements to be a group.

  • Lemma 54.1.35. Let \(n\) be an odd integer that is composite, then \(\cardin {J_n} \leq \cardin {\ZZ _n^*}/2\).

  • Proof: Let has the prime factorization \(n = \prod _{i=1}^t p_i^{k_i}\). Let \(q = p_1^{k_1}\), and \(m = n/q\). By Lemma 54.1.20p(page for theorem 54.1.20) , the group \(\ZZ _q^*\) is cyclic, and let \(g\) be its generator. Consider the element \(a \in \ZZ _n^*\) such that

    \(\seteqnumber{0}{54.}{2}\)

    \begin{align*} a \equiv g \bmod {q}\qquad \text {and}\qquad a \equiv 1 \bmod {m}. \end{align*} Such a number \(a\) exists and its unique, by the Chinese remainder theorem (Theorem 54.1.6p(page for theorem 54.1.6) ). In particular, let \(m = \prod _{i=2}^t p_i^{k_i}\), and observe that, for all \(i\), we have \(a \equiv 1 \pmod {p_i}\), as \(p_i \divides m\). As such, writing the Jacobi symbol explicitly, we have

    \(\seteqnumber{0}{54.}{2}\)

    \begin{align*} \jSym {a}{n}&=\jSym {a}{q}\prod _{i=2}^t \lSym {a}{p_i}^{k_i}=\jSym {a}{q}\prod _{i=2}^t \lSym {1}{p_i}^{k_i}\\ &=\jSym {a}{q}\prod _{i=2}^t 1=\jSym {a}{q}=\jSym {g}{q}. \end{align*} since \(a \equiv g \pmod {q}\), and Lemma 54.1.32p(page for theorem 54.1.32) (C). At this point there are two possibilities:

    • (A) If \(k_1=1\), then \(q= p_1\), and \(\jSym {g}{q} = \lSym {g}{q} = g^{(q-1)/2} \pmod q\). But \(g\) is a generator of \(\ZZ _{q}^*\), and its order is \(q-1\). As such \(g^{(q-1)/2} \equiv -1 \pmod {q}\), see Definition 54.1.23p(page for theorem 54.1.23) . We conclude that \(\jSym {a}{n} =-1\). If we assume that \(J_n = \ZZ _n^*\), then \(\jSym {a}{n} \equiv a^{(n-1)/2} \equiv -1 \pmod {n}\). Now, as \(m \divides n\), we have

      \(\seteqnumber{0}{54.}{2}\)

      \begin{align*} a^{(n-1)/2}\equiv _m\pth []{ a^{(n-1)/2} \bmod {n}}\bmod {m}\equiv _m-1. \end{align*} But this contradicts the choice of \(a\) as \(a \equiv 1 \pmod {m}\).

    • (B) If \(k_1 > 1\) then \(q =p_1^{k_1}\). Arguing as above, we have that \(\jSym {a}{n} = (-1)^{k_1}\). Thus, if we assume that \(J_n = \ZZ _n^*\), then \(a^{(n-1)/2} \equiv - 1 \pmod {n}\) or \(a^{(n-1)/2} \equiv 1 \pmod {n}\). This implies that \(a^{n-1} \equiv 1 \pmod {n}\). Thus, \(a^{n-1} \equiv 1 \pmod {q}\).

      Now \(a \equiv g \mod q\), and thus \(g^{n-1} \equiv 1 \pmod {q}\). This implies that the order of \(g\) in \(\ZZ _q^*\) must divide \(n-1\). That is \(\ordX {g} = \phi (q) \divides n-1\). Now, since \(k_1 \geq 2\), we have that \(p_1 \divides \phi (q) = \pth []{p_1^{k_1}} \pth []{p_1 -1}\), see Lemma 54.1.8p(page for theorem 54.1.8) . We conclude that \(p_1 \divides n-1\) and \(p_1 \divides n\), which is of course impossible, as \(p_1 >1\).

    We conclude that \(J_n\) must be a proper subgroup of \(\ZZ _n^*\),
    but, by Lemma 54.1.11p(page for theorem 54.1.11) , it must be that \(\cardin {J_n} \divides \cardin {\ZZ _n^*}\). But this implies that \(\cardin {J_n} \leq \cardin {\ZZ _n^*}/2\).

54.2 Primality testing

The primality test is now easy54.1. Indeed, given a number \(n\), first check if it is even (duh!). Otherwise, randomly pick a number \(r \in \brc {2, \ldots , n -1}\). If \(\gcd ( r, n) > 1\) then the number is composite. Otherwise, check if \(r \in J_n\) (see Eq. (54.2)p(page for eq. (54.2)) ), by computing \(x = \jSym {r}{n}\) in polynomial time, see Section 54.1.3.4p(page for section 54.1.3.4) , and \(x' =a^{(n-1)/2} \bmod {n}\). (see Lemma 54.1.7p(page for theorem 54.1.7) ). If \(x=x'\) then the algorithm returns is prime, otherwise it returns it is composite.

  • Theorem 54.2.1. Given a number \(n\), and a parameter \(\delta >0\), there is a randomized algorithm that, decides if the given number is prime or composite. The running time of the algorithm is \(O\bigl (\pth {\log n}^{c} \log (1/\delta ) \bigr )\), where \(c\) is some constant. If the algorithm returns that \(n\) is composite then it is. If the algorithm returns that \(n\) is prime, then is wrong with probability at most \(\delta \).

  • Proof: Run the above algorithm \(m = O( \log (1/\delta ))\) times. If any of the runs returns that it is composite then the algorithm return that \(n\) is composite, otherwise the algorithms returns that it is a prime.

    If the algorithm fails, then \(n\) is a composite, and let \(r_1, \ldots , r_m\) be the random numbers the algorithm picked. The algorithm fails only if \(r_1, \ldots , r_m \in J_n\), but since \(\cardin {J_n} \leq \cardin {\ZZ _n^2}/2\), by Lemma 54.1.35p(page for theorem 54.1.35) , it follows that this happens with probability at most \(\,\pth []{\cardin {J_n} / \cardin {\ZZ _n^2}}^m \! \leq 1/2^m \leq \delta \), as claimed.

54.2.1 Distribution of primes

In the following, let \(\pi (n)\) denote the number of primes between \(1\) and \(n\). Here, we prove that \(\pi (n) = \Theta ( n / \log n)\).

  • Lemma 54.2.2. Let \(\Delta \) be the product of all the prime numbers \(p\), where \(m <p \leq 2m\). We have that \(\Delta \leq \binom {2m}{m}\).

  • Proof: Let \(X\) be the product of the all composite numbers between \(m\) and \(2m\), we have

    \(\seteqnumber{0}{54.}{2}\)

    \begin{align*} \binom {2m}{m}=\frac {2m\cdot (2m - 1)\cdots (m + 2) \cdot (m + 1)}{m\cdot (m - 1)\cdots {2}\cdot {1} }=\frac {X \cdot \Delta }{m\cdot (m - 1)\cdots {2} \cdot {1}}. \end{align*} Since none of the numbers between \(2\) and \(m\) divides any of the factors of \(\Delta \), it must be that the number \(\frac {X}{m\cdot (m - 1)\cdots {2}\cdot {1}}\) is an integer number, as \(\binom {2m}{m}\) is an integer. Therefore, \(\binom {2m}{m} = c\cdot \Delta \), for some integer \(c > 0\), implying the claim.

  • Lemma 54.2.3. The number of prime numbers between \(m\) and \(2m\) is \(O(m/\ln m)\).

  • Proof: Let us denote all primes between \(m\) and \(2m\) as \(p_1 < p_2 < \cdots < p_k\). Since \(p_1 \geq m\), it follows from Lemma 54.2.2 that \(m^k \le \prod _{i=1}^{k} {p_i} \le \binom {2m}{m}\leq 2^{2m}\). Now, taking log of both sides, we have \(k \lg {m} \leq 2m\). Namely, \(k \leq 2m/\lg m\).

  • Lemma 54.2.4. \(\pi (n) = O(n/\ln n)\).

  • Proof: Let the number of primes less than \(n\) be \(\Pi (n)\), then by Lemma 54.2.3, there exist some positive constant \(C\), such that for all \(\forall n \ge N\), we have \(\Pi (2n) - \Pi (n) \leq C\cdot n/\ln {n}\). Namely, \(\Pi (2n) \leq C\cdot n/\ln {n}+ \Pi (n)\). Thus, \(\ds \Pi (2n)\leq \sum _{i=0}^{\ceil {\lg n} } \pth { \Biggl . \Pi \pth {2n/2^i} - \Pi \pth {2n/2^{i+1}}}\leq \sum _{i=0}^{\ceil {\lg n} } C\cdot \frac {n/2^i}{\ln \pth {n/2^i}}=O\pth {\frac {n}{\ln {n}}},\)by observing that the summation behaves like a decreasing geometric series.

  • Lemma 54.2.5. For integers \(m, k\) and a prime \(p\), if \(p^k \divides \binom {2m}{m}\), then \(p^k \leq 2m\).

  • Proof: Let \(T(p,m)\) be the number of times \(p\) appear in the prime factorization of \(m!\). Formally, \(T(p,m)\) is the highest number \(k\) such that \(p^k\) divides \(m!\). We claim that \(T(p,m) = \sum _{i=1}^{\infty } \floor {m / p^i}\). Indeed, consider an integer \(\beta \leq m\), such that \(\beta = p^t \gamma \), where \(\gamma \) is an integer that is not divisible by \(p\). Observe that \(\beta \) contributes exactly to the first \(t\) terms of the summation of \(T(p,m)\) – namely, its contribution to \(m!\) as far as powers of \(p\) is counted correctly.

    Let \(\alpha \) be the maximum number such that \(p^\alpha \) divides \(\binom {2m}{m} = \frac {2m!}{m! m!}\). Clearly,

    \(\seteqnumber{0}{54.}{2}\)

    \begin{align*} \alpha =T(p,2m) - 2T(p,m)=\sum _{i=1}^\infty \pth { \floor {\frac {2m}{ p^i}} -2 \floor {\frac {m}{p^i}}}. \end{align*} It is easy to verify that for any integers \(x, y\), we have that \(0 \leq \floor {\frac {2x}{y}} - 2 \floor {\frac {x}{y}} \leq 1\). In particular, let \(k\) be the largest number such that
    \(\pth []{ \floor {\frac {2m}{ p^k}} -2 \floor {\frac {m}{p^k}}} =1\), and observe that \(T(p, 2m) \leq k\) as only the proceedings \(k-1\) terms might be non-zero in the summation of \(T(p,2m)\). But this implies that \(\floor {2m/p^k}\geq 1\), which implies in turn that \(p^k \leq 2m\), as desired.

  • Lemma 54.2.6. \(\pi (n) = \Omega (n /\ln n)\).

  • Proof: Assume \(\binom {2m}{m}\) have \(k\) prime factors, and thus can be written as \(\binom {2m}{m} = \prod _{i=1}^k{p_i^{n_i}}.\)By Lemma 54.2.5, we have \(p_i^{n_i} \le 2m\). Of course, the above product might not include some prime numbers between \(1\) and \(2m\), and as such \(k\) is a lower bound on the number of primes in this range; that is, \(k \leq \pi (2m)\). This implies

    \(\seteqnumber{0}{54.}{2}\)

    \begin{equation*} \frac {2^{2m}}{2m} \le \binom {2m}{m} \le \prod _{i=1}^k{2m} = (2m)^k. \end{equation*}

    By taking \(\lg \) of both sides, we have \(\ds \frac {2m - \lg (2m)}{\lg (2m)} \leq k \leq \pi (2m).\)

We summarize the result.

  • Theorem 54.2.7. Let \(\pi (n)\) be the number of distinct prime numbers between \(1\) and \(n\). We have that \(\pi (n) = \Theta ( n / \ln n )\).

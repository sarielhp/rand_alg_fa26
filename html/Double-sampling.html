41.1 Double sampling

Double sampling is the idea that two random independent samples should look similar, and should not be completely different in the way they intersect a certain set. We use the following sampling model, which makes the computations somewhat easier.

  • Definition 41.1.1. Let \(\ObjSet = \brc { \obj _1, \ldots , \obj _n}\) be a set of objects, where the \(i\)th object has weight \(\Wg _i > 0\), for all \(i\). Let \(\TotalW = \sum _i \Wg _i\). For a target size \(\rho \), a \(\rho \)-sample is a random sample \(\Sample \subseteq \ObjSet \), where object \(\obj _i\) is picked independently with probability \(\displaystyle \rho \Wg _i / \TotalW \). To simplify the discussion, we assume that \(\rho \Wg _i / \TotalW < 1\). Handling the more general case is easy if somewhat tedious.

  • Lemma 41.1.2. Let \(\Sample _1\) and \(\Sample _2\) be two \(\rho \)-samples, and consider the merged sample \(\Sample = \Sample _1 \cup \Sample _2\). Let \(\SetB \subseteq \ObjSet \) be a set of \(m\) elements. Then, we have that

    \(\seteqnumber{0}{41.}{0}\)

    \begin{align*} \Prob { \Bigl . \SetB \subseteq \Sample _1 \bigm \vert { \SetB \subseteq \Sample }} \geq \frac {1}{2^m} \qquad \text { and } \qquad \Prob { \Bigl . \SetB \subseteq \Sample _1\text { and }\; \SetB \cap \Sample _2 = \emptyset \bigm \vert { \SetB \subseteq \Sample }} \leq \frac {1}{2^m}. \end{align*}

  • Proof: Consider an object \(\obj \in \SetB \), and observe that \(\Prob {\bigl . \obj \in \Sample _1 \text { or } \obj \in \Sample _2 \mid \obj \in \Sample } = 1.\)As such, by symmetry

    \(\seteqnumber{0}{41.}{0}\)

    \begin{align*} \Prob {\bigl . \obj \in \Sample _1 \mid \obj \in \Sample }=\Prob {\bigl . \obj \in \Sample _2 \mid \obj \in \Sample }\geq 1/2, \end{align*} Now, let \(\SetB = \brc { \obj _1, \ldots , \obj _m}\). Since \(\Sample _1\) and \(\Sample _2\) are independent, and each element is being picked independently, we have that

    \(\seteqnumber{0}{41.}{0}\)

    \begin{align*} \Prob { \bigl . \SetB \subseteq \Sample _1 \mid { \SetB \subseteq \Sample }}&=\Prob { \bigl . \obj _1, \ldots , \obj _m \in \Sample _1 \mid { \obj _1, \ldots , \obj _m \in \Sample }} =\prod _{i=1}^b \Prob { \bigl . \obj _i \in \Sample _1 \mid { \obj _1, \ldots , \obj _m \in \Sample }} \\&=\prod _{i=1}^b \Prob { \bigl . \obj _i \in \Sample _1 \mid { \obj _i \in \Sample }} \geq \frac {1}{2^m}. \end{align*}

    For the second claim, observe that again, by symmetry, we have that

    \(\seteqnumber{0}{41.}{0}\)

    \begin{equation*} \ProbCond {\bigl . \obj \in \Sample _1 \text { and } \obj \notin \Sample _2 }{ \obj \in \Sample }=\Prob {\bigl . \obj \notin \Sample _1 \text { and } \obj \in \Sample _2 \mid \obj \in \Sample }\leq 1/2, \end{equation*}

    as the two events are disjoint. Now, the claim follows by arguing as above.

41.1.1 Disagreement between samples on a specific set

We provide three proofs of the following lemma – the constants are somewhat different for each version.

  • Lemma 41.1.3. Let \(\Sample _1\) and \(\Sample _2\) be two \(\rho \)-samples from a ground set \(\ObjSet \), and consider a fixed set \(\SetB \subseteq \ObjSet \). We have that

    \(\seteqnumber{0}{41.}{0}\)

    \begin{equation*} \Prob {\Bigl . \cardin {\bigl .\cardin {\Sample _1 \cap \SetB } - \cardin {\Sample _2 \cap \SetB } }> \eps \rho }\leq 3 \exp \pth { - \eps ^2 \rho /2 }. \end{equation*}

  • Proof: (Simplest proof.) By Chernoff’s inequality, for \(\delta \in (0,1)\), we have

    \(\seteqnumber{0}{41.}{0}\)

    \begin{equation*} \Prob { \Bigl .\cardin {\bigl .\cardin {\Sample _1} - \rho } \geq (\eps /2) \rho } \leq 2 \exp \pth { - (\eps /2)^2 \rho /4 } = 2 \exp \pth { - \eps ^2 \rho /16 }. \end{equation*}

    The same holds for \(\Sample _2\), and as such we have

    \(\seteqnumber{0}{41.}{0}\)

    \begin{align*} \Prob { \Bigl .\cardin {\bigl .\cardin {\Sample _1} - \cardin {\Sample _2}} \geq \eps \rho } &\leq \Prob { \Bigl .\cardin {\bigl .\cardin {\Sample _1} -\rho } + \cardin {\bigl .\rho - \cardin {\Sample _2}} \geq \eps \rho } \\& \leq \Prob { \Bigl .\cardin {\bigl .\cardin {\Sample _1} -\rho } \geq (\eps /2)\rho } + \Prob { \Bigl . \cardin {\bigl .\rho - \cardin {\Sample _2}} \geq (\eps /2) \rho } \leq 4 \exp \pth { - \eps ^2 \rho /16 } \end{align*}

  • Proof: For an object \(\obj _i \in \ObjSet \), let \(X_i\) be a random variable, where

    \(\seteqnumber{0}{41.}{0}\)

    \begin{equation*} X_i = \begin{cases} 1 & \obj _i \in \Sample _1 \text { and } \obj _i \notin \Sample _2\\ -1 & \obj _i \notin \Sample _1 \text { and } \obj _i \in \Sample _2\\ 0 & \text {otherwise.} \end {cases} \end{equation*}

    We have that \(p_i = \Prob {X_i = 1} = \Prob {X_i=-1} = (\rho \Wg _i / \TotalW )( 1- \rho \Wg _i / \TotalW )\) and \(\Ex {X_i} = 0\). Applying the regular concentration inequalities in this case is not immediate, since there are many \(X_i\)s that are zero. To overcome this, let \(T\) be a random variable that is the number of variables in \(X_1, \ldots , X_n\) that are non-zero. We have that \(T\) is a sum of \(n\) independent \(0/1\) random variables, where \(\Ex {T} = \sum _i 2p_i =2 \rho \). In particular, by Chernoff’s inequality, we have that

    \(\seteqnumber{0}{41.}{0}\)

    \begin{equation*} q_1 = \Prob {\bigl . T > (1+\eps ) 2 \rho }\leq \exp \pth { \bigl .- 2\rho \eps ^2 /4} =\exp \pth { \bigl .- \rho \eps ^2 /2}. \end{equation*}

    and assume this happens. In particular, let \(Z_1, \ldots , Z_T\) be the non-zero variables in \(X_1,\ldots , X_n\), and observe that \(\Prob {Z_i=1} = \Prob {Z_i=-1} = 1/2\). Let \(Y=\sum _i X_i = \sum _i Z_i\). Observe that \(\Ex {Y} = 0\), and by Chernoff inequality, we have that

    \(\seteqnumber{0}{41.}{0}\)

    \begin{align*} q_2&=\Prob {\Bigl . \cardin {\bigl .\cardin {\Sample _1 \cap \ObjSet } - \cardin {\Sample _1 \cap \ObjSet } }> \eps \rho } =\Prob {\Bigl . \cardin {Y - \Ex {Y}} \geq \eps \rho } \leq \Prob {\Bigl . \cardin {\bigl .\textstyle {\sum }_i Z_i - 0} \geq \eps \rho } \\& \leq 2 \exp \pth { - 2 \frac { (\eps \rho )^2 }{2T}} \leq 2 \exp \pth { - 2 \frac { (\eps \rho )^2 }{2(1+\eps )\rho }} + q_1 =2 \exp \pth { - \frac { \eps ^2 \rho }{1+\eps }} + q_1 \leq 3 \exp \pth { - \eps ^2 \rho /2 }, \end{align*} using \(T \leq (1+\xi )2\rho \).

41.1.2 Exponential decay for a single set

  • Lemma 41.1.4. Consider a set \(\ObjSet \) of \(m\) objects, where every object \(\obj _i \in \ObjSet \) has weight \(\Wg _i > 0 \), and \(\TotalW = \sum _{i=1}^m \Wg _i.\)Next, consider a set \(\range \subseteq \ObjSet \) such that \(\WeightX {\range } \geq t \TotalW / \rho \) (such a set is \(t\)-heavy). Let \(\Sample \) be a \(\rho \)-sample from \(\ObjSet \). Then, the probability that \(\Sample \) misses \(\range \) is at most \(e^{-t}\). Formally, we have \(\Prob { \range \cap \Sample = \emptyset } \leq \exp \pth {-t}.\)

  • Proof: Let \(\range = \brc {\obj _1, \ldots , \obj _k}\). Clearly, the probability that \(\Sample \) fails to pick one of these conflicting objects, is bounded by \(\Prob { \range \cap \Sample = \emptyset }=\Prob { \bigl . \forall i \in \brc {1,\ldots , k} \quad \obj _i \notin \Sample _2}=\prod _{i=1}^k \pth {1 - \rho \frac {\Wg _i}{\TotalW }}\leq \prod _{i=1}^k \exp \pth { - \rho \frac {\Wg _i}{\TotalW }} =\exp \pth { - \frac {\rho }{\TotalW } \sum _i \Wg _i } \leq \exp \pth { - \frac {\rho }{\TotalW } \cdot t \frac {\TotalW }{\rho } } = \exp \pth {-t}.\)

41.1.3 Moments of the sample size

  • Lemma 41.1.5. Let \(\Sample \) an \(m\)-sample. And let \(\cFuncX {t} \leq \alpha t^\beta \), where \(\alpha \geq 1\) and \(\beta \geq 1\) are constants, such that \(m \geq 16\beta \). Then \(\cEFunc {m} = \Ex {\bigl . \cFuncX {\bigl . \cardin {\Sample }} } \leq 2 \alpha (2m)^\beta .\)

  • Proof: The proof follows from Chernoff’s inequality and some tedious but straightforward calculations. The reader is as such encouraged to skip reading it.

    Let \(X = \cardin {\Sample }\). This is a sum of \(0/1\) random variables with expectation \(m\). As such, we have

    \(\seteqnumber{0}{41.}{0}\)

    \begin{equation*} \nu =\Ex {\bigl . \cFuncX {\bigl .\cardin {\Sample }} }\leq \sum _{i=0}^\infty \Prob {X = i} f(i) \leq \alpha \sum _{i=0}^\infty \Prob {X = i} i^\beta . \end{equation*}

    Considering the last sum, we have

    \(\seteqnumber{0}{41.}{0}\)

    \begin{equation*} \sum _{i=0}^\infty \Prob {\big . X = i} i^\beta \leq \sum _{j=0}^\infty \Prob {\big . X \geq j m } \pth {(j+1) m}^\beta \leq (2m)^\beta + m^\beta \sum _{j=2}^\infty \Prob {\big . X \geq j m } \pth {j+1 }^\beta . \end{equation*}

    We bound the last summation using Chernoff’s inequality (see Theorem 15.4.1), we have

    \(\seteqnumber{0}{41.}{0}\)

    \begin{align*} \tau &= \sum _{j=2}^5 \Prob {\big . X \geq j m } \pth {j+1 }^\beta + \sum _{j=6}^\infty \Prob {\big . X \geq j m } \pth {j+1 }^\beta \\&\leq \sum _{j=2}^5 \exp \pth { - \frac {m (j-1)^2}{4} } \pth {j+1 }^\beta + \sum _{j=6}^\infty 2^{-jm} \pth {j+1 }^\beta \\&\leq \exp \pth { - \frac {m}{4} } 3^\beta + \exp \pth { - m} 4^\beta + \exp \pth { - 2m} 5^\beta + \exp \pth { - 4m} 6^\beta + \sum _{j=6}^\infty 2^{-jm} \pth {j+1 }^\beta < 1, \end{align*} since \(m \geq 16 \beta \). We conclude that \(\nu \leq \alpha (2 m)^\beta + \alpha m^\beta \tau \leq 2 \alpha (2m)^\beta \).

  • Remark 41.1.6. The constant \(16\) in the above lemma is somewhat strange. A better constant can be derived by breaking the range of sizes into smaller intervals and using the right Chernoff inequality. Since this is somewhat tangential to the point of this write-up, we leave it as is (i.e., this constant is not critical to our discussion).

41.1.4 Growth function

The growth function \(\Growth {\Dim }{n}\) is the maximum number of ranges in a range space with dimension \(\Dim \), and with \(n\) elements. By Sauer’s lemma, it is known that

\(\seteqnumber{0}{41.}{0}\)

\begin{equation} \Growth {\Dim }{n} = \sum _{i=0}^{\Dim } \binom {n}{i} \leq \sum _{i=0}^{\Dim } \frac {n^i}{i!} \leq n^\Dim , \eqlab {g:d:n:estimate:2} \end{equation}

The following is well known (the estimates are somewhat tedious to prove):

  • Lemma 41.1.7 ([h-gaa-11]). For \(n \geq 2\Dim \) and \(\Dim \geq 1\), we have \(\displaystyle \pth {\frac {n }{\Dim }}^\Dim \leq \Growth {\Dim }{n}\leq 2 \pth {\frac {n e}{\Dim }}^\Dim ,\)where \(\Growth {\Dim }{n} = \sum _{i=0}^{\Dim } \binom {n}{i}\).

  • Lemma 41.1.8. Let \(\Sample \) and \(\SampleA \) be two independent \(m\)-samples from \(\FGroundSet \). Assume that \(m \geq \Dim \). Then \(\Ex {\bigl . \Growth {\Dim }{\bigl .\cardin {\Sample } + \cardin {\SampleA }} }\leq \fGrowX {2m},\)where \(\fGrowX {2m} = 4 \, \pth {{4 e m}/{\Dim }}^{\Dim }.\)

  • Proof: We set \(\alpha = 2 \pth {\frac { e}{\Dim }}^\Dim ,\)\(\beta = \Dim \), and \(f(n) = \alpha n^\beta \). Duplicate every element in \(\FGroundSet \), and let \(\FGroundSet '\) be the resulting set. Clearly, the size of a \(2m\)-sample \(\Sample \) from \(\FGroundSet '\) is the same as \(\cardin {\Sample } + \cardin {T}\). By Lemma 41.1.7, we have \(\Ex {\Bigl . \Growth {\Dim }{\bigl .\cardin {\Sample }} }\leq \Ex {\Bigl . f \pth {\bigl .\cardin {\Sample }} }\leq 2 \alpha (4m)^\beta \leq 4 \pth {\frac { 4em}{\Dim }}^\Dim \)The last inequality follows from Lemma 41.1.5.

41.2 Proof of the \(\eps \)-net theorem

Here we are working in the unweighted settings (i.e., the weight of a single element is one).

  • Theorem 41.2.1 (\(\eps \)-net theorem, [hw-ensrq-87]). Let \((\GroundSet ,\RangeSet )\) be a range space of dimension \(\Dim \), let \(\FGroundSet \) be a finite subset of \(\GroundSet \), and suppose that \(0 < \eps \leq 1\) and \(\BadProb < 1\). Let \(N\) be an \(m\)-sample from \(\FGroundSet \) (see Definition 41.1.1), where

    \(\seteqnumber{0}{41.}{1}\)

    \begin{equation} m \geq \max \pth {\; \frac {8}{\eps } \lg \frac {4}{\BadProb } \,,\, \frac {16\Dim }{\eps }\lg \frac {16}{\eps } \;}. \eqlab {e:net:2} \end{equation}

    Then \(N\) is an \(\eps \)-net for \(\FGroundSet \) with probability at least \(1-\BadProb \).

41.2.1 The proof
41.2.1.1 Reduction to double sampling

Let \(n = \cardin {\FGroundSet }\). Let \(N\) be the \(m\)-sample from \(\FGroundSet \). Let \(\Event _1\) be the probability that \(N\) fails to be an \(\eps \)-net. Namely,

\(\seteqnumber{0}{41.}{2}\)

\begin{equation*} \Event _1=\Set { \exists {\range \in \RangeSet } }{\bigl .\ts \cardin {\range \cap \FGroundSet } \geq \eps n \text { ~ and ~ } \range \cap N = \emptyset }. \end{equation*}

(Namely, there exists a “heavy” range \(\range \) that does not contain any point of \(N\).) To complete the proof, we must show that \(\Prob {\Event _1}\leq \BadProb \). Let \(T\) be another \(m\)-sample generated in a similar fashion to \(N\). Let \(\Event _2\) be the event that \(N\) fails but \(T\) “works”. Formally

\(\seteqnumber{0}{41.}{2}\)

\begin{equation*} \Event _2=\Set {\bigl . \exists {\range \in \RangeSet }}{\bigl .\cardin {\range \cap \FGroundSet } \geq \eps n, \, \range \cap N = \emptyset , \, \text { and } \cardin {\range \cap T} \geq \frac {\eps m}{2} }. \end{equation*}

Intuitively, since \(\Ex {\bigl . \cardin {\range \cap \FGroundSet } } \geq \eps m\), we have that for the range \(\range \) that \(N\) fails for, it follows with “good” probability that \(\cardin {\range \cap T} \geq \eps m / 2\). Namely, \(\Event _1\) and \(\Event _2\) have more or less the same probability.

  • Claim 41.2.2. \(\Prob {\Event _2} \leq \Prob {\Event _1} \leq 2\Prob {\Event _2}\).

  • Proof: Clearly, \(\Event _2 \subseteq \Event _1\), and thus \(\Prob {\Event _2} \leq \Prob {\Event _1}\). As for the other part, note that by the definition of conditional probability, we have

    \[ \Prob { \Event _2 \mid { \Event _1}} = \Prob {\Event _2 \cap \Event _1} / \Prob {\Event _1} = \Prob {\Event _2} / \Prob {\Event _1}. \]

    It is thus enough to show that \(\Prob {\Event _2 \mid {\Event _1}}\) \(\geq 1/2\).

    Assume that \(\Event _1\) occurs. There is \(\range \in \RangeSet \), such that \(\cardin {\range \cap \FGroundSet } > \eps n\) and \(\range \cap N = \emptyset \). The required probability is at least the probability that for this specific \(\range \), we have \(X = \cardin { \range \cap T} \geq \tfrac {\eps n}{2}\). The variable \(X\) is a sum of \(t = \cardin {\range \cap \FGroundSet } \geq \eps n\) random independent 0/1 variables, each one has probability \(m/n\) to be one. Setting \(\mu = \Ex {X} = t m/n \geq \eps m\) and \(\xi = 1/2\), we have by Chernoff’s inequality that

    \(\seteqnumber{0}{41.}{2}\)

    \begin{align*} \Prob { \cardin {\range \cap T} \leq \eps m /2} \leq \Prob { X < (1-\xi ) \mu }\leq \exp \pth { - \mu \xi ^2 / 2 }=\exp \pth { - \eps m / 8 }< 1/2, \end{align*} if \(\eps m \geq 8\). Thus, for \(\range \in \Event _1\), we have \(\Prob {\Event _2} / \Prob {\Event _1} \geq \Prob {\cardin { \range \cap T} \geq \tfrac {\eps m}{2}} = 1 -\Prob { \cardin {\range \cap T} < \frac {\eps m}{2} } \geq \frac {1}{2}.\)

Claim 41.2.2 implies that to bound the probability of \(\Event _1\), it is enough to bound the probability of \(\Event _2\). Let

\(\seteqnumber{0}{41.}{2}\)

\begin{equation*} \Event _2'=\Set { \exists {\range \in \RangeSet } }{\bigl . \range \cap N = \emptyset \text { and }\cardin {\range \cap T} \geq \frac {\eps m}{2} }. \end{equation*}

Clearly, \(\Event _2 \subseteq \Event _2'\). Thus, bounding the probability of \(\Event _2'\) is enough to prove Theorem 41.2.1. Note, however, that a shocking thing happened! We no longer have \(\FGroundSet \) participating in our event. Namely, we turned bounding an event that depends on a global quantity (i.e., the ground set \(\FGroundSet \)) into bounding a quantity that depends only on a local quantity/experiment (involving only \(N\) and \(T\)). This is the crucial idea in this proof.

41.2.1.2 Using double sampling to finish the proof

  • Claim 41.2.3. \(\Prob {\bigl . \Event _2} \leq \Prob { \bigl . \Event _2'}\leq 2^{-\eps m /2} \fGrowX {2m}.\)

  • Proof: We fix the content of \(\Sample = N \cup T\). The range space \((\Sample , \VCProj {\RangeSet }{\Sample })\) has \(\Growth {\Dim }{ \cardin {\Sample }}\) ranges. Fix a range \(\range \) in this range space. Let \(\SetB = \range \cap \Sample \). If \(b = \cardin { \SetB } < \eps m /2\) then the \(\Event _2'\) can not happened. Otherwise, the probability that \(\range \) is a bad range is \(\Prob { \Bigl . \SetB \subseteq T \text { and }\; \SetB \cap N = \emptyset \bigm \vert { \SetB \subseteq \Sample }} \leq \frac {1}{2^b},\)by Lemma 41.1.2. In particular, by the union bound over all ranges, we have \(\Prob {\Event _2' \mid \Sample } \leq 2^{-\eps m /2} \Growth {\Dim }{ \cardin {\Sample }}.\)As such, we have

    \(\seteqnumber{0}{41.}{2}\)

    \begin{align*} \Prob {\Event _2'}=\sum _{\Sample } \Prob {\bigl . \Event _2' \mid \Sample } \Prob {\Sample } \leq \sum _{\Sample } 2^{-\eps m /2} \Growth {\Dim }{\bigl . \cardin {\Sample }} \Prob {\Sample } \leq 2^{-\eps m /2} \Ex {\Bigl . \Growth {\Dim }{\bigl . \cardin {\Sample }} } \leq 2^{-\eps m /2} \fGrowX {2m}. \end{align*} by Lemma 41.1.8.

  • Proof of THEOREM 41.2.1. By Claim 41.2.2 and Claim 41.2.3, we have that \(\Prob {\Event _1} \leq 2 \cdot 2^{-\eps m /2} \fGrowX {2m}.\)It thus remains to verify that if \(m\) satisfies Eq. (41.2), then the above is smaller than \(\BadProb \). Which is equivalent to

    \(\seteqnumber{0}{41.}{2}\)

    \begin{align*} 2 \cdot 2^{-\eps m/2} \fGrowX {2m} \leq \BadProb & \iff 16 \cdot 2^{-\eps m/2} \pth {\frac {4 e m}{\Dim }}^{\!\Dim } \leq \BadProb \iff -4 + \frac {\eps m }{ 2} - \Dim \lg \pth {\frac {4 e m}{\Dim }} \geq \lg \frac {1}{\BadProb }\\&\iff \pth { \frac { \eps m}{8} -4 - \Dim \lg \frac {4 e}{\Dim }} + \pth { \frac {\eps m}{8} - \lg \frac {1}{\BadProb }} + \pth {\frac {\eps m }{ 4} - \Dim \lg \pth {\frac { m}{\Dim }}} \geq 0 \end{align*} We remind the reader that the value of \(m\) we pick is such that \(m \geq \max \pth { \frac {8}{\eps } \lg \frac {4}{\BadProb } \,,\, \frac {16\Dim }{\eps }\lg \frac {16}{\eps } }.\)In particular, \(m \geq 64 \Dim / \eps \) and \(-4 - \Dim \lg \pth {\frac {4 e }{\Dim }} \geq -4 - 4 \Dim \leq -8 \Dim \geq -\eps m /8.\)Similarly, by the choice of \(m\), we have \(\eps m /8 \geq \lg \frac {1}{\BadProb }.\)As such, we need to show that \(\frac {\eps m }{ 4} \geq \Dim \lg \pth {\frac { m}{\Dim }} \iff m \geq \frac {4\Dim }{\eps } \lg {\frac { m}{\Dim }},\)and one can verify using some easy but tedious calculations that this holds if \(m \geq \frac {16\Dim }{\eps }\lg \frac {16}{\eps } \).

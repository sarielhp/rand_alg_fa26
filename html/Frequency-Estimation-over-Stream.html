28.1 The art of estimation

28.1.1 The problem

Assume we would like to estimate well some quantity \(\rho > 0\) - specifically, for a fixed parameter \(\eps \in (0,1)\), we would like to compute a quantity \(\rho '\) such that \(\rho ' \in [(1-\eps )\rho , (1+\eps )\rho ]\) with good probability. To this end, assume we have access to a distribution \(\Distribution \), such that if we sample \(X\) according to this distribution (i.e., \(X \sim \Distribution \)), we have that \(\Ex {X} = \rho \). We can use \(X\) to estimate our desired quantity, but this might not provide the desired estimation.

Example: Estimating \(p\) for a coin. Assume we have a coin that is head with probability \(p\). A natural way to estimate \(p\) is to flip the coin once and return \(1\) if it is head, and zero otherwise. Let \(X\) be the result of the coin flip, and observe that \(\Ex {X} = p\). But this is not very useful estimator.

28.1.2 Averaging estimator: Success with constant probability
28.1.2.1 The challenge

The basic problem is that \(X \sim \Distribution \) might be much bigger than \(\rho \). Or more specifically, its variance might be huge, where \(\Distribution \) is a distribution we have access to. Let

\(\seteqnumber{0}{28.}{0}\)

\begin{equation*} \rho = \Ex {\Distribution }\qquad \text {and}\qquad \nu = \Var {\Distribution }. \end{equation*}

We would to generate a variable \(Z\), such that

\(\seteqnumber{0}{28.}{0}\)

\begin{equation} \Ex {Z} = \rho \qquad \text {and}\qquad \Var {Z} \leq (\eps ^2/4) \rho ^2. \eqlab {small:variance} \end{equation}

This would imply by Chebychev’s inequality that

\(\seteqnumber{0}{28.}{1}\)

\begin{equation*} \Prob { |Z - \rho | \geq \eps \rho }=\Prob { |Z - \Ex {Z}| \geq 2\sqrt {(\eps ^2/4) \rho ^2}} \leq \Prob { |Z - \Ex {Z}| \geq 2 \sqrt {\Var {Z}}}\leq \frac {1}{4}. \end{equation*}

28.1.2.2 Taming of the variance

The basic idea is to take \(\alpha = \ceil {\frac {\nu }{\rho }} \) independent variables \(X_1, \ldots , X_\alpha \sim \Distribution \), and let \(Y = \sum _i X_i / \alpha \). We have by linearity of expectation that

\(\seteqnumber{0}{28.}{1}\)

\begin{equation*} \Ex {Y} = \sum _i \Ex {X_i}/\alpha = \Ex {X} = \rho . \end{equation*}

Using the independence of \(X_1, \ldots , X_\alpha \), we have

\(\seteqnumber{0}{28.}{1}\)

\begin{equation*} \Var {Y}=\Var {\sum _i X_i /\alpha } =\frac {1}{\alpha ^2}\Var {\sum _i X_i} =\frac {1}{\alpha ^2}\sum _i \Var {X_i} =\frac {1}{\alpha ^2} \alpha \nu =\frac {\nu }{\alpha }. \end{equation*}

Guided by Eq. (28.1), we want this quantity to be smaller than \(\leq (\eps ^2/4) \rho ^2\). Thus,

\(\seteqnumber{0}{28.}{1}\)

\begin{equation*} \frac {\nu }{\alpha } \leq (\eps ^2/4) \rho ^2 \qquad \impliedby \qquad \alpha \geq \ceil {\frac {4}{\eps ^2} \cdot \frac {\nu }{\rho ^2} } = \ceil { \frac {4 \Var {X}}{\eps ^2\Ex {X}^2} }. \end{equation*}

We thus summarize the result.

  • Lemma 28.1.1. Let \(\Distribution \) be a non-negative distribution with \(\rho = \Ex {\Distribution }\) and \(\nu = \Var {\Distribution }\), and let \(\eps \in (0,1)\) be a parameter. For \(\displaystyle \alpha \geq \Bigl \lceil { \frac {4 \VarSymb [\Distribution ]\bigr .} {\eps ^2(\ExSym [\Distribution ])^2\bigr .} } \Bigr \rceil ,\)consider sampling variables \(X_1, \ldots , X_\alpha \sim \Distribution \), and let \(Z = \sum _{i=1}^\alpha X_i /\alpha \). Then \(Z\) is a “good” estimator for \(\rho \). Formally, we have

    \(\seteqnumber{0}{28.}{1}\)

    \begin{equation*} \Prob { (1-\eps )\rho \leq Z \leq (1+\eps )\rho \Bigr .} \geq \frac {3}{4}. \end{equation*}

28.1.3 Median estimator: Success with high probability

We would like to get a better estimator, where the probability of success is high probability. Formally, we would have parameter \(\BadProb \), and we would like the estimator to succeed with probability \(\geq 1 - \BadProb \). A natural approach is to try and use Chernoff to bound the probability of failure for the averaging estimator. This would work in some cases, but is limited to the case when \(Z\) lies in a small bounded range. This would not work in general if sampling from \(\Distribution \) might return a huge value with tiny probability. Instead, we are going to boost the averaging estimator. Assume, we generating

\(\seteqnumber{0}{28.}{1}\)

\begin{equation*} \beta = O\Bigl ( \log \frac {1}{\BadProb } \Bigr ) \end{equation*}

instances of the averaging estimators: \(Z_1, \ldots , Z_\beta \) of Lemma 28.1.1. The median estimator returns the median value of the \(Z\)s as the desired estimate.

Analysis.

Let \(\Event _i\) be the event that \(Z_i \in [(1-\eps )\rho , (1+\eps )\rho ]\). Let \(G_i\) be an indicator variable for \(\Event _i\). By Lemma 28.1.1, \(\Prob {\Event _i} = \Prob {G_i=1} \geq 3/4\). The median estimator fails if \(\sum _{i=1}^\beta G_i < \beta /2\). Using Chernoff inequality, we get that this happens with probability \(\leq \BadProb \). We thus get the following.

  • Theorem 28.1.2. Let \(\Distribution \) be a non-negative distribution with \(\mu = \Ex {\Distribution }\) and \(\nu = \Var {\Distribution }\), and let \(\eps , \BadProb \in (0,1)\) be parameters. For some absolute constant \(c >0\), let \(M \geq 24 \Bigl \lceil { \frac {4 \nu \bigr .}{\eps ^2\mu ^2\bigr .} } \Bigr \rceil \ln \frac {1}{\BadProb }\), and consider sampling variables \(X_1, \ldots , X_M \sim \Distribution \). One can compute, in, \(O(M)\) time, a quantity \(Z\) from the sampled variables, such that

    \(\seteqnumber{0}{28.}{1}\)

    \begin{equation*} \Prob { (1-\eps )\mu \leq Z \leq (1+\eps )\mu \Bigr .} \geq 1 - \BadProb . \end{equation*}

  • Proof: Let \(m = \bigl \lceil { {4 \nu }/(\eps ^2\mu ^2) } \bigr \rceil \) and \(M = \ceil {24 \ln \frac {1}{\BadProb }}\). Build \(M\) averaging estimators, each one using \(m\) samples. That is let \(Z_i\) be the average of \(m\) samples \(s_{i,1}, \ldots , s_{i, m}\) from \(\Distribution \), for \(i=1, \ldots , M\). Formally,

    \(\seteqnumber{0}{28.}{1}\)

    \begin{equation*} Z_i = \frac {1}{m} \sum _{j=1}^m s_{i,j} \qquad \text {for}\qquad i=1,\ldots , M. \end{equation*}

    The estimate returned is the value \(\mathrm {median}( Z_1, \ldots , Z_{M} )\).

    By Lemma 28.1.1 each one of the averaging estimator is in the “good” range with probability \(\geq 3/4\). As such, let \(X_i\), for \(i=1,\ldots , M\), be an indicator variable, that is \(1\) if the \(i\)th averaging estimator is in the range \([(1-\eps )\mu ,(1+\eps )\mu ]\). Let \(Y = \sum _{i=1}^{M}X_i\). We have that \(\Ex {Y} \geq (3/4)M.\)As such, by Lemma ??, we have

    \(\seteqnumber{0}{28.}{1}\)

    \begin{equation*} \Prob {\bigl . \text {bad output}} =\Prob {\bigl .Y < (1/2)M} \leq \Prob {\bigl .Y < (1-1/3) \Ex {Y}} \leq \exp \pth { - \frac {(1/3)^2}{2}\Ex {Y}}. \end{equation*}

    The later quantity is bounded by \(\exp \pth { - \frac {1}{18} \frac {3}{4} M} = \exp ( -M/24)= \exp \pth { - \ceil {24 \ln \BadProb ^{-1}} /24 } \leq \BadProb .\)

28.2 Frequency estimation over a stream for the \(k\)th moment

Let \(\STRM = (\strm _1, \ldots , \strm _m)\) be a stream (i.e., sequence) of \(m\) elements from \(N = \{1,\ldots , n\}\). Let \(\frq _i\) be the number of times the number \(i\) appears in \(\STRM \). For \(k \geq 0\), let

\(\seteqnumber{0}{28.}{1}\)

\begin{equation*} \Frq _k=\sum _{i=1}^n \frq _i^k \end{equation*}

be the \(k\)th frequency moment of \(\STRM \). The quantity, \(\Frq _1=m\) is the length of the stream \(\STRM \). Similarly, \(\Frq _0\) is the number of distinct elements (where we use the convention that \(0^0=0\) and any other quantity to the power \(0\) is \(1\)). It is natural to define \(\Frq _\infty = \max _i \frq _i\).

Here, we are interested in approximating up to a factor of \(1\pm \eps \) the quantity \(\Frq _k\), for \(k\geq 1\) using small space, and reading the stream \(\STRM \) only once.

28.2.1 An estimator for the \(k\)th moment
28.2.1.1 Basic estimator

One can pick a representative element from a stream uniformly at random by using reservoir sampling. That is, sample the \(i\)th element \(\strm _i\) to be the representative with probability \(1/i\). Once sampled, the algorithm counts how many times it see the representative value later on in the stream (the counter is initialized to \(1\), to account for the chosen representative itself). In particular, if \(\strm _p\) is the chosen representative in the end of the stream (i.e., the algorithm might change the representative several times), then the counter value is

\(\seteqnumber{0}{28.}{1}\)

\begin{equation*} r = \cardin { \Set {j}{j \geq p \text { and } \strm _j = \strm _p}\Bigr .}. \end{equation*}

The output of the algorithm is the quantity

\(\seteqnumber{0}{28.}{1}\)

\begin{equation*} X = m\, \bigl ( r^k - (r-1)^k \bigr ), \end{equation*}

where \(m\) is the number of elements seen in the stream. Let \(V\) be the random variable that is the value of the representative in the end of the sequence.

28.2.1.2 Analysis

  • Lemma 28.2.1. We have \(\Ex {X}=\Frq _k\).

  • Proof: Observe that since we choose the representative uniformly at random, we have

    \(\seteqnumber{0}{28.}{1}\)

    \begin{equation*} \ExCond {X}{V=i} =\sum _{j=1}^{\frq _i}\frac {1}{\frq _i} m \bigl ( j^k - (j-1)^k \bigr ) =\frac {m}{\frq _i}\sum _{j=1}^{\frq _i} \bigl ( j^k - (j-1)^k \bigr ) =\frac {m}{\frq _i} \frq _i^{k}. \end{equation*}

    As such, we have \(\Ex {X}=\Ex {\bigl .\ExCond {X}{V}} =\sum _{i: \frq _i\neq 0} \frac {\frq _i}{m} \frac {m}{\frq _i} \frq _i^{k} =\sum _{i} \frq _i^{k} =\Frq _k.\)

  • Remark 28.2.2. In the above, we estimated the function \(g(x)=x^k\), over the frequency numbers \(\frq _1, \ldots , \frq _k\), but the above argumentation, on the expectation of \(X\), would work for any function \(g(x)\) such that \(g(0)=0\), and \(g(x) \geq 0\), for all \(x \geq 0\).

  • Lemma 28.2.3. For \(k > 1\), we have \(\sum _{i=1}^n \pth { i^k - (i-1)^k}^2 \leq kn^{2k-1}\).

  • Proof: Observe that for \(x\geq 1\), we have that \(x^k - (x-1)^k \leq kx^{k-1}\). As such, we have

    \(\seteqnumber{0}{28.}{1}\)

    \begin{equation*} \sum _{i=1}^n \pth { i^k - (i-1)^k}^2\leq \sum _{i=1}^n ki^{k-1}\pth { i^k - (i-1)^k}\leq kn^{k-1} \sum _{i=1}^n \pth { i^k - (i-1)^k}=kn^{k-1} n^{k} =kn^{2k-1}. \end{equation*}

  • Lemma 28.2.4. We have \(\Ex {X^2} \leq k m \Frq _{2k-1}\).

  • Proof: By Lemma 28.2.3, we have

    \(\seteqnumber{0}{28.}{1}\)

    \begin{equation*} \ExCond {X^2}{V=i} =\sum _{j=1}^{\frq _i}\frac {1}{\frq _i} m^2 \bigl ( j^k - (j-1)^k \bigr )^2 \leq \frac {m^2}{\frq _i} k \frq _i^{2k-1}=m^2 k \frq _i^{2k-2}, \end{equation*}

    and thus \(\ds \Ex {\smash {X^2}}=\Ex {\bigl .\ExCond {\smash {X^2}}{V}\bigr .} =\sum _{i: \frq _i\neq 0} \frac {\frq _i}{m}\cdot m^2 k \frq _i^{2k-2} = mk \Frq _{2k-1}.\)

  • Lemma 28.2.5. For any non-negative numbers \(\frq _1, \ldots , \frq _n\), and \(k \geq 1 \), we have

    \(\seteqnumber{0}{28.}{1}\)

    \begin{equation*} \sum _{i=1}^n \frq _i \leq n^{(k-1)/k} \Bigl ( \sum _{i=1}^n \frq _i^k\Bigr )^{1/k}. \end{equation*}

  • Proof: This is immediate from Hölder inequality, but here is a self contained proof. The above is equivalent to proving that \(\sum _i \frq _i/n \leq \Bigl ( \sum _{i=1}^n \frq _i^k/n \Bigr )^{1/k} \). Raising both sides to the power \(k\), we need to show that \(\pth {\sum _i \frq _i/n}^k \leq \sum _{i=1}^n \frq _i^k/n\). Setting \(g(x)=x^k\), we have \(g \pth {\sum _i \frq _i/n} \leq \sum _{i=1}^n g(\frq _i)/n\). The last inequality holds by the convexity of the function \(g(x)\) (indeed, \(g'(x) = kx^{k-1}\) and \(g''(x) = k(k-1)x^{k-2} \geq 0\), for \(x \geq 0\)).

  • Lemma 28.2.6. For any \(n\) numbers \(\frq _1, \ldots ,\frq _n \geq 0\), we have \(\Bigl ({\sum _i \frq _i} \Bigr ) \Bigl ( \sum _i \frq _i^{2k-1} \Bigr ) \leq n^{1-1/k} \Bigl (\sum _i \frq _i^{k}\Bigr )^2.\)

  • Proof: Let \(M =\max _i \frq _i\) and \(m = \sum _i f_i\). We have

    \(\seteqnumber{0}{28.}{1}\)

    \begin{align*} \sum _i \frq _i^{2k-1} &\leq M^{k-1} \sum _i \frq _i^{k} \leq M^{k(k-1)/k} \sum _i \frq _i^{k} \leq \Bigl (\sum _i \frq _i^k\Bigr )^{(k-1)/{k}} \sum _i \frq _i^{k} \leq \Bigl (\sum _i \frq _i^k\Bigr )^{(2k-1)/{k}}. \end{align*} By Lemma 28.2.5, we have \(\sum _{i=1}^{n} \frq _i \leq n^{(k-1)/k} \Bigl ( \sum _i \frq _i^k\Bigr )^{1/k}.\)Multiplying the above two inequality implies the claim.

  • Lemma 28.2.7. We have \(\Var {X} \leq k n^{1-1/k} \Frq _k^2\).

  • Proof: Since \(m = \sum _i \frq _i\), Lemma 28.2.4 and Lemma 28.2.6 together implies that

    \(\seteqnumber{0}{28.}{1}\)

    \begin{equation*} \Var {X}=\Ex {X^2} - (\Ex {X})^2 \leq \Ex {X^2}\overbrace {\leq }^{\text {\lemrefshort {f:e:exp:X}}} k m \Frq _{2k-2}=k \Bigl ({\sum _i \frq _i} \Bigr ) \Bigl ( \sum _i \frq _i^{2k-1} \Bigr ) \overbrace {\leq }^{\text {\lemrefshort {f:e:simplify}}} k n^{1-1/k} \Frq _k^2. \end{equation*}

28.2.2 An improved estimator: Plugin

We have an estimator for \(F_k\) using constant space \(O(1)\). Specifically, \(\mu = \Ex {X} = F_k\) see Lemma 51.1.1, and \(\nu = \Var {X} \leq k n^{1-1/k} \Frq _k^2\). Let

\(\seteqnumber{0}{28.}{1}\)

\begin{equation*} M = 24 \Bigl \lceil { \frac {4 \nu \bigr .}{\eps ^2\mu ^2\bigr .} } \Bigr \rceil \ln \frac {1}{\BadProb } \end{equation*}

We compute \(M\) estimators as the above (in parallel on the stream), and combine them as specified by Theorem 28.1.2, to get a new estimate \(Z\). We have that

\(\seteqnumber{0}{28.}{1}\)

\begin{equation*} \Prob { (1-\eps )\mu \leq Z \leq (1+\eps )\mu \Bigr .} \geq 1 - \BadProb . \end{equation*}

Thus, the amount of space this streaming algorithm is using is proportional to \(M\), and we have

\(\seteqnumber{0}{28.}{1}\)

\begin{equation*} M = O\pth {\frac { \nu \bigr .}{\eps ^2\mu ^2\bigr .} \ln \frac {1}{\BadProb } } =O\pth {\frac { k n^{1-1/k} \Frq _k^2 }{\eps ^2\Frq _k^2\bigr .} \ln \frac {1}{\BadProb } } =O\pth {\frac { k n^{1-1/k} }{\eps ^2} \ln \frac {1}{\BadProb } }. \end{equation*}

We thus proved the following.

In the following, we consider a computer word to be sufficiently large to contain \(\lg n\) or \(\lg m\) bits. This readily implies the following.

  • Theorem 28.2.8. Let \(\STRM =(\strm _1, \ldots , \strm _n)\) be a stream of numbers from the set \(\{1,\ldots , n\}\). Let \(k \geq 1\) be a parameter. Given \(\eps , \BadProb \in (0,1)\), one can build a data-structure using \(O( kn^{1-1/k}\eps ^{-2} \log \BadProb ^{-1})\) words, such that one can \((1\pm \eps )\)-approximate the \(k\)th moment of the elements in the stream; that is, the algorithm outs a number \(Z\), such that \((1-\eps )\Frq _k \leq Z \leq (1+\eps )\Frq _k\), where \(\Frq _k = \sum _{i=1}^n \frq _i^k\), and \(\frq _i\) is the number of times \(i\) appears in the stream \(\STRM \). The algorithm succeeds with probability \(\geq 1- \BadProb \).

28.3 Better estimation for \(\Frq _2\)

28.3.1 Pseudo-random \(k\)-wide independent sequence of signed bits

In the following, assume that we sample \(O( \log n)\) bits, such that given an index \(i\), one can compute (quickly!) a random signed bit \(b(i) \in \brc {-1,+1}\). We require that the resulting bits \(b(1), b(2), \ldots , b(n)\) are \(4\)-wise independent. To this end, pick a prime \(p\), that is, say bigger than \(n^{10}\). This can easily be done by sampling a number in the range \([n^{10}, n^{11}]\), and checking if it is prime (which can done in polynomial time).

Once we have such a prime, we generate a random polynomial \(g(i) = \sum _{i=0}^5 c_i x^i \bmod p\), by choosing \(c_0, \ldots , c_5\) from \(\ZZ _p = \brc {0, \ldots , p-1 \bigl . }\). We had seen that \(g(0), g(1), \ldots , g(n)\) are uniformly distributed in \(\ZZ _p\), and they are, say, \(6\)-wise independent (see Theorem 8.2.10).

We define

\(\seteqnumber{0}{28.}{1}\)

\begin{equation*} b(i)=\begin{cases} 0 & g(i) = p-1 \\ +1 & g(i) \text { is odd}\\ -1 & g(i) \text { is even}. \end {cases} \end{equation*}

Clearly, the sequence \(b(1), \ldots , b(n)\) are \(6\)-wise independent. There is a chance that one of these bits might be zero, but the probability for that is at most \(n/p\), which is so small, that we just assume it does not happen. There are known constructions that do not have this issue at all (one of the bits is zero), but they are more complicated.

  • Lemma 28.3.1. Given a parameter \(\BadProb \in (0,1)\), in polynomial time in \(O(\log (n/\BadProb ))\), one can construct a function \(b(\cdot )\), requiring \(O( \log (n/\BadProb ))\) bits of storage (or \(O(1)\) words), such that \(b(1), \ldots , b(n) \in \{-1,+1\}\) with equal probability, an they are \(6\)-wise independent. Furthermore, given \(i\), one can compute \(b(i)\) in \(O(1)\) time.

    The probability of this sequence to fail having the desired properties is smaller than \(\BadProb \).

  • Proof: We repeat the above construction, but picking a prime \(p\) in the range, say, \(n^{10}/ \BadProb \ldots n^{11} /\BadProb \).

28.3.2 Estimator construction for \(\Frq _2\)
28.3.2.1 The basic estimator

As before we have the stream \(\STRM = \strm _1.\ldots , \strm _m\) of numbers from the set \(1, \ldots , n\). We compute the \(6\)-wise independent sequence of random bits of Lemma 28.3.1, and in the following we assume this sequence is good (i.e., has only \(-1\) and \(+1\) in it). We compute the quantity

\(\seteqnumber{0}{28.}{1}\)

\begin{equation*} T = \sum _{i=1}^m b(i) \frq _i=\sum _{j=1}^m b( \strm _j), \end{equation*}

which can be computed on the fly using \(O(1)\) words of memory, and \(O(1)\) time per time in the stream.

The algorithm returns \(X = T^2\) as the desired estimate.

Analysis.

  • Lemma 28.3.2. We have \(\Ex {X} = \sum _i \frq _i^2 = \Frq _2\) and \(\Var {X} \leq 2 \Frq _2^2\).

  • Proof: We have that \(\Ex {X} = \Ex {\smash { \Bigl ( \sum _{i=1}^n b(i) \frq _i \Bigr )^2} \Bigr .},\)and as such

    \(\seteqnumber{0}{28.}{1}\)

    \begin{equation*} \Ex {X}=\Ex {\Bigr . \smash { \sum _{i=1}^n (b(i))^2 \frq _i^2 + 2\sum _{i < j} b(i) b(j) \frq _i \frq _j}}=\sum _{i=1}^m \frq _i^2 + 2\sum _{i < j} \frq _i \frq _j \Ex { b(i) b(j)}=\sum _{i=1}^m \frq _i^2 =\Frq _2, \end{equation*}

    since \(\Ex {b(i)} = 0\), \(\Ex {b(i)^2} =1\), and \(\Ex {b(i)b(j) } = \Ex {b(i) } \Ex {b(j)} = 0\) (assuming the sequence \(b(1), \ldots , b(n)\) has not failed), by the \(6\)-wise Independence of the sequence of signed bits.

    We next compute \(\Ex {X^2}\). To this end, let \(N = \{1,\ldots , n\}\), and \(\Gamma = N\times N \times N \times N\). We split this set into several sets, as follows:

    • (i) \(\Gamma _0 = \brc {(i,i,i,i) \in N^4}\): All quadruples that are all the same value.

    • (ii) \(\Gamma _{1}\): Set of all quadruples \((i,j,k,l)\) where there is at least one value that appears exactly once.

    • (iii) \(\Gamma _{2}\): Set of all \((i,j,k,\ell )\) with only two distinct values, each appearing exactly twice.

    Clearly, we have \(N^4 = \Gamma _0 \cup \Gamma _1 \cup \Gamma _2\).

    For a tuple \((i,i,i,i) \in \Gamma _0\), we have \(\Ex {b(i) b(i) b(i) b(i)}=\Ex {b(i)^4}=1.\)

    For a tuple \((i,j,k,\ell ) \in \Gamma _1\) with \(i\) being the unique value, we have that

    \(\seteqnumber{0}{28.}{1}\)

    \begin{equation*} \Ex {b(i) b(j) b(k) b(\ell )} =\Ex {b(i)} \Ex { b(j) b(k) b(\ell )} =0 \Ex { b(j) b(k) b(\ell )} =0, \end{equation*}

    using that the signed bits are \(4\)-wise independent.

    For a tuple \((i,i,j,j) \in \Gamma _2\), we have \(\Ex {b(i) b(i) b(j) b(j)}=\Ex {b(i)^2 b(j)^2}=\Ex {b(i)^2} \Ex { b(j)^2} =1,\)and the same argumentation applies to any tuple of \(\Gamma _2\). Observe that for any \(i <j\), there are \(\binom {4}{2} = 6\) different tuples in \(\Gamma _2\) that are made out of \(i\) and \(j\). As such, we have

    \(\seteqnumber{0}{28.}{1}\)

    \begin{align*} \Ex {X^2} &= \Ex {\smash { \Bigl ( \sum _{i=1}^n b(i) \frq _i \Bigr )^4} \Bigr .}=\Ex {\Bigr . \smash { \sum _{(i,j,k,\ell ) \in \Gamma } b(i)b(j) b(k) b(\ell ) \frq _i\frq _j \frq _k \frq _\ell } } \\[0.3cm] &=\sum _{(i,i,i,i) \in \Gamma _0} \Ex {b(i)^4} \frq _i^4 + \sum _{(i,j,k,\ell ) \in \Gamma _1} \frq _i\frq _j \frq _k \frq _\ell \Ex {b(i) b(j) b(k) b(\ell )} + 6 \sum _{i < j } \Ex {b(i)^2 b(j)^2} \frq _i^2 \frq _j^2 \\[0.3cm] &=\sum _{i=1}^n \frq _i^4 + 6 \sum _{i < j } \frq _i^2 \frq _j^2. \end{align*} As such, we have

    \(\seteqnumber{0}{28.}{1}\)

    \begin{equation*} \Var {X}=\Ex {X^2} - \pth {\Ex {X}}^2= \sum _{i=1}^n \frq _i^4 + 6 \sum _{i < j } \frq _i^2 \frq _j^2 - \Bigl ( \sum _{i=1}^m \frq _i^2 \Bigr )^2 =4 \sum _{i < j } \frq _i^2 \frq _j^2 \leq 2 \Frq _2^2. \end{equation*}

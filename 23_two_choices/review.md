## Summary of findings
The results are all true (and standard), but the proofs have real holes. The central Lemma `how:betas:behave` has an invalid coupling construction, conditions on a terminal event when bounding per-ball probabilities, and proves part (C) by an independence argument that does not exist in this single-run process; the standard ABKU device fixes all three at once (E1, G1, E2). The many-rows Section 1 argument as written only yields about 2 lg lg n rounds (G2), Lemma `strong:conc:3` uses Chernoff without independence and Jensen in the wrong direction (G3, G4), and the go-left sketch applies the row game at heights where it does not model the process (G5). Lemma `strong:conc` can be collapsed to a single, stronger bound (S1). The "Regular" column of the simulation table and the "13" in the introduction look like an RNG artifact (U1).

## Details

### E1 / G1. Coupling and conditioning in `how:betas:behave` (A)
With `tau_j = Pr[Y_j = 1]` marginal and `Y'_j = 1` if `Y_j = 1`, else with probability `p_i - tau_j`: `Pr[Y'_j = 1] = tau_j + (1 - tau_j)(p_i - tau_j) = p_i - tau_j(p_i - tau_j) < p_i` for `0 < tau_j < p_i` (e.g. `tau = 1/10, p = 3/10` gives `7/25`). The correct extra probability is `(p_i - tau_j)/(1 - tau_j)`. Independence fails because `Y'_j = Y_j or W_j` inherits the dependence of the `Y_j` (toy: `Y_1 = Y_2 ~ Bern(1/10)`, `p = 3/10`: `Pr[Y'_1 = Y'_2 = 1] = 17/125 != (7/25)^2`).

Conditioning on `G_i` is the deeper problem. Exact enumeration, `n = 3`, `d = 2`, 3 balls with replacement, first probe wins ties, level `i = 1`, `beta_1 = 2`, `p_1 = 4/9`: after two balls the state is (2,0,0) w.p. 1/9 or (1,1,0) w.p. 8/9; `Pr[G] = 41/81`, `Pr[Y_3 = 1 and G] = 33/81 <= 4/9` but `Pr[Y_3 = 1 | G] = 33/41 ~ 0.80 > 4/9`. Conditioning on the terminal good event biases earlier balls toward collisions. (Toy regime only; in the lemma's regime the distortion is at most `1/Pr[G_i]`, so the conclusion survives.)

Fix (ABKU Lemma 3.1 / Mitzenmacher-Upfal Thm 14.1): fix `i`; let `Y_t = 1` iff `h(t) >= i+1` and `bins_{>= i}(t-1) <= beta_i`. Then `Pr[Y_t = 1 | history] = 1{bins_{>= i}(t-1) <= beta_i} (bins_{>= i}(t-1)/n)^d <= p_i` for every history; couple with `q_t = Pr[Y_t = 1 | history]` and extra probability `(p_i - q_t)/(1 - q_t)` to get i.i.d. `Bern(p_i)` variables `Y'_t >= Y_t`. Since `bins_{>= i}(t-1)` is nondecreasing in `t`, on `G_i` all indicators coincide with `1{h(t) >= i+1}`, so `sum Y_t = balls_{>= i+1}(n) >= bins_{>= i+1}(n)` and `Pr[B_{i+1} and G_i] <= Pr[Bin(n, p_i) > 2 n p_i] < exp(-beta_{i+1}/8) <= n^{-2c}`. Same for (B) at level `I` with threshold `Delta`. No conditioning anywhere.

### E2. Part (C): replacing `q^j`
Let `Z_j` be the number of balls `t` with `h(t) >= I+1+j` and `bins_{>= I+1}(t-1) <= Delta`. A ball has height `>= I+1+j` iff all `d` probes hit bins of load `>= I+j` at time `t-1`; on the prefix-good event every such bin was created by a ball counted in `Z_{j-1}`, so their number is at most `min(Delta, Z_{j-1})` (pointwise, with `Z_{j-1}` the final restricted count; one bounds the random summand first and then takes expectations). Using `x^d <= Delta^{d-1} x` on `[0, Delta]`:
`E[Z_j] <= n * n^{-d} E[min(Delta, Z_{j-1})^d] <= Delta^{d-1} n^{1-d} E[Z_{j-1}]`, with `E[Z_1] <= n (Delta/n)^d`. Hence `E[Z_j] <= Delta^{(d-1)j+1} / n^{(d-1)j}`, and on `{bins_{>= I+1}(n) <= Delta}` we have `Z_j = balls_{>= I+1+j}(n) >= bins_{>= I+1+j}(n)`, so
`Pr[bins_{>= I+1+j}(n) > 0] <= Pr[not G_I] + Pr[bins_{>= I+1}(n) > Delta and G_I] + E[Z_j] <= n^{-c} + O(n^{-(d-1-eps)j})`.
(C) therefore holds up to the additive `n^{-c}` term (or on the good event); (D) follows with `eps = 1/2`, `j = ceil(2c)`.

### E3. Bookkeeping
Chain rule: `Pr[G_I] = Pr[G_4] prod_{l=4}^{I-1} Pr[not B_{l+1} | G_l]`, and `Pr[G_4] = 1` by Observation `t:c:stupid`. The paper's factor for `l = I+1` concerns `B_{I+2}`; and `not B_{I+1} = {bins_{>= I+1}(n) <= beta_{I+1}}` is not controlled by (A) (Chernoff gives only `exp(-beta_{I+1}/8)`, not small) nor by (B) (which gives `<= Delta`); for `n = 1e9, d = 2, c = 2`: `beta_9 = 0.116`, so `not B_9` would mean maximum load `<= 8`, unproven. With the ABKU device the clean statement is the union bound `Pr[not (G_I and {balls_{>= I+1}(n) <= Delta})] <= (I-4) n^{-2c} + 2^{-Delta} <= n^{-c}` for `n` large, using `I <= 3 + ceil(log_d lg n)` rather than `I <= n`.

### E5. Constant in `strong:conc` (C)
`2 exp(-3cm ln n / 2m) = 2 n^{-3c/2} <= n^{-c}` iff `n^{c/2} >= 2`. Failures: `c = 1, n = 2`: `0.707 > 0.5`; `c = 1, n = 3`: `0.385 > 0.333`; `c = 1/2, n = 15`: `0.262 > 0.258`. Replacing `3` by `4` still needs `n^c >= 2`.

### G2. Concentration in the many-rows argument
Lemma `strong:conc` (C) gives `n_{i+1} = n_i - s_i` only within `+- sqrt(3 c n_i ln n)`; this exceeds the main term `n alpha_i^2` once `alpha_i^3 < 3c ln n / n`, i.e. `n_i < n^{2/3}(3c ln n)^{1/3}`. For `n = 1e9` the crossover is at `n_i ~ 2.7e6` (main term 7545 vs error 13068). Iterating the lemma-certified recurrence `n_{i+1} = n_i(1 - e^{-n_i/n}) + 1 + sqrt(3 n_i ln n)` until `n_i <= 10 ln n`: rounds 7-8 (n = 1e6), 9 (1e9), 9-10 (1e12), 11 (1e18), 12-13 (1e30), against `lg lg n` = 4.3, 4.9, 5.3, 5.9, 6.6: the difference grows, so the argument as written gives about `2 lg lg n`, not `lg lg n + Theta(1)`. (The noise-free recurrence `n_{i+1} = n_i - n(1 - e^{-n_i/n})` needs 4-6 rounds, and simulation at `n = 1e6` gives 4-5: the theorem is right.)

Fix: in row `i` bins are fresh and hold one ball, so ball `j` is rejected iff an earlier ball of the row chose its bin: `Pr[rejected | history] <= (j-1)/n <= n_i/n`. Hence `R_i` (rejections) is stochastically dominated by `Bin(n_i, n_i/n)`, and Chernoff gives `R_i <= 2 n_i^2/n` w.h.p. while `n_i^2/n >= C log n`, and `R_i <= 2C log n` w.h.p. otherwise. This carries the squaring down to `n_i ~ sqrt(n log n)`; one more row leaves `O(log n)` balls, and the collision paragraph (lines 219-223) finishes with `O(c)` extra rows. The same domination replaces the Chernoff step in `strong:conc:3` (A) (G3).

### G3. `strong:conc:3` (A) at large d
Counterexample to the statement at the critical `d`: `alpha = 2^{-20}`, `n = floor(0.9 * 2^30) = 966,367,641`, `d = 1`: the bound `n alpha^{3/2} = 0.9 < 1` asserts `Y = 0` w.h.p., but the `k = 921` balls collide with probability `~ 1 - exp(-k(k-1)/2n) ~ 4.4e-4 = n^{-0.37}`, not `n^{-c}` for any `c >= 1`. Under the hypothesis `n alpha^{(2^d+1)/2} >= C log n`, each step has mean `>= C log n / 2`, domination plus Chernoff gives failure `<= n^{-C/6}` per row, and a union bound over `d` rows closes the proof.

### G4. `strong:conc:3` (C), Jensen direction
`h(N) = n(1 - (1-1/n)^N)` is concave, so `E[h(N)] <= h(E N)`: with `N in {n/2, 3n/2}` equiprobable, `E N = n` but the mean stored fraction is `(0.3935 + 0.7769)/2 = 0.585 < 1 - 1/e = 0.632`. Arrivals are `>= n` deterministically only for `i <= c log d`, while phase 1 uses the rate up to `i = D - 1 ~ 1.58 c log d` (e.g. `d = 100, c = 1.5`: deterministic for `i <= 6`, used up to `i = 10`). Phase 2 needs `psi(k) = k - h(k) <= k/e`, true for `k <= n` but false for `k > n` (`psi(2n) = 1.135 n > 0.736 n`), and `psi` is convex, so `E psi(N_D) >= psi(E N_D)`. The corrected inequality `psi(k) <= k/e + (1 - 1/e)(k - n)^+` holds for all `k`, but one still needs `E[(N_D - n)^+]` small, i.e. concentration: run both phases on the event of Lemma `strong:conc` (C) at every row (failure contributes `<= m n^{-c}` to the expectation). The conclusion `E Y <= n/e^{d/2}` is true.

### S1. One bound for Lemma `strong:conc`
Per bin, `Pr[empty] = (1 - 1/n)^m`, so `mu = n(1 - (1-1/n)^m)` exactly, for every `m` (this is the proof of (B), which never uses `alpha >= 1`). Then `(1-1/n)^m <= e^{-alpha}` gives `mu >= n(1 - e^{-alpha})`, and `f(x) = 1 - e^{-x} - x + x^2/2` has `f(0) = 0`, `f' = e^{-x} - 1 + x >= 0`, so `mu >= alpha n - alpha^2 n / 2`. Domination of (A): `n(1 - e^{-a}) - (m - a)e^{-a} = n(1 - (1+a)e^{-a}) + a e^{-a} >= 0` for all `a >= 0` since `(1+a)e^{-a}` is decreasing from 1 (checked on a grid of 1000 values of `alpha`, minimum ratio 1.0005 at `alpha = 0.001`). Gains: delete the backward-analysis chain (lines 91-124) and the Remark (158-162); the carried-over count becomes `n alpha - mu <= n(alpha - 1 + e^{-alpha}) <= n alpha^2/2`, so Section 1's recursion is `alpha_{i+1} <= alpha_i^2/2` and `strong:conc:3` (A) can use `gamma_i = gamma_{i-1}^2` (expectation `alpha^2/2`, Chernoff slack 2), giving `gamma_{d+1} = alpha^{2^d}` directly and removing Lemma `fast:dec` and the `alpha <= 1/4` hypothesis. The mis-citation at line 299-300 ("by Lemma strong:conc, at least `n alpha e^{-alpha}`", whereas (A) gives `(m - alpha)e^{-alpha}`) disappears too.

### U1. Simulation table
Columns sum exactly to 1e9 bins and 1e9 balls, so no transcription error. Regular column vs `n * Poisson(1)`: load 0: 369,899,815 vs 367,879,441 (z ~ +105); load 1: z ~ -103; load 4: ratio 1.028; load 8: 1.28; load 10: 1.41; load 12: 2 vs 0.77; load 13: 2 vs 0.06. The model "bin = rand32() % 1e9" (bins below 294,967,296 get probability 5/2^32, the rest 4/2^32) predicts load 0: 369,890,535 (z = +0.5) and thirteen of fourteen rows within |z| <= 1.7; a 31-bit generator does not fit. The qualitative conclusions (maximum 4 for both variants; go-left has fewer load-3 bins, 0.0045 vs 0.0089) hold in the uniform simulation.

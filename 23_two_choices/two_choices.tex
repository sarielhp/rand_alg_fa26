\bigskip%
\noindent%
Consider the problem of throwing $n$ balls into $n$ bins. It is well
known that the maximum load is $\Theta( \log n / \log \log n)$ with high
probability. Here we show that if one is allowed to pick {$d \geq 2$ bins
   for each ball, and throw it into the one among them that contains the
   fewest balls,} then the maximum load of a bin decreases to
$\Theta( \log \log n/ \log d)$. A variant of this approach leads to a maximum
load of {$O(1) + (\log \log n)/ d$.}

As a concrete example, for $n=10^9$ the maximum load is $13$ with a
single choice (the regular case), compared to $4$ with two choices---see
\figref{n:bins:2:choices}.

\section{Balls and bins with many rows}
\seclab{balls:many:rows}%

\subsection{The game}

Consider throwing $n$ balls into $n$ bins. Every bin can contain a
single ball. As such, as we throw the balls, some balls are
rejected because their assigned bin already contains a ball. We
collect all the rejected balls, and throw them again into a second row
of $n$ bins. We repeat this process until all the balls have found a
good and loving home (i.e., an empty bin). How many rows does one need
before this process is completed?

\subsection{Analysis}

\begin{lemma}
    \lemlab{strong:conc}%
    %
    Let $m = \alpha n$ balls be thrown into $n$ bins.  Let $\Yend$ be the
    number of bins that are not empty after all $m$ balls are thrown
    (here a bin may receive several balls; there are no rejections).
    \begin{compactenumA}
        \item For $\alpha \geq 0$, we have
        \begin{equation*}
            \mu%
            =%
            \Ex{\Yend}%
            \geq %
            \alpha n - \frac{\alpha^2}{2} n.
        \end{equation*}

        \item For $n \geq 4$ and  $c > 1$, we have
        \begin{math}
            \Bigl.  \Prob{\Bigl.\cardin{\Yend - \mu} > \smash{\sqrt{3
                     c m \log n}}} %
            \leq%
            1/n^c.
        \end{math}
    \end{compactenumA}
\end{lemma}
\begin{proof}
    (A) The probability that a bin is empty is $(1-1/n)^{\alpha n}$. As
    such, we have that
    \begin{align*}
        \mu %
        &\EQ%
        \Ex{\Yend}%
        \EQ%
        n\pth{ 1-(1-1/n)^{\alpha n}}%
        \\&
        \GEQ%
        n\pth{ 1-\exp\pth{-1/n}^{\alpha n}}%
        =%
        n\pth{ 1-\exp\pth{ -\alpha }}
        \\&
        \GEQ %
        n\pth{ \alpha - \frac{\alpha^2}{2}},        
    \end{align*}
    using $1-1/n \leq \exp(-1/n)$ and
    \begin{math}
        \exp(-x)
        \leq
        1 - x + \frac{x^2}{2},
    \end{math}
    for $x \geq 0$.

    
    \medskip%
    (B) Let $X_i$ be the index of the bin the $i$\th ball picked. Let
    $Y_i = \ExCond{\Yend}{X_1, \ldots, X_i}$. This is a Doob
    martingale, with $|Y_i - Y_{i-1}| \leq 1$. As such,
    \thmrefY{Azuma's inequality}{\si{azuma:ineq:s:f}} implies, for
    $\lambda = \sqrt{ 3c m \ln n}$, that
    \begin{equation*}
        \Prob{ \bigl. \cardin{\Yend - \Ex{\Yend}} \geq \lambda}%
        \leq%
        2\exp \pth{-\lambda^2/ 2m}%
        \leq%
        1/n^c.
    \end{equation*}
\end{proof}%


\paragraph*{Back to the problem.}

Let $n_i$ be the number of balls thrown in the $i$\th round, so
$n_1 = n$. We track an idealized ratio $\alpha_i$, with $\alpha_1 = 1$, such that
$n_i \approx \alpha_i n$. Inductively, assume that for $i>1$
\begin{equation*}
    n_i = \alpha_i n + O( \sqrt{ \alpha_{i-1} n \log n} ). 
\end{equation*}
By \lemref{strong:conc}, with high probability, the number of balls
stored in the $i$\th row is
\begin{equation*}
    s_i
    \GEQ
    \alpha_i n - \frac{\alpha_i^2}{2} n - O(\sqrt{n_i  \log n})
    \GEQ
    \alpha_i n - \alpha_i^2 n.
\end{equation*}
The last inequality is correct only if $\alpha_i$ is sufficiently large
(roughly $\alpha_i \geq 1/n^{1/3}$), but lets just ignore this issue (it can
easily be resolved but it really not worth the technical tedium it
requires to resolve right now), but we will assume (for our sins) that it
is correct throughout. Thus, we have
\begin{equation*}
    n_{i+1} \EQ n_i - s_i%
    \LEQ%a
    n \alpha_i^2.
\end{equation*}
\begin{defn}
    For a number $x > 0$, we use $\lg x = \log_2 x$.
\end{defn}

\begin{observation}
    Consider the sequence $\alpha_1 =1$, $c = \alpha_2=1-1/e$, and
    $\alpha_{i+1} = \alpha_i^2$, for $i \geq 2$. We have that
    $\alpha_i = c^{2^{i-2}}$. In particular, for
    \begin{equation*}
        \Delta%
        =%
        3 + \lg \log_{1/c} n
        =%
        3 + \lg \frac{\lg n}{\lg (1/c)}
        =
        3 + \lg \lg n  - \lg\lg \frac{1}{1-1/e},
    \end{equation*}
    we have that $\alpha_\Delta = c^{2^{\Delta-2}} < 1/n$.%
\end{observation}

The above observation almost implies that $\Delta$ rows suffice. The
problem is that the above calculations (i.e., the high probability
guarantee in \lemref{strong:conc}) break down when $n_i = O(\log n)$
---that is, when $\alpha_i = O((\log n) / n)$. However, if one throws
$O( \log n)$ balls into $n$ bins, the probability of a single collision
is at most $O( (\log n)^2/n)$. Repeating this for $O(c)$ additional rows, the
probability that any ball is left is at most $1/n^c$.

Done carefully, the above argument implies the following theorem. We omit
the details, since essentially the same analysis is done next in a more
involved setting; the matching lower bound follows from the same
argument.

\begin{theorem}
    Consider the process of throwing $n$ balls into $n$ bins in several
    rounds. Here, any ball that cannot be placed in a round, because its
    chosen bin is already occupied, is promoted to the next round. The
    next round throws all the rejected balls from the previous round into
    a new row of $n$ empty bins.  With high probability, all balls are
    placed within $M = \lg \lg n +\Theta(1)$ rounds, and
    $\lg \lg n - O(1)$ rounds do not suffice.
\end{theorem}

\subsection{With only $d$ rows}


\begin{lemma}
    \lemlab{fast:dec}%
    %
    For $\alpha \in (0,1/4]$, let $\gamma_1 = \alpha$, and
    $\gamma_i = 2 \gamma_{i-1}^2$. We have that
    $\gamma_{d+1} \leq \alpha^{(2^{d} + 1)/2}$.
\end{lemma}
\begin{proof}
    The proof, minimal as it may be, is by induction on $i$, showing that
    $\gamma_i \leq \alpha^{(2^{i-1}+1)/2}$ (the case $i=1$ is trivial):
    \begin{equation*}
        \gamma_{i+1}%
        =%
        2 \gamma_i^2 %
        \leq%
        2 \pth{\alpha^{(2^{i-1} + 1)/2}}^2
        =%
        2 \alpha^{(2^{i} + 2)/2}
        \leq%
        \alpha^{(2^{i} + 1)/2},
    \end{equation*}
    since $2\sqrt{\alpha} \leq 1$.
\end{proof}
    

\begin{lemma}
    \lemlab{strong:conc:3}%
    %
    Consider a matrix of $d$ rows with $n$ bins each, and throw $m$ balls
    into it one by one. Every bin can contain only a single ball; a ball
    that finds its chosen bin in the $i$\th row occupied is thrown into
    the next row, and so on, until it finds an empty bin, or it is
    rejected because it failed on the $d$\th row. Let $Y(d,n, m)$ be the
    number of balls that did not get stored in this matrix of bins. We
    have
    \begin{compactenumA}
        \item For $m = \alpha n$, where $\alpha \leq 1/4$ is a constant,
        we have $Y(d,n, \alpha n ) \leq n \alpha^{(2^{d} + 1)/2}$, with high
        probability.

        \item \itemlab{strong:c:3:B} For $m = dn$ balls, we have
        $\Ex{\bigl. Y(d,n, dn)} = O( n \log d) $.

        \item For a constant $c>1$ and $m = c n \log d$ balls, we have
        \[
            \Ex{\bigl. Y(d,n, c n \log d ) }
            \leq%
            n/e^{d/2},
        \]
        assuming $d$ is sufficiently large (so that $D \leq d/2$ in
        the proof below).
    \end{compactenumA}
\end{lemma}

\begin{proof}
    (A) By \lemref{strong:conc}, in expectation, at least
    $s_1 = n\alpha \exp(-\alpha)$ balls are placed in the first row. As such, in
    expectation $n_2 = n \alpha (1 - \exp( -\alpha)) \leq n\alpha^2$ balls get thrown into
    the second row. Using Chernoff's inequality, we get that
    $n_2 \leq 2 \alpha^{2}n$, with high probability. (Why Chernoff's
    inequality can be applied here requires an argument, which we leave
    as an exercise for the reader.)
    Setting $\gamma_1 = \alpha$, and $\gamma_i = 2 \gamma_{i-1}^2$, we get the
    claim (the number of balls rejected by row $d$ is at most
    $\gamma_{d+1} n$) via \lemref{fast:dec}.

    
    (B) As long as we throw $\Omega( n \log d)$ balls into a row, we
    expect by \lemref{strong:conc} that at least $n(1-1/d^{O(1)})$
    balls get stored in this row. As such, let $D = O(\log d )$,
    and observe that the first $d-D$ rows in expectation contain
    $n(d-D)(1-1/d^{O(1)})$ balls. This implies that only $O(D n)$ balls are
    not stored in these first $d-D$ rows, which implies the claim.


    (C) Break the $d$ rows into two groups. The first group of size
    \begin{equation*}
        D= \ceil{(c \log d-1)/(1-1/e)} + 1 = O(\log d),
    \end{equation*}
    and the second group is the remaining rows. As long as the number of
    balls arriving at a row is larger than $n$, we expect at least
    $n(1-1/e)$ balls to be stored in that row. As such, after the first
    $D$ rows, we expect the number of remaining balls to be $\leq
    n$. Indeed, after $i$ rows, then the expected number of balls moving
    on to the $(i+1)$\th row is at most
    \begin{equation*}
        n_{i+1} = cn \log d - i n(1-1/e).
    \end{equation*}
    Solving for $n_{i+1} \leq n$, we have
    \begin{math}
        cn \log d - i n(1-1/e) \leq n \implies i (1-1/e) \geq c \log
        d-1 \implies i \geq (c \log d-1)/(1-1/e) \geq D - 1.
    \end{math}    
    As such, $n_i \leq n$, for $i \geq D$.
    
    Applying the same calculation to the second group, the number of
    balls arriving at the $(D+i)$\th row, in expectation, is at most
    $n/e^i$. In particular, we get that the number of balls that fail to
    be placed is at most $n/e^{d-D} \leq n/e^{d/2}$.
\end{proof}

\section{The power of two choices}
\seclab{power:2:choices}%

\paragraph*{Making $d$ choices.}
Let us throw $n$ balls into $n$ bins. For each ball, we first pick
randomly $d\geq 2$ bins, and place the ball in the bin (among these $d$
bins) that currently contains the smallest number of balls (here, a bin
might contain an arbitrary number of balls). If there are several bins
with the same minimum load, we resolve it arbitrarily.

Here, we will show that the maximum number of balls in any bin is bounded
by $O\bigl( \tfrac{\log \log n}{\log d} \bigr)$ with high probability at
the end of this process. For $d=1$, which is the regular balls into bins
setting, we have already seen that this quantity is
$\Theta\bigl( \tfrac{\log n}{ \log \log n}\bigr)$, so this result is quite
surprising.

\begin{defn}
    The \emphOnly{load}\index{load} of a bin is the number of balls in it. The
    \emphOnly{height}\index{height} of a ball is the load of the bin it was inserted
    into, just after it was inserted.
\end{defn}

\begin{lemma}
    \lemlab{beta:i:good}%
    %
    For \chgY{$i=4,\ldots, I$}{every $i \geq 4$}, we have that $\beta_i \leq n/2^{d^{i-4}+1}$.
\end{lemma}
\begin{proof}
    The proof is by induction. For $i=4$, we have $\beta_4 \leq n/4$,
    as claimed. Otherwise, we have
    \begin{equation*}
        \beta_{i+1}%
        =%
        2 n \pth{\beta_i/n}^d%
        \leq%
        2n \pth{1/2^{d^{i-4} + 1}}^d
        =%
        n /2^{d^{i+1-4} + d - 1}
        \leq%
        n /2^{d^{i+1-4} + 1}.

\end{proof}

\begin{theorem}
    When throwing $n$ balls into $n$ bins, with $d$ choices, with
    probability \chgY{$\geq 1-1/n^{O(1)}$}{$\geq 1-1/n^{c}$, for any constant $c>1$ (the $O(1)$ below depends on $c$)}, we have that the maximum load of
    a bin is $O(1) + \tfrac{\lg \lg n}{\lg d}$.
\end{theorem}
\begin{proof}
    By \lemref{how:betas:behave}\chgY{, with the desired probability the
    $\beta_i$s bound the load in the bins for $i \leq I$.}{ (D), with the desired probability the
    maximum load is $I + O(c)$, so it suffices to bound $I$.}  By
    \lemref{beta:i:good}, \chgY{it follows that for
    $I = O(1) + \tfrac{\lg \lg n}{\lg d}\Bigr.$, we have that
    {$\beta_{I+1} \leq 16 c \ln n$}.  ~This gives the desired bound.}{$\beta_i < 16 c \ln n$ once
    $2^{d^{i-4}} > n/(16 c\ln n)$, that is, for
    $i = 4 + \ceil{\log_d \lg n} = O(1) + \tfrac{\lg \lg n}{\lg d}$.
    Since the $\beta_i$ are decreasing, $I$ is at most this value, which
    gives the desired bound.}
\end{proof}

It is not hard to verify that the upper bounds $\beta_i$ are tight up to
constants, so the maximum load is, up to an additive constant, the
same. We state this without proof.

\begin{theorem}
    When throwing $n$ balls into $n$ bins, with $d$ choices (where the
    ball is placed into the bin with the least load), with probability
    $\geq 1-o(1/n)$, we have that the maximum load of a bin is at
    least $\tfrac{\lg \lg n}{\lg d} - O(1)$.
\end{theorem}

\subsection{Applications}

As a direct application of the power of two choices, we can use it for
open hashing (chaining), where we use two hash functions, and place an
element in the bucket of the hash table with fewer elements. By the
above, this improves\, with high probability, the worst-case search time
from $O( \log n / \log \log n)$ to $O( \log \log n)$. This comes at the
cost of doubling the time it takes to do lookup on average.

\subsection{The power of restricted $d$ choices: %
   Always go left}
\seclab{restricted:d:choices}%

\noindent%
\textbf{The always go left rule.} %
\chgY{}{Assume that $d$ divides $n$. }Consider throwing a ball into $n$ bins (which might already have some
balls in them) as follows -- you pick uniformly a number
$X_i \in \IRX{n/d}$, for $i=1,\ldots, d$. Next, you try locations
$Y_1, \ldots, Y_d$, where $Y_j = X_j + (j-1)(n/d)$, for $j=1,\ldots, d$. Let
$L_j$ be the load of bin $Y_j$, for $j=1,\ldots, d$, and let
$L = \min_j L_j$ be the minimum load \chgY{of any bin.}{among these $d$ bins.}\remX{W6: the random numbers are indexed $X_i$ but used as $X_j$; also $Y_j$ and $\tau$ clash with $Y(d,n,m)$ and $\tau_j$ used nearby.} Let $\tau$ be the minimum
index such that $L_j = L$. We throw the ball into $Y_\tau$.

What the above scheme does is to partition the $n$ bins into $d$
groups each of size $n/d$, placed from left to right. We pick a bin
uniformly from each group, and always throw the ball in the leftmost
location that realizes the minimum load.

The following proof is only a sketch: it reduces the process to the
row-filling game and skips the concentration details.

\begin{theorem}
    When throwing $n$ balls into $n$ bins, using the always-go-left rule,
    with $d$ groups of size $n/d$, the maximum load of a bin is
    $O(1) + \tfrac{\lg \lg n}{d}$, with high probability.
\end{theorem}
\begin{proof}[Sketch.]
    We consider each of the $d$ groups to be a row in the matrix being
    filled. So each row has $n/d$ entries, and there are $d$ rows. We
    can now think about the above algorithm as first trying to place
    the ball in the first row (if there is an empty bin), otherwise,
    trying the next row and so on. If all the $d$ locations are full,
    in the row filling game we fail to place this ball.  By
    \lemref{strong:conc:3} \itemref{strong:c:3:B}, we have that the
    number of unplaced balls is
    $\Ex{\bigl. Y\bigl(d,n/d, (n/d) d\bigr)} = O\bigl( (n/d) \log d
    \bigr) $.  Thus, we have that the number of balls that get placed
    as the first ball in their bin is
    \begin{equation*}
        \geq n\Bigl(1-\frac{O(\log d)}{d}\Bigr),
    \end{equation*}
    and the height of these balls is one.

    \chgY{Applying the same argumentation for balls of height
    2---}{Applying the same argument to balls of height $2$,}
    \lemref{strong:conc:3} (C) implies that\chgY{}{, in expectation,} at most {$dn/e^{d/2}$}
    balls have height strictly larger than $2$.\remX{U2 in review.md: (C) with $n/d$ bins per row gives $(n/d)/e^{d/2}$, not $dn/e^{d/2}$; and the reduction to the row game is only exact at height~1, see G5.}

    \lemref{strong:conc:3} (A) \chgY{implies that now we can repeat the same
    analysis as the power of two choices, the critical difference is
    that every one of the $d$ groups, behaves like a separate height.}{now lets us repeat the same analysis
    as for the power of two choices. The critical difference is that
    each of the $d$ groups acts as its own height level, so the analysis
    advances $d$ levels per unit of load.}\remX{G5 in review.md: for heights $\geq 2$ the process is not the row game of \lemref{strong:conc:3} (probes are uniform over the group, not over the bins of load $\geq i-1$), and the row game is the optimistic side. The conclusion is true (V{\"o}cking), but the lemma does not imply it; say so explicitly.}
    Since the maximum height is $O( \log \log n)$ in the regular
    analysis, this implies that we get $O( (\log \log n)/d)$ maximum
    load, with high probability.
\end{proof}

\section{Avoiding terrible choices}
\seclab{a:t:c}

Interestingly, one can prove (see the bibliographical notes) that two
choices are not really necessary. Indeed, consider the variant where the
$i$\th ball \chgY{randomly chooses a random location $r_i$.}{chooses a
   uniformly random location $r_i$.} The ball is then placed in the bin
with the least load among the bins $r_i$ and $r_{i-1}$ (the first ball
inspects only a single bin -- $r_1$). It is not difficult to show that the
above analysis applies in this setting, and the maximum load is
$O( \log \log n)$ -- despite making only $n$ choices for $n$
balls. Intuitively, what is going on is that the power of two choices
lies in the ability to avoid following a horrible, no good, terrible
choice, by having an alternative. This alternative choice does not have
to be of quite the same quality as the original choice---it can be stolen
from the previous ball, etc.

\section{Escalated choices}

A variant that seems to work even better in practice\chgY{,}{ (than $2$-choices)} is the following
\emphOnly{escalated choices}\index{escalated choices} algorithm: The idea is to try more than one
bin only if you need to. To this end, try a random bin. If it is
empty, then the algorithm stores the ball in it. Otherwise, the
algorithm tries harder. In the $j$\th iteration, for $j >1$, the
algorithm picks \chgY{a random location. If any of the $j$ locations have}{one more random location (so $j$ locations have been inspected
so far). If any of these $j$ locations have}
load $< \ceil{j/2}$, then the algorithm places the ball in the
min-load bin among these. Otherwise, the algorithm continues to the
next iteration.

Experiments show that, on average, this algorithm probes only $1.96$
bins per ball (thus, making fewer probes than $2$-choices). In this
setting, the experiments show that $4$-choices with go-left do
better, but if one uses the threshold $< \ceil{j/3}$, then the average
number of probes is $2.30179$, while again having a better
performance.\remX{W7 in review.md: say in what measure ``better'' is meant (maximum load? load histogram?) and what is compared with what; also $1.96$ vs.\ $2.30179$ precision.} The intuition is that a sequence of really bad choices
is rare, and one can afford to try harder in such cases to get out of
them.

A theoretical analysis of this variant should be interesting.

(I ``invented'' this variant, but it might already be known.)

\begin {defn}[\DefName {Shatter function}] \deflab {shatter:function}Given a range space $\RangeSpace = (\GroundSet , \RangeSet )$, its \emphOnly {shatter function}\index {shatter function} $\ShatterFunc {\RangeSpace }(m)$ is the maximum number of sets that might be created by $\RangeSpace $ when restricted to subsets of size $m$. Formally, \begin {equation*} \ShatterFunc {\RangeSpace }(m)=\smash {\max _{\substack {B \subset \GroundSet \\ \cardin {B} = m}} \cardin { \VCProj {\RangeSet }{B} }}; \end {equation*} see \Eqref {v:c:project}. \end {defn}

\begin {theorem}[Hoeffding's inequality] Let $X_1, \dots , X_n$ be independent random variables, where $X_i \in \pbrcS {a_i, b_i}$, for $i=1,\ldots , n$. Then, for the random variable $ S = X_1 + \cdots + X_n$ and any $\eta > 0$, we have \[ \Prob {\ts \cardin {\Bigl . S - \Ex {\ts S\MakesBig } \ts } \geq \eta } \leq 2\exp \pth { - \frac {2\,\eta ^2}{\sum _{i=1}^n (b_i - a_i)^2} }. \] \par \index {inequality!Hoeffding} \index {Hoeffding's inequality} \par \thmlab {Hoeffding:inequality} \end {theorem}

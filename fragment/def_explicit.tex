\begin {theorem} For any $t > 0, r>0$ and $q = 2^t$, where $r<q$, we have that $\LD {q}{r}$ is a graph with $q^{r+1}$ vertices. Furthermore, $\lambda _1\pth {\LD {q}{r}} = q^2$, and $\lambda _i\pth {\LD {q}{r}} \leq rq$, for $i=2,\ldots , n$. \par In particular, if $r \leq q/2$, then $\LD {q}{r}$ is a \Expander {\MakeBig q^{r+1}}{q^2}{\frac {1}{4}}. \par \thmlab {explicit} \end {theorem}

\begin {defn}\index {Complexity!\CClass {BPP}} \deflab {b:p:p}The class \CClass {BPP} (for Bounded-error Probabilistic Polynomial time) is the class of languages that have a randomized algorithm \Alg with worst case polynomial running time such that for any input $x \in \Sigma ^*$, we have \begin {compactenumi} \item If $x \in L$ then $\Prob {\Alg (x) \text { accepts}} \geq 3/4$. \par \item If $x \notin L$ then $\Prob {\Alg (x) \text { accepts}} \leq 1/4$. \end {compactenumi} \end {defn}

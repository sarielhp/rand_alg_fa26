\begin {theorem} Let $\RangeSpace _1 = \pth {\GroundSet ,\RangeSet ^1}, \ldots , \RangeSpace _k = \pth {\GroundSet ,\RangeSet ^k}$ be range spaces with \VC dimension $\Dim _1, \ldots , \Dim _k$, respectively. Next, let $f\pth { \range _1, \ldots , \range _k}$ be a function that maps any $k$-tuple of sets $\range _1 \in \RangeSet ^1, \ldots , \range _k \in \RangeSet ^k$ into a subset of $\GroundSet $. Here, the function $f$ is restricted to be defined by a sequence of set operations like complement, intersection and union. Consider the range set \begin {align*} \RangeSetA =\Set { f\pth { \range _1, \ldots , \range _k}}{ \range _1 \in \RangeSet _1, \ldots , \range _k \in \RangeSet _k \bigr .} \end {align*} and the associated range space $\RangeSpaceA = \pth {\GroundSet , \RangeSetA }$. Then, the \VC dimension of $\;\RangeSpaceA $ is bounded by $O\pth { k \Dim \lg k}$, where $\Dim = \max _i \Dim _i$. \par \thmlab {VC:combination} \end {theorem}

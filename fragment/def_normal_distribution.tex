\begin {lemma} \lemlab {normal:distribution}We have the following properties: \begin {compactenumA} \par \smallskip \item Consider $\hdim $ independent variables $X_1, \ldots , X_\hdim \sim \NormalY {0}{1}$, the point $\pntA = (X_1, \ldots , X_\hdim )$ has the multi-dimensional normal distribution $\NormalDistX {\hdim }$. \par \smallskip \item The multi-dimensional normal distribution is symmetric. For any two points $\pnt , \pntA \in \Re ^\hdim $ such that $\norm { \pnt } = \norm {\pntA }$, we have that $g(\pnt ) = g(\pntA )$, where $g(\cdot )$ is the density function of the multi-dimensional normal distribution $\NormalDistX {\hdim }$. \par \smallskip \item The projection of the normal distribution on any direction (i.e., any vector of length $1$) is a one-dimensional normal distribution. \end {compactenumA} \end {lemma}

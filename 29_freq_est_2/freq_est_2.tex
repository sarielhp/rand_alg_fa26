\section{Counting number of distinct elements}

We first analyze an idealized estimator based on fully random hash
values. We then turn to pairwise independent sampling.

\subsection{First order statistic}

Let $X_1, \ldots, X_u$ be $u$ independent random variables uniformly
distributed in $[0,1]$. Let $Y = \min (X_1, \ldots, X_u)$. The value $Y$ is
the \emphOnly{first order statistic}\index{first order statistic} of
$X_1,\ldots, X_u$.


For a continuous variable $X$, the \emphOnly{probability density
   function}\index{probability density function} (i.e.,
\emphOnly{\pdf}\index{\pdf}) is the ``probability'' of $X$ having this
value. Since this is not well defined, one looks on the
\emphOnly{cumulative distribution function}\index{cumulative distribution
   function} $F(x) = \Prob{X \leq x}$. The \pdf is then the derivative of
the \cdf.  Discrete distribution do not have ordinary \pdf{}s. This can
be simulated by Dirac's $\delta$-functions, but fortunately, this pile of
amusement and headache is outside our scope. In particular, the
probability $\Prob{X=\alpha}$, for any specific $\alpha$, is zero.

\begin{lemma}
    The \emph{probability density function} of $Y$ is
    \begin{equation*}
        f(x) = \binom{u}{1} 1 (1-x)^{u-1}.
    \end{equation*}
\end{lemma}
\begin{proof}
    The minimum exceed $x$ only if all the $u$ numbers are larger than
    $x$. Thus,
    $ F(x)=\Prob{Y \leq x } =1 - (1-x)^u$. As such
    $f(x) = F'(x) = u(1-x)^{u-1}$.
\end{proof}
\begin{proof}[Second version: no need to read it.]
    Considering the \pdf of $X_1$ being $x$, and all other $X_i$s
    being bigger. We have that this \pdf is
    \begin{align*}
        g(x)
        &=%
        \Prob{ (X_1 = x) \cap \smash{\bigcap_{i=2}^u} (X_i>X_1)\Bigr.}
        \\&=
        \ProbCond{\Bigl. \smash{\bigcap_{i=2}^u} (X_i>X_1)}{X_1=x} \Prob{X_1=x}
        \\&=%
        (1-x)^{u-1}.
    \end{align*}
    Since every one of the $X_i$ has equal probability to realize $Y$,
    we have $f(x) = u g(x)$.
\end{proof}

\begin{lemma}
    \lemlab{order:stat}%
    %
    We have $\Ex{Y} = \frac{1}{u+1}$,
    $\Ex{Y^2} = \frac{2}{(u+1)(u+2)}$, and
    $\Var{Y}=\frac{u}{(u+1)^2 (u+2)}$.
\end{lemma}
\begin{proof}
    Let $A,B$ be two independent uniform samples from $[0,1]$,
    independent of $X_1,\ldots,X_u$. Conditioned on $Y$, the probability
    that $A<Y$ is $Y$. On the other hand, $A<Y$ exactly when $A$ is
    the smallest of $u+1$ samples. Thus, by symmetry,
    \[
        \Ex{Y} = \Prob{A<Y} = \frac{1}{u+1}.
    \]
    Similarly, conditioned on $Y$, the probability that both $A$ and
    $B$ are smaller than $Y$ is $Y^2$. This happens exactly when
    $A,B$ are the two smallest of $u+2$ samples. All pairs are equally
    likely to be the two smallest, so
    \[
        \Ex{Y^2}%
        \EQ%
        \Prob{A<Y,\ B<Y}%
        \EQ%
        \frac{1}{\binom{u+2}{2}}%
        \EQ%
        \frac{2}{(u+1)(u+2)}.
    \]
    Consequently,
    \begin{align*}
        \Var{Y} &= \Ex{Y^2} - \pth{\Ex{Y}}^2\\
        &= \frac{2}{(u+1)(u+2)} - \frac{1}{(u+1)^2}
        = \frac{u}{(u+1)^2(u+2)}.
    \end{align*}
\end{proof}

\subsection{The algorithm}

\paragraph*{A single estimator.}



Assume that we have a perfectly random hash function $h$ that randomly
maps $N = \brc{1,\ldots, n}$ to $[0,1]$. Assume that the stream
$\STRM=\strm_1,\ldots,\strm_m$, has $u$ unique numbers in $N$. Then the set
$\{h(\strm_1),\ldots, h(\strm_m)\}$ contains $u$ random numbers uniformly
distributed in $[0,1]$.  The algorithm computes $Y = \min_i h(\strm_i)$.

\paragraph*{Explanation.}
Note that $Y$ is \emph{not} an estimator for $u$ -- instead, as
$\Ex{Y} = 1/(u+1)$, we are estimating $1/(u+1)$. The key observation is
that an $1 \pm \eps$ estimator for $1/(u+1)$, is $1 \pm O(\eps)$ estimator for
$u+1$, which is in turn an $1 \pm O(\eps)$ estimator for $u$.

\begin{lemma}
    Let $\eps, \BadProb \in (0,1)$ be parameters. Given a stream
    $\STRM$ of items from $\{1,\ldots, n\}$ one can return an estimate
    $X$, such that
    \begin{equation}
        \Prob{ (1-\eps/4)\frac{1}{u+1} \leq X \leq
           (1+\eps/4)\frac{1}{u+1}} \geq 1-\BadProb,
        \eqlab{range-est}
    \end{equation}
    where $u$ is the
    number of unique elements in $\STRM$. This requires
    $O\pth{ \frac{1 }{\eps^2 } \log \frac{1}{\BadProb}}$ space.
\end{lemma}
\begin{proof}
    The basic estimator $Y$ has $\mu = \Ex{Y} = \frac{1}{u+1}$ and
    $\nu = \Var{Y}=\frac{u}{(u+1)^2 (u+2)}$. We now plug this
    estimator into the mean/median framework. By \lemref{order:stat},
    for $c$ some absolute constant, this requires maintaining $M$
    estimators, where $M$ is larger than
    \begin{equation*}
        c \frac{4\cdot 16 \nu}{\eps^2 \mu^2 } \log \frac{1}{\BadProb}
        = 
        O\pth{  \frac{u^2 }{\eps^2 u^2 } \log \frac{1}{\BadProb}}
        = 
        O\pth{  \frac{1 }{\eps^2  } \log \frac{1}{\BadProb}}.
    \end{equation*}
\end{proof}

Assume $X$ is in the desired range, and write it in the form
$X = (1+\eta)/(u+1)$, where $|\eta|\leq\eps/4$. For a nonempty stream, $u\geq1$, so
\begin{align*}
    \frac{|(1/X-1)-u|}{u}
    &= \frac{u+1}{u}\frac{|\eta|}{|1+\eta|}
    \leq \frac{2|\eta|}{1-|\eta|}
    \leq \frac{2\eps}{4-\eps}<\eps.
\end{align*}
Thus, $1/X-1$ is a $(1\pm\eps)$-estimate of the number of distinct
elements.

\paragraph*{The algorithm revisited.}
Compute $X$ as above, and output the quantity $1/X-1$.

\bigskip

This immediately implies the following.

\begin{lemma}
    Let $\eps,\BadProb\in(0,1)$. Under the unreasonable\footnote{Criminal
       even!} assumption that we can sample perfectly random functions
    from $\{1,\ldots,n\}$ to $[0,1]$, and store each function and each hash
    value in $O(1)$ words, one can process a nonempty stream with $u$
    distinct elements and return an estimate $\rho$ satisfying
    \[
        \Prob{(1-\eps)u\leq\rho\leq(1+\eps)u}\geq1-\BadProb,
    \]
    using $O(\eps^{-2}\log(2/\BadProb))$ words.
\end{lemma}

\subsection{Implementing the scheme}
\seclab{distinct:implementation}%

The preceding analysis assumes that a perfectly random hash function
and its values can be stored in constant space. This is problematic:
storing an arbitrary random function requires a table with an entry for
every possible input, and a uniformly random real number has unbounded
precision. Neither fits our small-space model.

Instead, hash into a sufficiently large finite range using a $k$-wise
independent family. Such a hash function can be represented by $k$
coefficients over a finite field, using $O(k)$ words. The same input
always receives the same hash value, while any $k$ distinct inputs have
independent uniform hash values. Indyk~\cite{i-samwi-01} showed that
$k=O(\log(1/\eps))$ suffices for approximate min-wise independence:
with a sufficiently large range, each value in a fixed set of size $u$
is its unique minimum-hash value with probability $(1\pm\eps)/u$.

Using this result and limited-independence moment bounds, one can
implement the minimum estimator above with sufficiently large $k$ and
a sufficiently fine finite range. The analysis must bound the bias in
the moments and the error from discretization; the exact identities
proved above no longer hold. These details are somewhat tedious, and
we omit them. For our purposes, the following deliberately nonoptimal
consequence suffices: assuming $n>1$, using $k=O(\log n)$ and independent repetitions,
one obtains an estimate $\rho\in[u/2,2u]$ with failure probability at
most $(2n)^{-c}$, for any fixed constant $c>0$, using
$O(\log^2 n)$ words. Thus, the idealized assumption can be removed
while keeping the space polylogarithmic.

\section{Sampling with pairwise independence}




Assume that we have a stream of elements
$\STRM = \strm_1, \ldots, \strm_m$, all taken from the set
$\{1,\ldots, n\}$.  Let $\distinctX{\STRM}$ denote the set of values that
appear in $\STRM$, and set $S=\distinctX{\STRM}$. Thus,
\begin{equation*}
    \Frq_0 = \Frq_0(\STRM) = \cardin{S}
\end{equation*}
is the number of distinct values in the stream $\STRM$.


Assume that we have a random sequence of bits
$\mathcal{B} \equiv B_1, \ldots, B_n$, such that $\Prob{B_i=1} =p$, for
some $p$. Furthermore, we can compute $B_i$ efficiently. Assume that the
bits of $\mathcal{B}$ are pairwise independent, and can be computed using constant
space.


\paragraph*{The sampling algorithm.}
When the $i$\th item $\strm_i$ arrives, we compute $B_{\strm_i}$. If this
bit is $1$, then we insert $\strm_i$ into the random sample $R$ (if it is
already in $R$, there is no need to store a second copy, naturally).


This defines a natural random sample
\begin{equation*}
    R = \Set{i}{B_i =1 \text{ and } i \in S} \subseteq S.
\end{equation*}

\begin{lemma}
    \lemlab{f:e:2:ev}%
    %
    For the above random sample $R$, let $X = \cardin{R}$. We have
    that $\Ex{X} = p \nu$ and $\Var{X} = p \nu - p^2 \nu$, where
    $\nu = \Frq_0(\STRM)$ is the number of distinct elements in $S$.
\end{lemma}
\begin{proof}
    Since $X=\sum_{i\in S}B_i$, linearity of expectation gives
    \[
        \Ex{X}=\sum_{i\in S}\Ex{B_i}=p\nu.
    \]
    Pairwise independence makes the covariances zero, so
    \[
        \Var{X}=\sum_{i\in S}\Var{B_i}
        =\nu p(1-p)=p\nu-p^2\nu.
    \]
\end{proof}
  
\begin{lemma}
    \lemlab{estimator}%
    %
    Let $\eps \in (0,1/4)$.  Given $O(1/\eps^2)$ space, and a
    parameter $N$. Consider the task of estimating the size of
    $\Frq_0 = \cardin{\distinctX{\STRM}}$, where $\Frq_0 > N/4$.
    Then, the algorithm described below outputs one of the following:
    \begin{compactenumA}
        \smallskip%
        \item $\Frq_0 > 2N$.
        \smallskip%
        \item Output a number $\rho$ such that
        $(1-\eps)\Frq_0 \leq \rho \leq (1+\eps)\Frq_0$.
    \end{compactenumA}
    \smallskip%
    (Note, that the two options are not disjoint.)  The output of this
    algorithm is correct, with probability $\geq 7/8$.
\end{lemma}
\begin{proof}
    We set $p= \frac{c}{N\eps^2}$, where $c$ is a constant to be determined
    shortly\footnote{If $p>1$ call the probability police and set its
       value to $1$, which makes what follows uninteresting.}. Let
    $T = p N = O(1/\eps^2)$. We sample a random sample $R$ from $S$, by
    scanning the elements of $S$, and adding $i\in S$ to $R$ if $B_i=1$, If
    the random sample is larger than $8T$, at any point, then the
    algorithm outputs that $\cardin{S} > 2N$.

    In all other cases, the algorithm outputs $\cardin{R} /p$ as the
    estimate for the size of $S$, together with $R$.

    To bound the failure probability, consider first the case that
    $N/4 < \cardin{\distinctX{\STRM}}$. In this case, we have by the
    above, that
    \begin{align*}
        \Prob{\cardin{X - \Ex{X}} > \eps \Ex{X}}%
        &\leq%
        \Prob{\cardin{X - \Ex{X}} > \eps
           \frac{\Ex{X}}{\sqrt{\Var{X}}}
           \sqrt{\Var{X}}}%
        \\&\leq%
        \frac{\Var{X}}{\eps^2(\Ex{X})^2}
        \leq
        \frac{1}{8},
    \end{align*}

    if $\frac{\Var{X}}{\eps^2 (\Ex{X})^2} \leq \frac{1}{8}$, For
    $\nu = \Frq_0 \geq N/4$, this happens if
    $\frac{p \nu}{\eps^2 p^2 \nu^2} \leq \frac{1}{8}$. This in turn is
    equivalent to $8/\eps^2 \leq p \nu $. This in turn happens if
    \begin{equation*}
        \frac{c}{N\eps^2} \cdot \frac{N}{4} \geq \frac{8}{\eps^2}, \biggr.
    \end{equation*}
    which implies that this holds for $c=32$.  Namely, the algorithm
    in this case would output a $(1\pm\eps)$-estimate for
    $\cardin{S}$.

    Thus, assume that $X$ is within the ``good'' range, which happens
    with probability $\geq 7/8$. If the sample gets bigger than $8T$, then
    the above readily implies that the size of $S$ is at least
    $(1-\eps)8T/p > 2N$. Namely, the output of the algorithm is correct in
    this case.
\end{proof}
  
\begin{lemma}
    \lemlab{f:e:0:resolution}%
    %
    Let $\eps \in (0,1/4)$ and $\BadProb \in (0,1)$.  Given
    $O(\eps^{-2} \log \BadProb^{-1})$ space, and a parameter $N$, and
    the task is to estimate $\Frq_0$ of $\STRM$, given that
    $\Frq_0 > N/4$.  Then, there is an algorithm that would output one
    of the following:
    \begin{compactenumA}
        \smallskip%
        \item $\Frq_0 > 2N$.
        \smallskip%
        \item Output a number $\rho$ such that
        $(1-\eps)\Frq_0 \leq \rho \leq (1+\eps)\Frq_0$.
    \end{compactenumA}
    \smallskip%
    (Note, that the two options are not disjoint.)  The output of this
    algorithm is correct, with probability $\geq 1- \BadProb$.
\end{lemma}

\begin{proof}
    We run $O( \log \BadProb^{-1})$ independent copies of
    \lemref{estimator}. If half of them returns that $\Frq_0 > 2N$, then
    the algorithm returns that $\Frq_0 > 2N$. Otherwise, the algorithm
    returns the median of the estimates returned, and return it as the
    desired estimate. The correctness readily follows by a repeated
    application of Chernoff's inequality. Indeed, for the result to be
    wrong, at least a quarter of the estimators have to fail, but the
    probability of failure per estimator is at most $1/8$.
\end{proof}


\begin{lemma}
    Let $\eps \in (0,1/4)$.  Given $O(\eps^{-2} \log^2 n)$ space, one
    can read the stream $\STRM$ once, and output a number $\rho$, such
    that $(1-\eps)\Frq_0 \leq \rho \leq (1+\eps)\Frq_0$. The estimate
    is correct with high probability (i.e., $\geq 1-1/n^{O(1)}$).
\end{lemma}
\begin{proof}
    Let $N_i = 2^i$, for $i=1, \ldots, M$, where $M = \ceil{\lg n}$. Run
    $M$ copies of \lemref{f:e:0:resolution}, for each value of $N_i$,
    with $\BadProb = 1/n^{O(1)}$. Let $Y_1, \ldots, Y_M$ be the outputs of
    these algorithms for the stream. A prefix of these outputs, are going
    to be ``$\Frq_0 > 2N_i$'', Let $j$ be the first $Y_j$ that is a
    number.

  
    % Return this number as the desired estimate. The correctness
    % is easy---the first estimate that is a number, is a correct estimate
    % with high probability. Since $N_M \geq n$, it also follows that $Y_M$
    % must be a number. As such, there is a first number in the sequence,
    % and the algorithm would output an estimate.

    More precisely, there is a minimal index $i$, such that
    $N_i/4 \leq \Frq_0 \leq 2N_i$, and $Y_i$ is a good estimate, with high
    probability. The algorithm returns $Y_i$ as the desired estimate.
    Importantly, all earlier estimates are correct with high probability
    as well.
    % If any of the $Y_j$, for $j < i$, is an estimate, then
    % it is correct (again) with high probability.
\end{proof}


\subsection{Sampling in detail}

Assume $n>1$ throughout this subsection.

\begin{remark}[Using the scheme twice]
    A natural approach is to run two independent copies of the preceding
    scheme: use the first to estimate $u=\cardin{S}$, and use this estimate
    to choose a resolution in the second with expected sample size
    $\Theta(t)$. Choosing uniformly among the non-overflowed samples, with
    a generous $Ct$ cap, preserves inclusion probabilities within constant
    factors. Repetition makes such a sample available with high
    probability, but it unfortunately still biased.
\end{remark}

\paragraph*{One approximately uniform value.}
Assume for now we know the value $u$ (the scheme would also if we know it
only approximately).  Choose a sampling probability $p$ with
\begin{equation*}
    \frac{1}{32}
    <
    pu
    \leq
    \frac{1}{4},
\end{equation*}
and retain a pairwise independent sample $R$ only when it
is a singleton, using the above scheme.

% AAA
Recall that we use pairwise independent bits $B_1, \ldots, B_n$ (which
can be computed on the fly using constant space), with
\begin{equation*}
    \Prob{B_i=1}=p.
\end{equation*}
The same bit $B_x$ is used for every occurrence of $x$. The algorithm
stores the first value $x$ encountered with $B_x=1$, and marks the trial
as failed permanently if a different value $y$ with $B_y=1$
arrives. Repeated occurrences of the stored value are ignored. Thus, a
trial uses constant space and succeeds exactly when
$R=\Set{x\in S}{B_x=1}$ is a singleton.

Fix $x\in S$ and condition on $B_x=1$. For each $y\neq x$, pairwise
independence gives $\ProbCond{B_y=1}{B_x=1}=p$. Thus, by the union bound,
\begin{align*}
    \ProbCond{R=\{x\}}{B_x=1}
    &=1-\ProbCond{\bigcup_{y\in S\setminus\{x\}}\{B_y=1\}}{B_x=1}
    \\
    &\geq1-\sum_{y\in S\setminus\{x\}}
                   \ProbCond{B_y=1}{B_x=1}
    \\
    &=1-(u-1)p\geq\frac34,
\end{align*}
where the last inequality uses $up\leq1/4$. Since $\Prob{B_x=1}=p$,
we conclude that
\[
    \Prob{R=\{x\}}
    \EQ%
    p\ProbCond{R=\{x\}}{B_x=1}
    \GEQ%
    \frac{3p}{4}.
\]
Observe that
\begin{equation*}
    \Prob{R=\{x\}}
    \leq
    \Prob{B_x = 1}
    =
    p
\end{equation*}
Since the singleton events are disjoint, a trial succeeds with probability
\[
    \Prob{\cardin{R}=1}
    =\sum_{x\in S}\Prob{R=\{x\}}
    \geq\frac{3up}{4}>\frac{3}{128}>\frac{1}{64}.
\]
Conditional on the success of the sample, its returned value being $x$
has probabilities $q_x$ satisfying
\[
    \frac{3}{4u}\leq q_x\leq\frac{4}{3u}.
\]

%TTT
\begin{remark}
    Pairwise independence does not guarantee that the $q_x$ are equal.
    Higher independence gives a closer approximation to uniformity, but
    no fixed level of $k$-wise independence guarantees exact uniformity
    for arbitrarily large $u$. Fully independent bits give $q_x=1/u$
    for every $x\in S$.
\end{remark}

\paragraph*{Choosing the resolution and collecting values.}
We may assume $1\leq t<u/4$: in parallel, store up to $4t$ distinct values
and mark this set as overflowed upon encountering a new value when it is
full. If it never overflows, return a uniformly random $t$-subset of the
stored values, or all of them if there are fewer than $t$. This handles
$u\leq4t$, including an empty stream, using $O(t)$ additional words.

Set $\delta=(2n)^{-3}$. Use the preceding counting scheme to obtain
$\rho\in[u/2,2u]$, except with probability at most $\delta/2$, and clamp
it to $[1,n]$. Independently, maintain
$K=\lceil128t\ln(n/\delta)\rceil$ independent singleton trials at each
resolution $p_j=2^{-j}$, for $j=0,\ldots,\lceil\lg(16n)\rceil$.
At the end, choose the largest $p_j\leq1/(8\rho)$, using only the estimate.
For a good estimate, the chosen probability satisfies $1/32<pu\leq1/4$.
Inspect this level's trials in their predetermined order, and return the
first $t$ distinct successful values, or all distinct successful values
if there are fewer.

\begin{theorem}[Sampling distinct values]
    \thmlab{distinct:sampling}%
    Let $1\leq t<u/4$, where $u\leq n$. A stream with $u$ distinct values can be
    processed in one pass using pairwise independent hashing and
    $O(t\log^2 n)$ words of space. The returned set $T$ satisfies
    \[
        \Prob{\cardin{T}=t}\geq1-(2n)^{-3}.
    \]
    Every distinct value has inclusion probability
    $\Theta(t/u)$, regardless of its frequency in the stream.
\end{theorem}
\begin{proof}
    Fix any good estimate, so that the selected level is independent of
    its trials. Up to a constant factor, collecting $t$ distinct values
    is no slower than collecting all $t$ types in the standard coupon
    collector problem. Its concentration bound\BookMode{
    (\lemref{coupon})} therefore implies that the $K$ trials collect $t$
    distinct values except with probability at most $\delta/2$. Adding
    the probability of an estimation error proves the sample-size
    guarantee.

    Since at most $t<u/4$ values are picked, each new value is
    approximately uniform among the remaining values, which still form
    a constant fraction of $S$. Thus, every value has inclusion probability
    $\Theta(t/u)$; the small failure probability does not affect these
    constant-factor bounds.

    Finally, there are $O(\log n)$ resolutions, each storing
    $K=O(t\log n)$ constant-space trials. The counting scheme uses
    $O(\log^2 n)$ additional words.
\end{proof}

The conclusion concerns individual inclusion probabilities, not uniformity over all size-$t$
subsets. Only pairwise independence is needed within each trial; the
trials and the counting scheme use independent randomness.


\subsubsection{Why not ordinary reservoir sampling?}

Reservoir sampling chooses stream positions uniformly, so repeated values
are favored. For example, a reservoir of size one selects a value of
frequency $f_x$ with probability $f_x/m$. If the stream contains $m-1$
copies of $a$ and one copy of $b$, we want probability $1/2$ for each,
whereas reservoir sampling selects $b$ with probability $1/m$. Removing
duplicates afterward does not remove this bias.

Applying reservoir sampling only to first occurrences would work, but
recognizing them by storing all previously seen values costs $O(u)$
words. Checking only the reservoir does not suffice: a discarded value
can reappear. Our sampling rule instead reuses the same hash value for
every occurrence. Reservoir sampling does work once a set of distinct
values has already been stored.

\section{Bibliographical notes}

The singleton construction above is mainly pedagogical: it obtains a
sample using only pairwise independence and elementary probability.
With higher independence, the concentration bounds of Schmidt \etal
\cite{sss-chbli-95} simplify the direct sampling scheme.
A sufficiently large $O(t+\log n)$ sample budget lets the appropriate
resolution retain at least $t$ values without overflowing, with high
probability. Applying the bounds also after conditioning on a value
being sampled yields approximately uniform inclusion probabilities
after choosing a uniform $t$-subset. Another standard approach is
bottom-$t$ sampling: retain the $t$ distinct values with smallest hash
values~\cite{t-bkps-13}. Five-wise independence suffices for
constant-factor inclusion probabilities, by extending the fourth-moment
argument for min-wise hashing of Knudsen and St\"ockel~\cite{ks-qlbm-15}.
These approaches give simpler sampling algorithms at the cost of
stronger probabilistic tools.
